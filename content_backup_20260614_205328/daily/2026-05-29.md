### [Claude Code Dynamic Workflows — 大规模并行子 Agent 架构](https://claude.com/blog/introducing-dynamic-workflows-in-claude-code)

### [Ktx — 开源可执行上下文层，让数据 Agent 更可靠](https://github.com/Kaelio/ktx)
