## 事情是这样的

一个月前我买了个域名 198007.xyz，想搭个在线工具站。但问题来了——**我不是程序员**。

我能看懂代码，但让我从零写一个带界面、带交互、带错误提示的工具？一天能憋出一个就不错了。

但我装了一个叫 **Hermes** 的开源AI代理。它跑在我的服务器上，能调用终端、读写文件、操作浏览器、还能定时执行任务。

我最常用的工作流是这样的：

1. 我在微信上发一句"写一个URL编码解码工具"
2. Hermes 打开项目，写好 HTML/CSS/JS，自动保存到对应目录
3. 它自动 git add → commit → push 到 GitHub
4. GitHub 自动触发 Vercel 构建
5. 30分钟后工具上线，微信收到推送通知

整个过程我问都没问过一句代码的事。
