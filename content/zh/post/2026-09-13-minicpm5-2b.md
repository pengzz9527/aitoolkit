# MiniCPM5-2B：2B 参数量内的端侧 LLM 新标杆，本地运行也能调用工具

**MiniCPM5-2B** 是由上海人工智能实验室 OpenBMB 团队于 2026 年 9 月 7 日发布的新一代端侧大语言模型，是 MiniCPM5 系列的第二款模型。它在仅 2B 参数规模下达到了 2B 级开源 SOTA，综合性能超越多数同类甚至更大参数量的模型，同时支持 131K 长上下文和原生工具调用，非常适合本地部署和资源受限场景。

## 核心功能

### 1. 2B 级开源 SOTA 性能

MiniCPM5-2B 在多个基准测试中超越了同规模的 LFM2.5-2.6B、Qwen3.5-2B、Gemma-4-E2B-it 等模型，平均得分达到 53.9，还超越了包括 Qwen3.5-4B、granite-4.2-3B 等更大参数量的模型。其优势主要集中在代码推理、数学推理、长上下文理解、工具调用和多步 Agent 任务等领域。

### 2. 原生工具调用（Tool Calling）

MiniCPM5-2B 在训练阶段就内建了工具调用能力，支持通过 XML 格式的 `<function name="...">` 标签调用外部工具。这意味着你可以在本地部署后，直接将模型接入搜索、计算器、代码执行等工具，实现真正的本地 Agent 能力，而无需依赖云端 API。

### 3. 131K 超长上下文

模型原生支持 131,072 tokens 的上下文长度，这意味着你可以将整本书、长篇技术文档或完整的代码库片段一次性喂给模型进行分析。对于需要处理长文本的本地应用（如文档摘要、代码审查、法律文件分析等），这是一个非常实用的特性。

### 4. 多格式量化版本就绪

官方提供了多种格式的模型权重，包括 BF16 原始版本、GGUF（本地推理友好）、MLX（Apple Silicon 原生优化）、GPTQ 和 DSpark 等，用户可以根据硬件条件选择最适合的格式。特别是 GGUF 和 MLX 版本，让消费级设备也能流畅运行。

### 5. UltraData 高质量训练数据体系

模型训练配套开放了完整的高质量数据集家族 UltraData，包括 Ultra-FineWeb、UltraData-Code、UltraData-Math、UltraData-SFT-Agent-2609 等，这些数据也支持用户进行进一步微调，适合追求极致本地化部署的研究者和开发者。

## 如何使用

### 方式一：HuggingFace Transformers 直接推理

```bash
# 安装依赖
pip install transformers accelerate

# Python 推理示例
from transformers import AutoModelForCausalLM, AutoTokenizer

model_name = "openbmb/MiniCPM5-2B"
tokenizer = AutoTokenizer.from_pretrained(model_name)
model = AutoModelForCausalLM.from_pretrained(
    model_name,
    torch_dtype="auto",
    device_map="auto"
)

messages = [{"role": "user", "content": "帮我写一个 Python 函数，计算斐波那契数列前 10 项"}]
text = tokenizer.apply_chat_template(messages, tokenize=False, add_generation_prompt=True)
inputs = tokenizer(text, return_tensors="pt").to(model.device)
outputs = model.generate(**inputs, max_new_tokens=512, temperature=1.0, top_p=0.95)
print(tokenizer.decode(outputs[0][inputs.input_ids.shape[1]:], skip_special_tokens=False))
```

### 方式二：Ollama 本地部署（推荐）

```bash
# 拉取并运行模型
ollama pull minicpm5:2b
ollama run minicpm5:2b "用中文解释量子计算的基本原理"
```

### 方式三：本地 GGUF 推理（低显存友好）

```bash
# 下载 GGUF 版本（约 1.2GB，4-bit 量化）
# https://huggingface.co/openbmb/MiniCPM5-2B-GGUF

# 使用 llama.cpp 运行
./main -m MiniCPM5-2B-Q4_K_M.gguf \
  -p "你好，请用中文介绍一下你自己" \
  --chat-template minicpm5
```

### 方式四：Apple Silicon 原生推理（MLX）

```bash
# 需要 mlx-lm
pip install mlx-lm
mlx_lm.generate --model openbmb/MiniCPM5-2B-MLX --prompt "写一首关于 AI 的短诗" --max-tokens 256
```

**推荐采样参数**：`temperature=1.0, top_p=0.95`；如果出现重复输出，可尝试加入 `repetition_penalty=1.05`。
