# nanobot — 开源个人 AI 智能体框架，47K Stars 的终极助手方案

![nanobot](https://raw.githubusercontent.com/HKUDS/nanobot/main/images/readme-cover-light.svg)

**nanobot** 是由香港大学数据智能实验室（HKUDS）开发的超轻量级开源个人 AI 智能体框架，基于 Python 构建，Stars 数已超过 47,000。它可以在浏览器 WebUI、终端或 Telegram、Discord、微信等多种聊天应用中运行，将工具调用、长期记忆、MCP 集成、模型路由、多智能体协作和定时自动化等功能整合在一个简洁易读的代码核心中。

## 核心功能

1. **多平台接入**：支持 WebUI 浏览器界面、命令行终端，以及 Telegram、Discord、Slack、微信、飞书、邮件、Mattermost 等聊天平台，随时随地与 AI 助手交互。
2. **长期记忆系统 Dream**：内置 Dream 记忆模块，能够跨会话持久保存对话历史和个人偏好，让 AI 助手真正"记住"你的需求。
3. **MCP 工具扩展**：原生支持 Model Context Protocol，可轻松集成 GitHub、文件系统、Shell 命令、网络搜索等外部工具，也可通过 MCP 协议接入任意第三方服务。
4. **模型自由切换**：支持 OpenAI 兼容 API、本地 LLM、图像生成等多种后端，可配置模型降级链，在主要模型不可用时自动切换备用方案。
5. **多智能体协作**：支持子智能体委托和定时自动化任务，可以让 nanobot 在后台自主执行长期目标，而无需人工干预。
6. **OpenAI 兼容 API**：内置 OpenAI 兼容接口，可轻松将 nanobot 接入 Cursor、Copilot、其他 Agent 工具或自建应用。

## 适用人群

- **追求隐私的开发者**：希望所有数据和对话完全由自己掌控，不想上传到第三方云端。
- **多工具用户**：同时使用多个 AI 编程助手（Claude Code、Cursor、Codex 等），需要一个统一入口管理所有工具。
- **自动化爱好者**：希望通过定时任务、多智能体协作实现工作流的自动化。
- **技术社区成员**：希望通过 WeChat / 飞书群参与讨论，获取最新功能更新和教程。

## 如何使用

### 安装（推荐一键安装）

```bash
# macOS / Linux
curl -fsSL https://raw.githubusercontent.com/HKUDS/nanobot/main/scripts/install.sh | sh

# Windows PowerShell
irm https://raw.githubusercontent.com/HKUDS/nanobot/main/scripts/install.ps1 | iex
```

或使用 uv：

```bash
uv tool install nanobot-ai
```

### 快速启动 WebUI

```bash
nanobot webui
```

安装完成后会自动打开浏览器访问 `http://127.0.0.1:8765`，在 Settings → Models 中配置第一个 AI 提供商即可开始使用。

### 保持后台运行

```bash
# 以守护进程方式运行
nanobot gateway --background

# 查看状态、日志、重启
nanobot gateway status
nanobot gateway logs
nanobot gateway restart
nanobot gateway stop
```

### 配置聊天平台接入

在 WebUI 的 Settings → Channels 中可按向导完成 Telegram Bot、Discord Bot、微信等平台的配置；也可通过编辑 `~/.nanobot/config.json` 手动设置：

```json
{
  "channels": {
    "telegram": {
      "enabled": true,
      "token": "${TELEGRAM_BOT_TOKEN}"
    }
  }
}
```

配置文件中的敏感信息支持使用环境变量占位符（如 `${TELEGRAM_BOT_TOKEN}`），在运行时解析，不会写入磁盘。
