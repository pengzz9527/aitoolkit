# Ruflo：AI 代理的元编排引擎

**一句话简介**：Ruflo 是一个 AI 代理元编排框架（Meta-Harness），为 Claude Code、Codex、Hermes 等主流 AI 编程代理叠加多智能体协作、自适应记忆、自我学习和安全联邦能力，让代理从"单兵作战"进化为"协同团队"。

## 核心功能

### 1. 100+ 专业代理矩阵

Ruflo 内置超过 100 个专业化代理，覆盖编码、测试、安全审计、文档生成、架构设计等全生命周期。每个代理都有明确的职责边界，例如代码审查代理专注于 PR 质量，安全审计代理扫描漏洞和 CVE，文档代理自动生成和维护技术文档。

### 2. 自适应记忆系统

基于 AgentDB + HNSW 向量数据库的持久化记忆层，检索速度比暴力搜索快约 1.9 倍（N=20k）到 3.7 倍（N=5k）。代理可以跨会话记住用户偏好、项目上下文和历史经验，实现真正的持续学习。

### 3. 多智能体协同编排

支持层级式、网状和自适应三种拓扑结构，通过共识机制（Consensus）协调多个代理的行为。智能路由引擎以 89% 的准确率将任务分发给最合适的代理，避免资源浪费。

### 4. 自我学习与优化

采用 SONA 神经网络模式匹配和推理库（ReasoningBank），代理能从历史成功经验中自主学习，不断优化工作流程。系统会记录每次任务的轨迹（Trajectories），用于后续的模式识别和改进。

### 5. 零信任联邦协作

支持跨机器、跨组织的代理安全协作。采用 mTLS + Ed25519 身份认证、14 类型 PiI 检测管道和动态信任评分机制，确保数据在传输前自动脱敏。不信任的代理只能访问发现信息，不能读取记忆。

### 6. 多模型支持

原生支持 Claude、GPT、Gemini、 Cohere、Ollama 等 LLM 提供商，配备智能路由和故障切换。同时集成 ruvLLM 本地模型层，支持纯离线运行。

## 如何使用

### 快速安装

```bash
# macOS / Linux / WSL
curl -fsSL https://cdn.jsdelivr.net/gh/ruvnet/ruflo@main/scripts/install.sh | bash

# 所有平台（含原生 Windows PowerShell / cmd）
npm init ruflo@latest
```

### 插件安装路径

**路径 A — Claude Code 插件（轻量）**
```bash
/plugin marketplace add ruvnet/ruflo
/plugin install ruflo-core@ruflo
/plugin install ruflo-swarm@ruflo
/plugin install ruflo-rag-memory@ruflo
```
零侵入工作空间，适合试用。

**路径 B — CLI 完整版**
```bash
npm init ruflo@latest
# 交互式引导安装所有组件
```
完整功能，包括 98 个代理、60+ 命令、30 技能、MCP 服务器、Hook 等。

### 注册 MCP 服务器

```bash
claude mcp add claude-flow -- npm ruflo@latest mcp start
```

### 使用 Web UI 测试

访问 [flO.ruv.io](https://flO.ruv.io)，无需注册和 API Key，可直接体验多模型聊天和代理协作。

### 目标规划器

访问 [goal.ruv.io](https://goal.ruv.io)，用自然语言描述目标，Ruflo 自动分解为可执行计划并调度代理执行。
