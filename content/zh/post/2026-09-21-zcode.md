# ZCode：Z.ai 开源的 AI 编程工作台，桌面/Web/CLI 三端覆盖

**ZCode**（zai-org/ZCode）是 [Z.ai](https://z.ai) 于 2026 年开源的 AI 编程工作台，采用 TypeScript 编写，以 Apache-2.0 许可证发布。它提供三种使用入口：**Electron 桌面应用**、**Web 界面** 和 **终端 Agent CLI**，一套后端服务打通所有入口，开发者可以根据工作习惯自由选择。

目前 ZCode 在 GitHub 上已获得 **3,600+ 星标**，最近更新于 2026 年 9 月 21 日。

- **GitHub 星标**：3,600+
- **GitHub 仓库**：https://github.com/zai-org/ZCode
- **许可证**：Apache-2.0
- **语言**：TypeScript
- **支持平台**：macOS / Windows / Linux

## 核心功能

### 1. 三端统一入口

ZCode 最大的亮点是同一套 Agent 运行时可以同时跑在三个入口上：

| 入口 | 方式 | 适用场景 |
|------|------|----------|
| Desktop | `pnpm dev:desktop`，Electron 应用 | 日常开发、重度编码 |
| Web | `pnpm dev:web`，浏览器访问 | 远程协作、无桌面环境 |
| CLI / TUI | `zcode` 或 `zcode --web` | 终端党、SSH 远程操作 |

三种入口共享同一个后端服务和 Agent 运行时，工作区、会话历史、配置完全同步。

### 2. 终端 TUI 与 Agent 命令行

在终端中直接运行 `zcode` 即可进入 TUI（终端用户界面），无需打开浏览器。对于习惯命令行操作的开发者来说，这是最轻量级的接入方式。Agent CLI 同时也为 Desktop 和 Web 提供后端运行时支持。

### 3. SSH / WSL 远程开发支持

ZCode 支持通过 SSH 或 WSL 连接到远程项目，开发态资源取自本地构建产物，经 SFTP 上传到远程执行，不依赖外部 CDN。这对需要在远程服务器或容器环境中工作的开发者非常友好。

### 4. 完整的桌面打包能力

可以通过 `pnpm bundle:desktop` 构建各平台的桌面安装包，支持 macOS arm64/x64、Windows x64、Linux x64 等目标。构建脚本自动生成 DMG / MSI / AppImage 等格式，开箱即用。

### 5. 规范的 UI 设计系统

ZCode 内置了一套完整的 Design System（见 `DESIGN.md`），定义了从字体尺度（`text-ui-*`）、语义化颜色变量到主题模式的完整规范，界面风格冷静、信息密度高，适合长时间编码场景。

## 适用人群

- **追求多端统一的开发者**：希望桌面、Web、终端三端体验一致，随时切换工作入口。
- **远程/服务器开发者**：需要 SSH 或 WSL 远程连接进行编码，ZCode 的远程模式正好匹配。
- **终端爱好者**：喜欢 TUI 操作，不想频繁切换图形界面。
- **Z.ai 生态用户**：如果你已经在用 Z.ai 的其他产品（如 Z.ai Chat），ZCode 可以无缝衔接。

## 如何使用

### 环境准备

ZCode 要求以下基础环境（版本以仓库 `mise.toml` 为准）：

- Git
- Node.js **24.14.0+**
- pnpm **10.33.2+**

### 安装与启动

```bash
# 克隆仓库
git clone https://github.com/zai-org/ZCode.git
cd ZCode

# 初始化依赖（安装 workspace 依赖 + 准备桌面资源 + 构建）
pnpm bootstrap

# 启动桌面应用
pnpm dev:desktop

# 或使用测试数据目录
ZCODE_DATA_BASE_DIR="$HOME/.zcode-dev-home" pnpm dev:desktop:test

# 启动 Web 模式
pnpm dev:web
# 访问 http://localhost:5173
```

### CLI 模式

```bash
# 直接进入 TUI
zcode

# 启动 Web 界面
zcode --web

# 指定项目和端口
zcode --web --workspace /path/to/project --port 3030 --no-open
```

### 构建发行包

```bash
# 桌面版
pnpm bundle:desktop -- --os mac --arch arm64

# 命令行发行包（TUI + Web + Agent）
pnpm build:zcode --base-url https://your-cdn.com/zcode/
```
