# MaxUn：无代码 AI 数据采集平台，把任何网站变成结构化 API

**MaxUn**（getmaxun/maxun）是一款开源的无代码 Web 数据采集平台，由团队于 2023 年 10 月开源。它的核心理念非常直接：让任何人无需编写一行代码，就能从任意网站抓取、搜索和提取结构化数据，并将结果自动转换为 JSON、CSV 或 Markdown 等格式。

目前 MaxUn 在 GitHub 上已获得 **17,490+ 星标**，使用 TypeScript 编写，采用 AGPL-3.0 许可证开源，提供 Web 应用、Docker 自托管、SDK 和 CLI 多种使用方式。

## 核心功能

### 1. 五种自动化机器人类型

MaxUn 提供了五种不同用途的机器人，覆盖数据采集的全链路：

| 机器人类型 | 功能说明 |
|-----------|---------|
| **Extract（提取）** | 模拟真实用户行为，从网站捕获结构化数据 |
| **Scrape（抓取）** | 将整页转换为干净的 Markdown/HTML，可截图 |
| **Crawl（爬虫）** | 对整个网站进行深度爬取，自动发现并提取所有相关页面 |
| **Search（搜索）** | 自动化网页搜索，支持时间筛选和结果提取 |
| **Document Extraction（文档解析）** | 解析 PDF/DOCX/XLSX/JPG/PNG，支持 OCR 扫描文档 |

### 2. AI 驱动的自然语言提取

MaxUn 的 **AI Mode** 是其最大亮点——用户只需用自然语言描述想要提取什么，LLM 会自动理解网页结构并提取目标数据。例如输入"提取电影名称、评分和时长"，系统会自动分析 IMDb 页面并输出结构化 JSON。

同时提供 **Recorder Mode（录制模式）**：像录屏一样操作浏览器，MaxUn 会把你的每一步点击、滚动、输入都记录成可复用的提取机器人。

### 3. 文档与图像智能解析

除了网页数据，MaxUn 还支持文档提取——上传 PDF、Word、Excel、图片或扫描文档，系统通过 OCR 识别文字，并可将结果转换为 Markdown、HTML、JSON 或摘要。这让它同时具备文档 AI 处理能力。

### 4. 一键连接 Google Sheets 与 Airtable

提取的数据可以直接导出到 Google Sheets 或 Airtable，无需中间转换步骤。配合定时调度，可以设置"每天自动更新数据表"的工作流。

### 5. SDK + CLI + MCP 全面支持

对于开发者，MaxUn 提供完整的 **Node.js SDK** 和 **CLI 工具**，可以在代码中编程控制机器人创建、触发和结果获取。同时还支持 **MCP（Model Context Protocol）** 集成，让 AI Agent 也能直接调用 MaxUn 的数据能力。

## 如何使用

### 方式一：使用在线版（最快上手）

1. 访问 https://app.maxun.dev，注册账号
2. 点击"Create Robot"，选择 Extract 类型
3. 粘贴目标网址，选择 Recorder Mode 或 AI Mode
4. 录制操作或输入自然语言描述，点击"Run"
5. 预览提取结果，导出为 JSON/CSV 或同步到 Sheets

### 方式二：Docker 自托管（适合企业/隐私场景）

```bash
# 克隆仓库
git clone https://github.com/getmaxun/maxun.git
cd maxun

# 复制环境变量配置
cp .env.example .env
# 编辑 .env，设置必要的配置项

# 启动服务
docker compose up -d

# 访问 http://localhost:3000
```

详细步骤参考官方文档：https://docs.maxun.dev/installation/docker

### 方式三：SDK 编程调用

```typescript
import { MaxunClient } from '@maxun/sdk';

const client = new MaxunClient({ apiKey: 'your-api-key' });

// 创建提取机器人
const robot = await client.createRobot({
  name: 'price-monitor',
  type: 'extract',
  url: 'https://example.com/products',
  aiMode: true,
  instruction: 'Extract product name, price, and rating',
});

// 运行机器人并获取结果
const result = await robot.run();
console.log(result.data); // [{name: '...', price: '...', rating: '...'}]
```
