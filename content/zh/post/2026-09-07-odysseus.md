# odysseus — 自托管 AI 全能工作台，86K Stars 的私人 AI 枢纽

![odysseus](https://raw.githubusercontent.com/odysseus-dev/odysseus/main/assets/branding/odysseus-wordmark.png)

**odysseus** 是一个开源、自托管的 AI 工作空间平台，Stars 数已超过 86,900。它将聊天对话、AI Agent、深度研究、文档编辑、邮件管理、笔记任务、日历安排以及本地模型运行等多种能力整合进一个统一的 Web 界面中，让你把 AI 真正变成私人数字助手。项目使用 Python 构建，采用 Docker Compose 一键部署，License 为 AGPL-3.0。

## 核心功能

1. **Chat + Agents**：支持本地 API 模型和多种云端提供商，内置工具调用、MCP 集成、文件上传、Shell 命令执行、技能扩展和长期记忆系统，对话即服务。
2. **Deep Research（深度研究）**：多步骤自动网页研究，能够阅读来源内容并生成结构化报告，适合调研和分析任务。
3. **Compare（模型对比）**：盲测模式下并排对比不同模型的回答，辅助你做技术选型和模型评估。
4. **Cookbook（菜谱）**：硬件感知的模型推荐引擎，提供模型下载、量化选择和服务器部署的一站式指引，涵盖 NVIDIA/AMD GPU 和纯 CPU 场景。
5. **Documents（文档）**：类 Notion 的写作编辑器，支持 Markdown、HTML、CSV，内置 AI 编辑建议和语法高亮。
6. **Email（邮件）**：IMAP/SMTP 收件箱集成，支持邮件分拣、标签管理、AI 摘要、提醒和回复草稿，可对接 Google OAuth。
7. **Notes / Tasks / Calendar**：待办事项、提醒、定时 Agent 任务以及 CalDAV 日历同步，让 AI 真正融入日程管理。

## 适用人群

- **数据隐私优先者**：所有数据存储在本地，模型可以选择完全离线运行，无需担心数据泄露。
- **AI 多面手用户**：希望在一个界面里同时完成对话、研究、写文档、管邮件、排日程，不想在多个工具间切换。
- **本地模型爱好者**：想在自家机器上运行 Ollama、vLLM、LM Studio 等本地推理后端，并通过统一入口调用。
- **技术团队/个人开发者**：需要 Deep Research、RAG 知识库和 Agent 自动化来实现信息处理效率的质变。

## 如何使用

### 快速启动（Docker）

```bash
git clone https://github.com/odysseus-dev/odysseus.git
cd odysseus
cp .env.example .env
docker compose up -d --build
```

启动完成后，浏览器打开 `http://localhost:7000`，初始管理员密码会在 `docker compose logs odysseus` 输出中打印。

### 配置 LLM 后端

在 `.env` 中配置你的模型提供方：

```bash
# 使用 Ollama 本地模型
LLM_HOST=localhost
OLLAMA_BASE_URL=http://host.docker.internal:11434/v1

# 或使用 OpenAI 兼容 API
# OPENAI_API_KEY=sk-xxx
# LLM_HOST=https://api.openai.com
```

### 启用 GPU 推理（NVIDIA）

```bash
COMPOSE_FILE=docker-compose.yml:docker/gpu.nvidia.yml
```

确保主机已安装 `nvidia-container-toolkit`，并在容器内通过 Cookbook 安装 vLLM 或 llama-cpp-python。

### 启用 GPU 推理（AMD ROCm）

```bash
COMPOSE_FILE=docker-compose.yml:docker/gpu.amd.yml
RENDER_GID=$(getent group render | cut -d: -f3)
```

### 添加模型到 Cookbook

进入 Web UI → Cookbook → Dependencies，选择你的目标硬件（CPU / NVIDIA / AMD），按照引导安装推理后端和模型。首次启动会自动下载约 50MB 的 embedding 模型（all-MiniLM-L6-v2）。

### 开启搜索功能

Odysseus 内置 SearXNG 搜索引擎（Docker Compose 自动启动），无需额外配置即可在对话中使用网页搜索。也支持接入 DataBrave、Tavily、Serper 等第三方搜索 API。
