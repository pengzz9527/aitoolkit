# Fuxi — 终端里的自由 AI 编程助手，自带成本路由与多模型切换

在 AI 编程助手赛道上，Claude Code、Cursor、Aider 等工具已经相当成熟，但大多数产品都绑定特定模型或平台。今天介绍的 **Fuxi**（GitHub：[fuxicodex/Fuxi](https://github.com/fuxicodex/Fuxi)，⭐ 3316）走了一条不同的路：**模型无关、成本可控、全栈终端**。它用一个静态 Go 二进制文件，提供了一个 Think → Act → Verify 的完整编程代理循环，同时还支持通过 MCP 协议扩展工具链。

## 一句话简介

> Fuxi 是一个快速、自包含的终端 AI 编程代理，支持任意 OpenAI 兼容模型，自带成本感知路由、50+ 内置工具和细粒度安全沙箱。

## 核心功能

### 1. 多模型路由与成本优化
Fuxi 不绑定任何单一 LLM 厂商。你可以通过 `~/.fuxi/config.yaml` 配置多个提供商（OpenAI、Anthropic、Gemini、Bedrock/Vertex 等），并在 TUI 中用 `/model` 命令即时切换。更重要的是它支持**成本感知路由**——系统会根据任务复杂度自动选择性价比最优的模型，避免用 expensive 模型处理简单问题。

### 2. 50+ 内置开发工具
Fuxi 内置了完整的开发者工具集，涵盖：
- 文件操作：读取、写入、编辑（支持大文件高效处理）
- 终端执行：bash / PowerShell，带 AST 安全分类器
- 代码搜索：集成 ripgrep，支持全文/正则搜索
- 语言服务：LSP 诊断、Jupyter 笔记本交互
- 浏览器自动化：网页抓取、截图
- 并行子代理：多任务并发处理

### 3. 安全沙箱与权限控制
安全是 Fuxi 的重点设计。所有 shell 命令在执行前都会经过 **AST 安全分类器**，防止恶意命令。你可以通过 `/permissions` 精细控制哪些操作需要人工确认，也支持 `--auto` 模式让安全命令自动执行。审计日志完整记录每一次工具调用，方便事后审查。

### 4. 持久会话与记忆系统
每次会话 transcript 自动保存到磁盘，支持 `--resume` 恢复历史对话、checkpoint 回滚、以及 fork 分支实验。更有趣的是"梦想模式"——当代理空闲时会自动整理和压缩长期记忆，而长对话则通过自动 compact 机制节省 token 消耗。

### 5. MCP 协议与可扩展性
Fuxi 原生支持 MCP（Model Context Protocol），可以加载自定义 MCP 服务器来扩展工具能力。同时支持 hooks、skills、plugins 和斜杠命令，全部热加载，无需重启。

## 如何使用

### 安装

```bash
# macOS / Linux
curl -fsSL https://releases.fuxicode.com/bootstrap.sh | bash

# Windows (PowerShell)
irm https://releases.fuxicode.com/bootstrap.ps1 | iex
```

安装后验证：
```bash
fuxi --version
fuxi doctor    # 检查环境配置
```

### 配置模型

两种方式：

**方式一：OAuth 登录（推荐新手）**
```bash
fuxi login    # 浏览器授权，自动生成 FuXi 托管模型
```

**方式二：自带 API Key**
```bash
fuxi wizard   # 交互式向导，选择提供商、输入 base_url 和 api_key
```

或者手动编辑 `~/.fuxi/config.yaml`：
```yaml
provider: openapi
base_url: https://your-endpoint/v1
api_key: <your-key>
model: your-model
```

### 基本使用

启动 TUI：
```bash
fuxi
```

常用斜杠命令：
- `/model` — 切换当前模型
- `/status` — 查看提供商状态和成本
- `/context` — 查看上下文窗口使用情况
- `/cost` / `/usage` — 查看会话费用和计划用量
- `/commit` — 创建 git commit
- `/review` — 代码审查 / 生成 PR

### 命令行模式（适合 CI/脚本）

```bash
# 单次任务
fuxi --thinking enabled --prompt "修复 tests/ 下的失败用例"

# 恢复上次会话
fuxi --continue

# 指定工作目录
fuxi --dir /path/to/project
```

### 更新

```bash
fuxi update           # 更新到最新版（带 SHA-256 校验）
fuxi update 0.1.2     # 指定版本
```
