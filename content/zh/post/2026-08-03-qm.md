## 一句话介绍

**qm** 是由 Y Combinator 孵化的多人协作 AI 智能体平台，为团队中的每个成员提供独立的智能体工作空间，支持 Slack 和 Web 界面，让 AI 智能体从"个人助手"进化为"团队协作工具"。

---

## 它是什么？

大多数 AI 智能体工具都设计为个人助手——你有一个，我用一个，彼此独立。但真实工作场景中，团队协作需求往往被忽视。如果一个智能体能同时为整个公司工作，它很快会变得混乱。**qm 正是为了解决这个问题而生**。

qm（全名 "QuickMind"）由 Y Combinator 孵化的 yc-software 团队开发，于 2026 年 7 月 29 日发布，仅用 5 天便获得 **7,750+ Stars** 和 **817 Forks**，迅速登上 GitHub 趋势榜。项目采用 **MIT 许可证**开源，基于 TypeScript 开发，支持 Docker 部署。

---

## 核心功能

### 1. 个人与共享双重作用域

qm 的核心设计理念是**隔离与协作并存**：

- 每个成员拥有独立的工作空间，包括专属的记忆、文件、密钥链视图和权限
- 通过 Slack 频道、群聊和项目实现跨成员协作
- 每个人的智能体可以个性化定制，同时与他人协同工作

### 2. Slack 与 Web 统一体验

qm 同时支持两种交互方式：

- **Slack 集成**：团队成员在 Slack 中与智能体对话，获得一致的体验
- **Web UI**：提供更丰富的可视化界面，支持文件管理、Cron 任务、技能配置等

同一身份配置可在 Slack 和 Web 之间无缝切换。

### 3. 企业级管理控制

qm 提供了完整的管理员控制功能：

- 设置组织级配置、安全策略
- 管理可用的智能体框架和模型
- 控制谁可以使用哪些功能
- 部署自定义 Web 应用并发布给指定人员

### 4. 共享技能系统

技能（Skills）是 qm 的可复用组件：

- 技能拥有独立的作用域，可通过授权共享
- 管理员可将技能提升推广至整个组织
- 支持从 Git 仓库导入技能包
- 每个技能都有自己的权限和配置

### 5. 后台任务与调度

qm 支持无需实时监控的后台工作：

- **Cron 任务**：定时执行智能体工作
- **Watchers**：监听变化并自动触发
- 所有任务均有完整日志记录

### 6. 多框架支持

qm 的核心是通用的，支持多种智能体框架：

| 框架 | 支持方式 |
|------|----------|
| **Pi** | 原生 ACPC 协议 |
| **OpenCode** | 原生 ACPC 协议 |
| **OpenClaw** | 原生 ACPC 协议 |
| **Codex** | CLI + ACPC 协议 |
| **Claude Code** | CLI + ACPC 协议 |
| **Hermes** | CLI + ACPC 协议 |
| **CodeBuddy** | CLI + ACPC 协议 |

这意味着你可以灵活选择智能体引擎，而不被锁定在单一供应商。

## 如何使用 qm

### 方法一：快速部署

```bash
# 初始化部署目录
npm exec --yes -p @yc-software/qm@latest qm init . --org <your-org> --target fly-or-aws

# 安装依赖
npm install
```

### 方法二：本地开发

```bash
# 克隆仓库
git clone https://github.com/yc-software/qm.git
cd qm

# 配置环境变量
cp .env.example .env
# 编辑 .env 文件，配置数据库、认证等

# 启动服务
npm run dev
```

### 方法三：使用不同框架

```bash
# 使用 Pi 框架
export AGENT_PROTOCOL=pi

# 使用 OpenCode 框架
export AGENT_PROTOCOL=opencode

# 使用 OpenClaw 框架
export AGENT_PROTOCOL=openclaw

# 启动 qm
qm gateway start
```

### 典型使用场景

**场景 1：团队知识库检索**

1. 管理员配置组织级技能包，导入内部文档、数据库连接
2. 团队成员在 Slack 中向智能体提问
3. 智能体在隔离的沙箱中搜索内部资料，返回答案

**场景 2：自动代码审查**

1. 设置 Cron 任务，每 2 小时检查 GitHub PR
2. 智能体自动审查代码变更
3. 在 Slack 频道中发布审查报告

**场景 3：邮件处理助手**

1. 配置智能体学习你的写作风格
2. 定时检查收件箱，生成回复草稿
3. 在 Slack 中确认后发送

## 使用体验与建议

**优点**：
- ✅ 多框架支持，灵活选择智能体引擎
- ✅ 原生 Slack 集成，团队友好

- ⚠️ 需要配置 PostgreSQL 数据库
- ⚠️ 部分高级功能需要额外配置

**优化建议**：希望未来能提供更多预配置的组织模板，让非技术团队也能快速上手；同时加强中文社区建设。
