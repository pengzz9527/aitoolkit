# Mika 评测：安卓端侧 AI Agent，一句话操作 App 和网页，数据不出手机

**Mika**（wangzan101/Mika）是 2026 年 10 月 29 日开源的安卓端侧 AI Agent，采用 Kotlin 编写，以 Apache-2.0 许可证发布。它的核心理念是**"你手机上跑一个 AI Agent，替你看屏幕、点按钮、发消息、下单，全程数据不出手机"**。用户只需说一句话，Mika 就能在后台屏幕上操作任意 App 或网页，直到任务完成。

目前 Mika 在 GitHub 上已获得 **7,453 星标**，创建仅 10 天，增长速度在 AI Agent 领域极为罕见。

- **GitHub 星标**：7,453+
- **GitHub 仓库**：https://github.com/wangzan101/Mika
- **许可证**：Apache-2.0
- **语言**：Kotlin
- **最低要求**：Android 11（操作 App 需 Android 12+，推荐 Android 14+）
- **架构**：arm64（Linux 沙箱）

---

## 核心功能

### 1. 后台屏操作，不占你的屏幕

Mika 最大亮点是**在单独的后台屏幕上操作 App**，而不打断你正在使用手机。它像人一样看屏幕、找按钮、点击、输入、翻页，无需任何 App 开放 API 或事先适配。你在聊天界面看到任务进度，点开小画面即可实时观看操作过程，也可以随时关闭画面继续刷手机。

多任务并行时，后台屏会列出每个任务正在使用哪个 App、进行到哪一步；两个任务争抢同一个 App 时会自动排队，避免死锁。

### 2. 任意 App 和网页，无需预先集成

Mika 不需要目标 App 提供任何接口。它内置了一套**屏幕文字识别**（APK 内置 OCR）和**视觉模型**（可选，理解截图找按钮）的组合能力，理论上能操作任何装了 App 的安卓手机。内置使用知识库已覆盖微信、小红书、B站、知乎、抖音、BOSS直聘、闲鱼、Amazon、YouTube 等 40+ 个 App 和网站。

### 3. 内置桌面级浏览器，登录状态保留

Mika 自带一个**桌面模式的内置浏览器**，保持你在浏览器里的登录状态，能读取页面文本和数据、下载上传文件。页面加载有节奏控制（同站连续加载间隔递增），识别反爬虫拦截页并交由用户处理，避免被封锁。

### 4. 定时任务、条件触发、随时插话

你可以用自然语言设置定时和条件任务："每天早上 8 点查天气，下雨才告诉我"、"每周五检查订单状态"、"价格跌 50 以上提醒我"。任务执行完可以**随时插话补充要求**，长按消息撤回或修改还没被处理的指令；停止任务后它会汇报做到哪一步，说"继续"即可从断点恢复。

### 5. 每个对话一个 Linux 沙箱

每个对话拥有独立的 Linux 沙箱工作区（arm64 设备），可以运行 Python、Node 和 shell 命令，处理你发来的文件，结果存到手机 Download/Mika 目录。默认离线，需要联网时手动开启，也可配置代理。

## 适用人群

- **重度手机用户**：希望把重复操作（查天气、刷消息、下单）交给 AI，自己只管说一句话。
- **隐私敏感型用户**：不想数据经过第三方服务器，Mika 没有后端，所有数据只在你手机和自选的模型服务商之间流转。
- **安卓 14+ 用户**：后台屏有独立焦点，不干扰主屏操作，体验最佳。
- **喜欢终端/CLI 的高级用户**：可以通过 CLI + Skill 或 MCP 从电脑给手机上的 Mika 派任务，实现跨设备协作。
- **AI Agent 爱好者**：想体验端侧 Agent 的完整链路，Mika 是安卓上目前最完整的开源方案。

## 如何使用

### 第一步：安装

从 GitHub Releases 下载 APK：

```
https://github.com/wangzan101/Mika/releases/latest
```

安装到安卓 11+ 手机（推荐 Android 14+ arm64 设备）。

### 第二步：连接模型

打开 App，进入 **设置 › 模型**，有两种方式：

**方式 A：填 API Key（推荐，灵活）**

1. 选服务商预设（DeepSeek、通义千问、Kimi、智谱、Ollama、LM Studio、OpenAI、Anthropic、Gemini 等 20+ 家）
2. 填 API Key
3. 点"测试并保存"
4. 主模型必须支持 tool calling；可选配置视觉模型、轻量模型、语音识别模型

**方式 B：账号登录（免 Key）**

- ChatGPT（Plus/Pro 套餐）
- xAI / Grok（SuperGrok / X Premium+）
- OpenRouter（官方授权，生成专属 Key）

### 第三步（可选）：设置手机操作

如果要让 Mika 操作手机 App，需要：

1. 在 **设置 › 设置手机操作** 进入向导
2. 配对无线调试（一次性操作）
3. 部分手机系统没有无线调试选项，可以用电脑通过 USB 启动手机助手

配对成功后，Mika 会自动开启辅助功能权限，无需手动操作。

### 第四步：开始使用

直接说一句话试试：

- "帮我订明天早上 9:40 和 10:00 的闹钟"
- "总结一下我微信群里今天聊了啥"
- "每天早上 8 点查天气，下雨才告诉我"
- "帮我在这个招聘网站给 3 个岗位打招呼"
- "30 美元以内、4.5 星以上的充电器，加到购物车"

### 第五步（可选）：从电脑派任务

**CLI 方式：**

```bash
# 安装 CLI
# 连接手机（USB 或 Wi-Fi）
mika task submit "帮我查一下今天天气"
mika task status <task_id>
mika ui   # 在浏览器中打开任务面板
```

**MCP 方式：** 在电脑上配置 MCP 客户端，连接手机上的 Mika，通过 USB ADB 转发或 Wi-Fi 直连（需手动开启网络访问），支持 token 认证。

**让电脑 AI Agent 自动安装：** 手机 USB 连接电脑后，对电脑上的 AI Agent 说：

```
请按 https://github.com/wangzan101/Mika/blob/main/docs/install-with-agent.md 的步骤，帮我把 Mika 安装到通过 USB 连着的安卓手机上。
```

它会检查手机、下载安装、开启权限，全程只需你在手机上点几次确认。

## 安全与隐私说明

Mika 的隐私设计在同类工具中非常突出：

- **没有 Mika 服务器**：你的话、屏幕内容只发给你自己配置的模型服务商
- **API Key 和记忆加密存储在手机上**，不经过任何第三方
- **对话和运行记录只存在本机**，检查更新只访问 GitHub
- 付款、登录、验证码等敏感操作**必须由你亲自完成**，Mika 不会代为处理
- 内置浏览器可以导入其他浏览器的 Cookies 和 LocalStorage，获得对应登录状态，请自行判断风险

> ⚠️ 注意：自动操作第三方 App 和网站可能违反其用户协议，Mika 官方建议使用 Ask 模式（默认）并检查结果，重要操作不要切换到 Autonomous 模式。

## 总结

Mika 是 2026 年移动端 AI Agent 赛道中**最具差异化**的开源项目。它把"看屏幕找按钮"的 Computer Use 能力做到了安卓本地，数据完全不出手机，操作后台不占主屏，还支持从电脑远程派任务。10 天 7,400+ 星标证明了开发者社区对"端侧、隐私、开放"这一组合的强烈需求。

**扣分点：**
- Android 12-13 上后台操作可能影响主屏焦点，体验最佳需 Android 14+
- Linux 沙箱仅限 arm64 设备
- 自动操作第三方 App 存在合规风险，需用户自行判断
- 主模型必须支持 tool calling，部分国产模型兼容性需验证

**推荐指数：⭐⭐⭐⭐½（4.5/5）**

如果你有一台 Android 14+ 的 arm64 手机，想要一个隐私优先、可自托管、能操作任意 App 的 AI Agent，Mika 是目前开源选项中最完整、最值得关注的一个。
