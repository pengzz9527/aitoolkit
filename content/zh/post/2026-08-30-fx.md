# fx：Vercel Labs 出品的零依赖 Unix 风格编程代理

**一句话简介**：fx 是一款由 Vercel Labs 开发的轻量级编码代理 CLI，采用 Zig 语言编写，以 7.8MB 的极致体积和类 Unix Shell 的极简交互，重新定义了 AI 编程助手的形态。

## 核心功能

### 1. 极简的 Unix Shell 风格交互

fx 不同于传统 Coding Agent 的重型 TUI（终端用户界面），其设计风格更接近经典的 Unix Shell。输出清晰、响应迅速，命令式交互方式让开发者可以快速上手，没有学习成本。

### 2. 多模型无缝切换

fx 支持三种主流模型接入方式：

- **Vercel AI Gateway**：通过 `fx login` 直接登录，使用 Vercel 提供的统一模型路由
- **OpenAI Codex OAuth**：通过 `fx login codex` 利用 ChatGPT 订阅访问 Codex 模型
- **xAI Grok OAuth**：通过 `fx login grok` 使用 xAI 订阅访问 Grok 模型

支持 `/model` 命令切换模型，`/fast` 命令在支持的模型上启用优先服务层级。

### 3. 完整的工具链支持

fx 内置了完整的开发工具集，包括文件读写、代码执行、Git 操作、进程管理等。同时支持通过 MCP（Model Context Protocol）扩展工具能力：

```bash
fx mcp add NAME COMMAND [ARGS...]   # 添加本地 MCP 服务器
fx mcp add --transport http NAME URL  # 添加远程 HTTP MCP
```

### 4. 安全权限系统

fx 默认运行在 `auto` 权限模式下，常规的 understood 开发操作直接执行，每个未决议的操作会经过一次安全审查。支持配置持久化规则：

```bash
/permissions remember <allow|deny> <tool-name> <arguments-json>
```

### 5. 会话管理与远程嵌入

fx 支持会话保存与恢复，可以通过 `fx sessions` 列出历史会话，`fx session resume` 恢复指定会话。此外还支持 WebAssembly 嵌入模式，可以集成到更大的系统中：

```bash
fx acp                    # 通过 Agent Client Protocol 连接编辑器
createFxAgent()           # JavaScript 宿主环境嵌入
```

## 如何使用

### 安装

```bash
curl -fsSL https://fx.sh/setup.sh | bash
```

### 快速开始

```bash
# 登录 Vercel AI Gateway
fx login

# 进入项目目录启动
cd your_project
fx
```

### 单任务执行

```bash
# 单次请求，适合脚本集成
fx ask "explain the changes in this repository"

# JSON 格式输出
fx ask --json "refactor the auth module to use JWT"
```

### 会话管理

```bash
# 列出所有会话
fx sessions

# 恢复最近会话
fx session resume last

# 恢复指定会话
fx session resume --id <session-id>
```

### 模型切换

```bash
# 登录不同提供商
fx login codex
fx login grok

# 在 fx 内切换
/setup    # 选择 Model provider
/model   # 查看可用模型
/fast    # 启用快速模式（需要对应订阅）
```

### MCP 扩展

```bash
# 添加本地 MCP 服务器
fx mcp add myserver /path/to/server

# 添加远程 HTTP MCP
fx mcp add --transport http myserver https://example.com/mcp

# 信任并连接
fx mcp trust approve myserver
```
