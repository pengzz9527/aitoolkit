# MiniMind 评测：2 小时、3 块钱，从 0 训出你的 64M 大模型——GitHub 6.7 万星的极简 LLM 全链路

**MiniMind** 是一个国产开源项目，一句话定位：**让任何有一张显卡的人，从 0 开始完整走一遍大模型训练全流程**。官方口号很直白——「两小时从 0 训出你的 64M 大模型，成本约 3 元人民币」。它不只是给一个模型权重，而是把**大模型的极简结构 + 完整训练链路**全部开源：数据清洗、预训练（Pretrain）、监督微调（SFT）、LoRA、直接偏好对齐（DPO）、RLAIF（PPO / GRPO / CISPO）、MoE 共享专家、Agentic RL、工具调用、模型蒸馏，一套代码串到底。

对大多数人来说，「学 LLM」的上限就是给别人的大模型做 LoRA 微调。MiniMind 的态度是：这就像教牛顿用智能手机——绕开了理解本质的初衷。你要想真正搞懂「大模型是怎么炼成的」，从 64M 这个量级从零起步是性价比最高的路径。

- **GitHub 星标**：67,500+（2026-11-22 当日 GitHub Trending 在榜）
- **GitHub 仓库**：https://github.com/jingyaogong/minimind
- **许可证**：Apache-2.0，2024-07 创建，由国内开发者 jingyaogong（Gong Jinyao）主导
- **最新主线**：`minimind-3`（64M Dense）与 `minimind-3-moe`（198M-A64M，4 专家 top-1），2026-04-01 发布
- **训练门槛**：单卡 3090（租用价约 1.3 元/小时），mini 数据集组合预训练 + SFT 全程约 2.3 小时、约 3 元
- **词表设计**：自研 6,400 词 tokenizer，压缩 embedding 层参数占比（对比 Qwen2 15 万词、Llama3 12.8 万词）

## 核心功能

### 1. 完整训练链路开源：从数据清洗到 RLAIF 一条龙

这是 MiniMind 和「nanoGPT 跑个 125M 预训练」类教程最大的区别。它覆盖的环节包括：

| 环节 | 说明 |
|---|---|
| 数据清洗 | 提供清洗后的 `pretrain_t2t` / `sft_t2t` 系列 JSONL 数据集（ModelScope / HuggingFace 双通道下载） |
| 预训练 | 无监督 next-token 训练，mini 组合约 1.2 小时 |
| SFT | 指令微调，SFT 数据已混入 Tool Call 数据，通常无需再单独做工具调用微调 |
| LoRA | 轻量参数高效微调，附 exam 对齐示例（ceval/mmlu 格式增强） |
| DPO / RLAIF | 直接偏好优化 + PPO / GRPO / CISPO 多种 RL 对齐，训练侧与 rollout 侧解耦设计 |
| Agentic RL | 工具执行、多轮 rollout、延迟奖励的最小串联实现 |
| 蒸馏 | 大模型知识向 64M 小模型的蒸馏方案 |
| 模型族 | MiniMind-V（视觉 VLM）、MiniMind-O（全模态）、dLM（离散扩散）、Linear Attention 实验线 |

### 2. 模型结构对齐 Qwen3 生态，训完就能用

`minimind-3` 采用 Transformer Decoder-Only 结构：Pre-Norm + RMSNorm、SwiGLU 激活、RoPE 旋转位置编码（支持 YaRN 长度外推）、q_heads=8 / kv_heads=4、最大位置 32,768。整体配置刻意对齐 Qwen3 / Qwen3-MoE，意味着训出来的权重**可以直接转成 transformers / llama.cpp / Ollama / vLLM 格式**，也能导出 MNN 4-bit 量化跑在 Mac 和手机上。学完不是只留在 notebook 里，而是真正能部署、能推理、能接进工程。

### 3. 2 小时 3 元的全流程成本（单卡 3090）

以 3090 租卡约 1.3 元/小时计（作者官方估算）：

| 阶段 | 耗时 | 成本 |
|---|---|---|
| pretrain（mini 1.2GB） | ≈1.21h | ≈1.57 元 |
| SFT（mini 1.6GB） | ≈1.10h | ≈1.43 元 |
| Tool Call 微调 | ≈0.9h | ≈1.17 元 |
| RLAIF | ≈1.1h | ≈1.43 元 |

也就是说，一个周末、一杯咖啡的钱，可以从 0 得到一个能对话、会用工具的 64M 模型。换 8×H100 可以把总时长压到分钟级——项目同时照顾「穷人复现」和「正经研究」两个场景。

### 4. 64M 的基准表现：不靠堆参数，靠结构取舍

64M 是什么概念？约等于 GPT-3（175B）的 1/2700。参考官方基准（中文 C-Eval / CMMLU，英文 ARC / PIQA / OBQA / HellaSwag / SIQA）：

| 模型 | 参数量 | 中文 | 英文 |
|---|---|---|---|
| minimind-3 | 64M | 24.89 / 25.38 | 28.49 / 50.65 / 23.60 / 28.28 / 34.19 |
| gpt2-medium | 360M | 23.18 / 25.00 | 43.60 / 66.38 / 30.20 / 39.38 / 39.10 |
| SmolLM2-135M | 135M | 24.44 / 24.71 | 58.50 / 68.17 / 32.80 / 43.15 / 39.46 |
| Steel-LLM | 1121M | 24.89 / 25.32 | 39.69 / 65.13 / 26.00 / 35.73 / 39.15 |

64M 模型在中文常识基准上打平 1121M 的 Steel-LLM（C-Eval），英文上接近 360M 的 GPT-2 系列——当然绝对分数都不高，但这是 64M 的物理极限，重点在于**你在自家 GPU 上完整复现了它**。

### 5. 全生态多模态衍生线

主线之外，项目同时维护 MiniMind-V（视觉多模态）、MiniMind-O（全模态）、MiniMind-dLM（离散扩散语言模型）与 Linear Attention 版本，均可基于主线 AR 模型续训。想从「会聊天」升级到「看图说话」，不用换框架，同一套代码体系走到底。

## 如何使用（具体步骤）

### 方式 A：先推理体验（0 成本）

```bash
# 1. 克隆仓库、装依赖
git clone --depth 1 https://github.com/jingyaogong/minimind
cd minimind && pip install -r requirements.txt

# 2. 下载现成的 minimind-3（64M）
modelscope download --model gongjy/minimind-3 --local_dir ./minimind-3

# 3. CLI 对话
python eval_llm.py --load_from ./minimind-3

# 4.（可选）接 Ollama / vLLM
ollama run jingyaogong/minimind-3
vllm serve ./minimind-3 --model-impl transformers --served-model-name "minimind"
```

### 方式 B：从 0 训练（单卡 3090，约 3 元）

```bash
# 1. 下载 mini 数据集（共约 2.8GB）放到 ./dataset/
#    pretrain_t2t_mini.jsonl (1.2GB) + sft_t2t_mini.jsonl (1.6GB)
#    来源：ModelScope gongjy/minimind_dataset 或 HuggingFace jingyaogong/minimind_dataset

# 2. 预训练
python model_pretrain.py

# 3. 监督微调
python model_sft.py

# 4.（可选）DPO / RLAIF 对齐
python model_rlhf.py
```

训练完成后 `./out` 目录下生成权重，`eval_llm.py --load_from ./model --weight full_sft` 即可对话；想部署就把 PyTorch 权重转成 transformers 格式喂给 Ollama / vLLM / llama.cpp。想上 MoE 版本，把模型配置切到 `minimind-3-moe`（198M-A64M）再走一遍同样流程即可。

## 总结

MiniMind 抓住了 LLM 学习领域一个很真实的痛点：**「理解大模型」和「玩大模型」之间差着一个从 0 训练的完整闭环**，而这个闭环过去只属于有大算力的人。它把门槛打到 3 块钱、2 小时，代码质量在线（结构对齐 Qwen3、支持 YaRN 外推、训推解耦的 RL 设计、MNN 端侧导出），生态延伸（V/O/dLM/Linear）也给了进阶路线。67,000 星不是白来的——它是目前中文社区里最完整的「小模型全链路」开源项目。

短板同样明确：64M 模型的绝对能力有限（常识基准 25 分档），别指望它当客服；mini 数据集 2.8GB 决定了上限；自研 6,400 词 tokenizer 的中文编解码效率弱于 Qwen2 / GLM 词表，做严肃中文任务前要有心理预期。

**推荐指数：⭐⭐⭐⭐☆（4.5/5）** —— 学习 LLM 原理与训练工程的最佳起点之一；作为生产力工具则建议直接上更大的开源模型。如果你今年还没从 0 训过一个模型，MiniMind 是目前最划算的入口。
