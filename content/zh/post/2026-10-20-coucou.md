# Coucou 评测：Mac 灵动岛里的 Mochi 小助手，让 AI 编程 agent 的批准和进度直接跳到你眼前

Claude Code 跑到一半需要授权，Codex 要跑一条命令问你，你正在另一个终端窗口里改别的东西——回头一看，agent 已经卡了五分钟等你点「允许」。这种「agent 在后台跑，人却盯着终端数行等待」的处境，是大多数 AI 编程用户每天都在重复的摩擦。

**Coucou** 就是把这种摩擦消灭掉的小工具：它把一只叫 **Mochi** 的灵动岛小角色贴在 Mac 屏幕顶部，实时跟踪你本机跑的 9 种 AI 编程 agent（Claude Code、Codex、Cursor、Gemini CLI、Antigravity、Copilot CLI、Muse Code、OpenCode、Amp / Hermes），每一步文件修改、命令执行、权限请求都直接弹到灵动岛上——你在 IDE 里、在别的终端里、甚至锁屏后离开电脑了，Mochi 都会跳出来提醒你，一键 Allow / Deny 即可，全程不用切回终端。项目 2026 年 9 月底开源，MIT 协议，一个月冲到 **5600+ 星标**，更新频率极高（两周 30+ 个版本），迭代方向从「agent 监控」迅速扩展到了全系统级的「生活伴侣 + 语音输入 + 通话记录」，覆盖 macOS / Windows / Linux / iPhone / Android 五个平台。

## 工具简介

**Coucou** 是一个跨平台的 AI agent 监控伴侣应用，核心目标是「不离开当前工作界面，也能批准 agent 的操作、看进度、问问题」。灵动岛里的小角色 Mochi 是整个交互的中心：

- **GitHub**: https://github.com/Louis-CFM/coucou
- **语言**: Swift 6（macOS/iOS 原生）+ Tauri 2 / Rust（Windows/Linux）+ Kotlin / Jetpack Compose（Android）
- **开源协议**: MIT（代码）；Mochi 角色与声音素材 © Louis Raillé
- **平台**: macOS 15+、Windows 10/11、Linux（AppImage / deb / rpm）、iOS 18+、Android 11+
- **定位**: 本地 AI agent 会话监控 + 权限管理 + 轻量生活工具（语音输入、通话记录、服务集成），不是聊天机器人或代码编辑器

## 核心功能

1. **多 agent 会话实时跟踪**：同时连接 Claude Code、Codex、Cursor、Gemini CLI、Antigravity、Copilot CLI、Muse Code、OpenCode、Amp / Hermes 共 9 种 agent，每一步文件修改显示文件名与 +N −M 行数变更，点击查看完整 diff；agent 完成时 Mochi 做一个小跳跃庆祝。未连接任何 agent 时灵动岛自动隐藏，hover 才探出头。

2. **灵动岛权限批准**：Claude Code / Codex 的权限请求（Allow / Deny / Always）直接出现在灵动岛卡片里；`AskUserQuestion` 多选提问（最多 4 题）也在岛上作答，不用切终端。若 Coucou 没在运行，hook 直接退出，agent 永不被阻塞。

3. **多模型聊天**：在灵动岛内置聊天框里直接和 Claude、Gemini、OpenAI、DeepSeek、Qwen、Moonshot 或本地模型（Ollama / LM Studio）对话，点击模型名切换提供商；支持语音输入（麦克风识别，本地运行）。

4. **iPhone / Android 远程批准**：Mac 锁屏后 Mochi 跟随到 iPhone 的锁屏和灵动岛，支持 Face ID / 指纹解锁批准；Android 手机通过局域网（Wi-Fi + 配对证书）连接 Windows/Linux 版的 Coucou，解锁指纹批准，agent 会话和聊天同步到手机。

5. **系统级附加功能（0.4+）**：全局语音输入（长按右 Option 键说话，自动粘贴到任意应用）；NVIDIA Parakeet 离线识别（25 语言，Apple Silicon）；通话记录器（录麦克风 + Mac 音频，无 bot 进会议，生成逐人转录 + 摘要 + 待办，音频自动删除）；GitHub / Vercel / Stripe / n8n / Notion / Resend / Cal.com 服务集成（各有一个独立颜色的 Mochi）；加密货币组合追踪（16 网络 + 5 交易所）；Apple Music / Spotify 播放控制；每周工作总结（周一早晨自动生成 1080×1920 分享图）；WhatsApp 消息集成（实验性，通过本地 GOWA 网关）；OK Coucou 语音助手（说「OK Coucou，播放 Daft Punk」，Claude 驱动）。

## 适用人群

- 重度使用 Claude Code / Codex / Cursor 等 AI 编程 agent、希望「不切终端也能批准」的开发者
- 多 agent 并行（同时跑 Claude Code + Codex + Cursor）想集中监控进度的团队或个人
- 想在锁屏或离开电脑时通过手机管理 agent 会话的远程办公者（iPhone TestFlight 免费 / Android APK 直接安装）
- 对语音输入、通话记录、服务集成等「生活伴侣」功能感兴趣，但又不想装一堆独立 app 的 Mac / Windows 用户
- **不适合**：只用 Linux 且只关心 agent 监控（Linux 版功能略滞后于 macOS 版）；对「角色形象」有强烈偏好但不喜欢 Mochi 设计的（角色可换装，但基础造型固定）；没有 macOS 15+ / iOS 18+ 且不想跑 Windows 版的人

## 与同类工具对比

| 工具 | 定位 | 优势 | 局限 |
| --- | --- | --- | --- |
| **Coucou** | 多平台 AI agent 监控伴侣 + 生活工具 | 9 种 agent 同屏跟踪、灵动岛 / 锁屏 / 指纹批准、多模型聊天、语音输入、通话记录、服务集成、全开源 MIT | iPhone 版仍在 TestFlight（App Store 待上架）；角色造型固定；部分高级功能仅限 macOS GitHub 版 |

| **Cursor / Codex 桌面通知** | IDE 内权限弹窗 | 集成在 IDE 内 | 只覆盖自家 agent，不支持跨 agent 统一视图 |
| **Terminal.app 通知** | 系统级终端提示 | 原生、轻量 | 无 diff 预览、无多模型聊天、无手机同步 |

一句话：**只要同时跑 2 个以上 AI 编程 agent，或经常锁屏离开电脑，Coucou 是目前最完整的「不切终端」方案，且完全免费开源；只跑单个 agent 且一直盯着终端的话，终端内通知就够了。**

## 如何使用（具体步骤）

**1. 安装 Coucou**

```bash
# macOS（Homebrew）
brew tap louis-cfm/coucou https://github.com/Louis-CFM/coucou
brew install --cask coucou

# macOS（手动）
# 从 GitHub Releases 下载 Coucou.zip，解压后拖到 /Applications
# 首次启动时 macOS 可能要求允许 Coucou 访问已保存的 key，输密码选 Always Allow

# Windows
# 下载 Coucou-Windows-setup.exe，运行时 SmartScreen 会警告（无代码签名）
# 点 More info → Run anyway

# Linux
# 下载 Coucou-Linux-x86_64.AppImage
chmod +x Coucou-Linux-x86_64.AppImage
./Coucou-Linux-x86_64.AppImage

# 或 Debian/Ubuntu
sudo apt install ./Coucou-Linux-x86_64-amd64.deb
```

**2. 连接 Claude Code**

```bash
# 打开 Coucou（macOS：Dock 或菜单栏；Windows/Linux：系统托盘）
# Settings → Claude Code → Install hooks
# Coucou 会备份 ~/.claude/settings.json，合并 hooks，展示 diff 后写入
# 若 Claude Code 已在运行，重启一次使 hooks 生效
```

**3. 连接其他 agent（按需）**

```bash
# Settings → Gemini CLI → Install hooks（备份 ~/.gemini/settings.json）
# Settings → Antigravity → Install hooks（备份 ~/.gemini/config/hooks.json）
# Settings → Codex → Install hooks
# OpenCode / Amp / Hermes → 对应 Plugin 安装
```

**4. 配置 AI 聊天（可选）**

```bash
# Settings → Chat
# 填入 Anthropic / OpenAI / Google AI API key（存入系统 Keychain / Credential Manager）
# 或连接本地 Ollama / LM Studio（Settings → Chat → Local models → Connect）
```

**5. 连接 iPhone（macOS + iOS 18+）**

```bash
# 1. iPhone 上安装 TestFlight（App Store 免费），然后加入：
#    https://testflight.apple.com/join/3GpeHv2b
# 2. Mac 上 Coucou → Settings → General → iPhone
#    开启 Show my agent sessions on my iPhone
#    开启 Move Mochi to my iPhone's Dynamic Island when my Mac is locked
# 3. Mac 和 iPhone 使用同一 Apple ID（iCloud）
# 4. 打开 iPhone 上的 Coucou，允许通知
# 5. Mac 锁屏后 Mochi 自动出现在 iPhone 锁屏和灵动岛
```

**6. 连接 Android（Windows/Linux + Android 11+）**

```bash
# 1. 手机上从 Releases 下载 Coucou-Android-0.2.0.apk 并安装
# 2. 电脑上 Coucou 0.4.0+ → Settings → Android phone → 开启 Phone link
# 3. 显示配对码，手机扫码（电脑和手机须在同一 Wi-Fi）
# 4. 手机上的 Allow 需要指纹或屏幕锁，Deny 不需要
```

**7. 启用语音输入（macOS，0.4+）**

```bash
# Coucou → Flow → Settings
# 选择按键（默认右 Option，也可选 fn / 右 Command / 右 Control）
# 授予 Accessibility 和 Microphone 权限
# 可选：下载 Parakeet（约 650 MB，Apple Silicon）实现离线 25 语言识别
# 长按按键说话，松手自动粘贴到当前光标位置；双快速点按可免手操作；Esc 取消
```

**8. 启用通话记录器（macOS，0.4+）**

```bash
# 屏幕底部（或侧边）的透明小药丸（pill）→ hover 出工具栏 → 点击 Record a call
# 录制麦克风和 Mac 播放音频，无 bot 进会议
# 通话结束：逐人转录 + 摘要 + 要点 + 待办，由 Claude（你的 API key）或 Apple Intelligence 生成
# 音频在转录完成后自动删除
```

**小贴士**：
- 灵动岛默认空闲时完全隐藏，hover 顶部边缘（Windows/Linux）或 Mac 刘海处才探出 Mochi
- 拖文件到灵动岛上，Mochi 变成盒子吞掉它，然后可以针对该文件提问或发邮件
- 把 Mochi 拖到桌面（120pt 浮动角色）或拖到任意窗口上作为 Claude 上下文
- 每周 Monday 早晨自动生成上周工作总结（编码时长、会话数、文件变更、最活跃 agent），可导出 1080×1920 图片
- 14 种语言界面（含简体中文 / 繁体中文），Settings → General → Language 切换
- 所有 key 存系统级密钥管理（Keychain / Credential Manager / Secret Service），无遥测，无账号

## 总结与推荐指数

Coucou 解决的是一个很具体的痛点：AI 编程 agent 越来越多、越来越强，但它们的权限模型还是「终端里等人点按钮」。Coucou 把这个等待环节从终端里抽出来，放在了一个你随时能看到、能操作的视觉中心——灵动岛 / 锁屏 / 指纹屏——并且顺手把多 agent 并行、多模型聊天、服务集成、语音输入这些「开发者日常」也整合进来，还做出了一个有性格的角色（Mochi 会眨眼、会生气、会跳舞），让「等待 agent」这件事从枯燥的盯终端变成了「看一眼 Mochi」的轻交互。

5600+ 星标、两周 30+ 个版本、五平台同步迭代、MIT 协议全开源，让它在同类「agent 监控」工具里几乎是唯一同时覆盖了 Mac / Windows / Linux / iPhone / Android 的项目。唯一的门槛是：iPhone 版还在 TestFlight（免费，上限 1 万人），App Store 正式版还在 Apple 审核中；Windows 版没有代码签名，首次安装需要点「仍然运行」。

- 适合：多 agent 并行开发者、锁屏后仍需批准 agent 的远程办公者、喜欢 Mochi 这类有性格桌面伴侣的用户
- 不适合：只跑单个 agent 且始终盯着终端的人；需要 iPhone App Store 正式版的用户（目前用 TestFlight 版）

**推荐指数：⭐⭐⭐⭐（4.0 / 5）**
