# AutoClip 评测：开源「一个链接一键出片」桌面工具，本机量产抖音、小红书与 Shorts 切片

**AutoClip** 是一个开源（MIT）的 AI 视频剪辑桌面工具，一句话定位：**“一个链接，一键出片”**。你贴一个播客、访谈、课程或 YouTube/B 站长视频链接，选好要发的平台，它在本机自动挑出值得发的片段、完成剪辑与渲染，直接产出**视频 + 封面 + 标题 + 简介 + 话题 + ZIP 发布包**——抖音、小红书、TikTok、Reels、YouTube Shorts、B 站、YouTube 一套全齐。软件本身免费，分析模型自选：云端按量计费，或 Ollama / LM Studio 全本地跑。

它 2025 年 7 月创建，已经冲到 **10,800+ 星标**（Fork 1,900+，19 个正式 release，当前 1.5.8），今天还在 GitHub Trending 榜上。在「长视频转短视频」这个赛道里，它是少数同时做到**开源 + 本地渲染 + 中文平台模板 + 桌面/CLI/MCP 三形态**的项目。

- **GitHub 星标**：10,874（Trending 在榜）
- **GitHub 仓库**：https://github.com/zhouxiaoka/autoclip
- **官网**：https://zhouxiaoka.github.io/autoclip_intro/
- **许可证**：MIT
- **技术栈**：Tauri（桌面壳）+ React + FastAPI（Python 后端）+ FFmpeg；依赖 yt-dlp、Whisper、FunASR
- **创建时间**：2025-07-08，19 个 release（当前 1.5.8）
- **运行要求（桌面版）**：macOS Apple Silicon（`.dmg`）或 Windows 10/11 x64（`-setup.exe`），安装包自带 Python 与 FFmpeg，无需预装；Intel Mac 与 Linux 走 Docker / CLI

## 核心功能

### 1. 贴链接就出片：平台规则内置，每个平台先出 10 条

选好目标平台后，工具按**该平台的画幅与时长规则**自动挑片：长视频先筛出 20–40 个候选片段，按评分自动生成至多 10 条合格成片，其余列为「备选」，点「生成这条」再制作——省时间也省模型费用。每条成片自带封面、标题、简介、话题标签和 ZIP 发布包，复制的文案不带 AutoClip 署名。B 站 / YouTube 出横版，竖版平台出竖版，外语素材可自动配中文字幕。

### 2. 成片自己会包装：访谈式 / 满屏播客式两种版式

抖音、小红书默认「访谈式」竖版；TikTok、Reels、Shorts 默认「满屏播客式」，竖版也可自行切换。画面会**跟随说话人**取景，无人镜头保留完整画面；自动品牌片尾（1.8 秒标志动画）默认开启、可在设置关闭。你不用进时间线拖帧，包装已经完成；想微调时再进编辑器。

### 3. 剪辑渲染全在本机，模型自选

这是它和订阅制云切片工具最大的区别：挑片分析可接 Qwen、DeepSeek、GPT、Gemini 等云端 API（OpenAI 兼容接口填 Base URL 即可），也可接 **Ollama / LM Studio 本地模型**（无需 API Key）；字幕可用作者自带 SRT（最快）、本地 Whisper / SenseVoice，或百炼云端转写（约 0.1 元/小时音频）。全本地配置下**视频不离开你的电脑**。匿名统计与错误报告可在设置关闭。

### 4. 成本透明：一小时视频出 10 条切片，文字模型几分钱

作者公布的实测（2026-10-01，Apple Silicon Mac）：

| 场景 | 原片 | 出片耗时 | 文字模型费用估算（qwen-plus） |
|---|---|---|---|
| 有字幕 | Jensen · 1h43m（英 → 小红书） | 7.5 分钟 / 10 条 | **¥0.09** |
| 无字幕（本地 Whisper） | TIM × 罗永浩 · 2h52m（中 → 抖音） | 29.5 分钟 / 10 条 | ¥0.20 |
| 旧链路 | MrBeast · 2h06m（英 → TikTok） | 65 分钟 | ¥0.64 |

挑片算法从「上百次模型调用」改成「一次通读全文 + 并行执行」后，新版速度提升明显。

### 5. 桌面、Docker、CLI / MCP 三种形态共用同一条链路

- **桌面版**：给创作者，双开即用的 Studio 编辑器；
- **Docker**：自建 Web 服务，跑在服务器或 NAS 上（`docker compose up -d --build`，含 FastAPI + Web 界面 + API 文档）；
- **CLI / MCP**：`autoclip produce talk.mp4 --platform douyin --json` 批量出片，MCP 入口（`start_quick_output` / `get_quick_output_status`）让 Claude Code、Cursor、OpenCode 等 Agent 直接调用同一条出片流程——CLI 出的项目，桌面端首页直接可见。

## 适用人群

- **播客、访谈、课程、口播类创作者**：主要验证场景就是这类素材，一条长片一天多平台分发，替代过去「剪映拖一下午 + 写文案」；
- **多平台分发 / 出海创作者**：中文平台（抖音、小红书、B 站）专属模板 + 外语素材自动配中文字幕 + TikTok/Reels/Shorts 满屏版式，一套素材全渠道吃；
- **隐私敏感团队 / 个人**：剪辑与渲染在本机，全本地模型 + 本地转写时零上传；
- **Agent 工作流 / 自动化爱好者**：MCP + CLI 把「出片」变成一条可脚本化的管道，批量跑、接流水线。

**不太适合：**

- **需要逐帧精剪、复杂多轨特效的成片**：它是「一键出片」流水线，编辑器用于微调而非专业剪辑；
- **游戏录屏、口播少的素材**：需要自行配置多模态模型启用画面识别，且仍要人工检查选段；
- **不想配置任何 API Key 的用户**：示例项目可以不配 Key 体验，但真实素材分析要么配云端 Key，要么本地 Ollama / LM Studio 硬件达标；
- **Intel Mac / Linux 桌面用户**：没有安装包，走 Docker 或 CLI。

## 与同类工具对比

| 维度 | AutoClip | Opus Clip（云 SaaS） | 剪映 AI 智能成片 | 对话式 Agent 切片 |
|------|----------|---------------------|-----------------|------------------|
| 出品方 | 个人开源（MIT） | Opus（闭源订阅） | 字节（闭源） | 自建 / 第三方 |
| 处理位置 | **本机剪辑渲染，模型自选** | 云端 | 云端 + 本地 | 取决于实现 |
| 中文平台 | **抖音/小红书/B 站模板 + 自动中文字幕** | 以 YouTube/TikTok 为主 | 抖音/小红书模板 | 需自己搭 |
| 产出 | **视频 + 封面 + 文案 + ZIP 发布包** | 视频 + 文案 | 视频 + 模板包装 | 取决于 prompt |
| 费用 | **软件免费，模型按量（实测几分钱/10 条）** | 订阅制 | 基础免费 + 会员 | 模型调用费 |
| 自动化 | **CLI + MCP 接 Agent** | API 受限 | 无 | 灵活但易跑偏 |
| 数据 | **可全本地离线** | 视频上传云端 | 部分上传 | 取决于实现 |

结论：**AutoClip 切的是「开源 + 本地 + 中文平台」这块地**——Opus Clip 胜在省心但闭源、订阅、偏海外平台；剪映强在人工精修生态，但自动化「一键多平台发布包」不是它的定位；纯对话式 Agent 切片则经常要反复纠正需求。AutoClip 把挑片、取景、包装、发布包做成确定性流水线，且代码可读可改、费用可控。短板是个人维护项目，没有即时客服，选片质量仍与所选模型能力挂钩。

> ⚠️ 三个要留意的点：
> 1. **安装包未公证 / 未签名**：macOS 15+ 需在「系统设置 → 隐私与安全性」放行，Windows 会在 SmartScreen 提示「仍要运行」；
> 2. **云端模式有上传边界**：云端分析发送字幕与文案、画面理解发送抽样帧、云端转写发送音频——全本地模式则无对应上传，介意隐私就选 Ollama + 本地 Whisper；
> 3. **选片质量看模型**：片段选得不好时官方建议换更强的模型重试，项目方在置顶 issue 收集坏例持续改进。

## 如何使用

### 第一步：安装桌面版

在 [Releases](https://github.com/zhouxiaoka/autoclip/releases/latest) 下载：macOS Apple Silicon 选 `.dmg`，Windows 10/11 x64 选 `-setup.exe`。安装包**自带 Python 与 FFmpeg**，无需预装。macOS 15+ 首次打开被拦截时，到「系统设置 → 隐私与安全性 → 仍要打开」；Windows 在 SmartScreen 点「更多信息 → 仍要运行」。

### 第二步：配置模型

在设置里选择服务商、填写 API Key，测试连接并保存；想用本地模型则先启动 Ollama（默认 `http://localhost:11434/v1`）或 LM Studio（默认 `http://localhost:1234/v1`）并加载模型——无需 Key。没有字幕的视频第一次会下载约 220 MB 的本地转写组件（国内网络约 15 分钟），装不上就切百炼云端转写（音频上云）。

### 第三步：先跑示例项目

首页点「用示例项目看看效果」——示例内置在安装包里，**不需要 API Key**，跑一遍看产出质量再上自己的素材。

### 第四步：贴链接，一键出片

贴 YouTube / B 站链接（yt-dlp 下载）或本地文件 → 选平台（可多平台追加）→ 选竖版版式 → 按「生成」。每个平台自动出评分最高的 10 条成片，备选片段按需生成。

### 第五步：检查、导出或投稿

预览成片，检查字幕、取景与内容完整性，然后下载 ZIP 发布包（视频 + 封面 + 文案），或连接 B 站 / YouTube 账号直接投稿。

### 想用 CLI / MCP 接 Agent？

```bash
# 一行安装 MCP（或从 Releases 下载 CLI/MCP ZIP）
uvx autoclip-mcp
npx skills add zhouxiaoka/autoclip

# 批量出片：已有字幕可 --srt 跳过转写
autoclip produce talk.mp4 --srt talk.srt --platform douyin --portrait-style podcast --json
autoclip outputs PROJECT_ID --export-kits

# 接入 MCP 客户端（以 OpenCode 为例）
autoclip mcp install opencode
```

CLI 与桌面共用同一条出片链路和同一个数据目录，`--json` 输出直接给脚本和流水线。

## 总结

AutoClip 把「长视频 → 多平台可发布切片」这件过去要花一下午的活压到一次点击：平台画幅时长规则内置、封面文案自动打包、剪辑渲染全在本机、模型可云可本地，费用按 qwen-plus 实测一小时素材出 10 条只要几分钱。MIT 开源 + 桌面/Docker/CLI/MCP 四形态，既服务内容创作者，也方便 Agent 自动化爱好者把「出片」变成管道的一环。对国内创作者，**抖音/小红书/B 站模板 + 外语素材自动中文字幕**是最实际的卖点。

**扣分点：**

- **个人维护项目**：作者明说「不提供即时客服或一对一部署」，排错靠自己翻 FAQ 和 issue；
- **安装包未公证**：macOS / Windows 首次打开都要手动放行；
- **选片质量依赖模型**：弱模型下高光选段会跑偏，需要换强模型重试；
- **桌面版只覆盖 Apple Silicon 与 Windows x64**：Intel Mac / Linux 走 Docker 或 CLI。

**推荐指数：⭐⭐⭐⭐☆（4/5）**

- **播客 / 访谈 / 课程创作者** → **强烈建议试用**，先跑示例项目，再用自己的长片出第一批切片；
- **多平台分发（含出海）** → 一套素材全渠道模板 + 自动中文字幕，性价比很高；
- **Agent 自动化场景** → 接 MCP / CLI，把出片做成可批量的流水线；
- **需要逐帧精修的专业成片** → 还是回到剪映 / PR，AutoClip 做前置初筛即可。
