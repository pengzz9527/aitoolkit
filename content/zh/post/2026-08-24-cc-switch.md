# CC Switch 评测：一个让你告别多工具配置烦恼的 AI 编码助手管理器

在 AI 编码工具爆发式增长的今天，开发者们面临着「幸福的烦恼」：Claude Code、Codex、Gemini CLI、Grok Build、OpenCode、OpenClaw、Hermes Agent……每个工具都有各自的配置方式、API Key 管理和环境变量设置。频繁切换工具时，配置丢失、环境变量冲突、MCP Server 重复配置等问题让人头疼不已。

今天我们要介绍的 **CC Switch**，正是一个为解决这些痛点而生的跨平台桌面 All-in-One 管理器。自 2025 年 8 月开源以来，该项目已在 GitHub 上收获了 **12.9 万星**，成为近期最火爆的 AI 开发辅助工具之一。

## 工具简介

**CC Switch** 是一款基于 Tauri 2 构建的跨平台桌面应用，目前最新版本为 **v3.20.0**（2026 年 8 月发布）。它支持 Claude Code、Claude Desktop、Codex、Gemini CLI、Grok Build、OpenCode、OpenClaw、Hermes Agent 等八大 AI 编码工具，提供统一的配置管理、一键切换、本地代理与故障转移、MCP 统一管理、用量追踪等核心功能。

- **GitHub**: https://github.com/farion1231/cc-switch
- **官网**: https://ccswitch.io
- **语言**: Rust + Tauri 2
- **开源协议**: MIT
- **支持平台**: Windows、macOS、Linux

## 核心功能

### 1. 统一 Provider 管理

CC Switch 最核心的功能是对多个 AI 编码工具的 Provider 进行统一管理。

- **8 大工具支持**：覆盖目前主流的 Claude Code、Codex、Gemini CLI、Grok Build、OpenCode、OpenClaw、Hermes Agent 以及 Claude Desktop
- **50+ 预设配置**：内置各大服务商的预设模板，一键导入 API Key 即可使用
- **通用 Provider**：一套配置可同时同步到 Claude Code、Codex 和 Gemini CLI，无需重复配置
- **拖拽排序**：直观地调整 Provider 优先级，拖一拖就完成了配置顺序的调整

### 2. 本地代理与故障转移

CC Switch 内置了一个本地代理服务器，提供以下高级功能：

- **格式转换**：自动将不同服务商的 API 格式统一转换
- **自动故障转移**：当某个 Provider 不可用时，自动切换到备用 Provider
- **熔断器机制**：防止故障 Provider 持续消耗请求资源
- **健康监控**：实时监控各 Provider 的可用性和响应质量
- **应用级别接管**：可以为每个工具独立设置代理，精细控制到单个 Provider

### 3. MCP 统一管理

MCP（Model Context Protocol）是 AI 编码工具生态中越来越重要的标准。CC Switch 提供：

- **跨工具同步**：统一管理 Claude、Codex、Gemini、Grok Build、OpenCode 和 Hermes 的 MCP Server
- **双向同步**：在 CC Switch 中修改配置，自动同步到各工具
- **Deep Link 导入**：支持通过 URL 直接导入 MCP Server 配置

### 4. 提示词与 Skills 管理

- **跨应用同步**：统一管理 CLAUDE.md、AGENTS.md、GEMINI.md 等提示词文件
- **Markdown 编辑器**：内置编辑器支持实时预览
- **一键安装 Skills**：从 GitHub 仓库或 ZIP 文件一键安装，支持符号链接和文件复制两种方式
- **防回退保护**：导入新配置时自动备份原有内容，避免配置丢失

### 5. 用量与费用追踪

- **使用仪表板**：可视化展示各模型的 Token 消耗、请求次数和费用趋势
- **自定义定价**：支持为每个模型设置自定义价格，精确计算实际费用
- **请求日志**：详细的请求历史记录，方便排查问题
- **会话管理**：浏览、搜索和恢复 across 多个工具的历史对话

### 6. 数据同步与备份

- **云端同步**：支持 Dropbox、OneDrive、iCloud、NAS 和 WebDAV 服务器
- **自动备份**：每次修改配置前自动创建备份，保留最近 10 份历史
- **Deep Link 协议**：通过 `ccswitch://` 协议直接导入配置
- **原子写入**：确保配置写入的原子性，防止数据损坏

## 适用人群

CC Switch 适合以下用户：

- **多工具使用者**：同时使用 Claude Code、Codex、Gemini CLI 等多个 AI 编码工具，需要频繁切换的场景
- **团队协作者**：需要在团队成员间共享配置和 Skills
- **成本敏感型用户**：关注 API 费用，希望通过故障转移选择最优价格的服务商
- **进阶 MCP 用户**：配置了多个 MCP Server，需要统一管理
- **配置党**：重视数据安全，需要备份和同步功能

## 如何使用

### 安装

**macOS（推荐）**：
```bash
brew install --cask cc-switch
```

**Windows**：
从 [Releases 页面](https://github.com/farion1231/cc-switch/releases) 下载最新的 MSI 安装包或便携版 ZIP。

**Linux**：
从 Releases 页面下载对应的 AppImage，赋予执行权限后运行：
```bash
chmod +x CC-Switch-v*.AppImage
./CC-Switch-v*.AppImage
```

### 基本使用流程

1. **添加 Provider**：点击「Add Provider」→ 选择预设或创建自定义配置 → 填入 API Key
2. **切换 Provider**：在主界面选中 Provider → 点击「Enable」；或通过系统托盘快速切换
3. **生效配置**：大多数工具需要重启终端，Claude Code 支持热切换无需重启
4. **恢复官方登录**：添加官方登录预设，重启工具后按提示完成 OAuth 流程

### MCP 配置示例

1. 点击界面上的「MCP」按钮
2. 选择要配置的 Tool（如 Claude Code）
3. 添加 MCP Server（可通过模板或自定义配置）
4. 勾选「Sync to All」即可同步到所有支持的工具

### 用量追踪

在主界面点击「Usage」按钮，即可看到：
- 各 Provider 的请求次数和 Token 消耗趋势图
- 详细的请求日志
- 按模型分类的费用统计
- 自定义每模型单价，精确计算实际支出

## 版本亮点（v3.20.0）

最新版本的几个重要更新：

- **Pi 工具正式加入**：CC Switch 成为第九个支持的工具，提供 58 个预设配置和 57 个模型的完整目录
- **Codex 多账号支持**：Auth Center 支持登录多个 ChatGPT 账号，可分别绑定到不同 Provider
- **Claude Code WebSearch 支持**：通过 Responses Provider 或 Codex OAuth 后端的路由支持内置 WebSearch
- **Windows WSL 修复**：修复了 Windows 上 WSL 路径的文件替换问题
- **macOS IME 修复**：解决了中文/日文输入法导致表单字段损坏的问题
- **DeepSeek V4 价格更新**：根据服务商最新定价更新了 DeepSeek V4 的费用

## 总结

CC Switch 是一款设计精良、功能全面的 AI 编码工具管理器。它将原本分散在多个工具中的配置管理、MCP 设置、费用追踪等功能统一到一个界面中，大大降低了多工具使用的工作量。

**优点**：
- 跨平台支持完善（Windows / macOS / Linux）
- 功能全面，覆盖 Provider 管理、代理、MCP、Skills、用量追踪等
- 开源免费，MIT 协议，社区活跃
- 最近版本更新频繁，开发迭代迅速
- 系统托盘、Deep Link 等细节体验设计优秀

**缺点**：
- 工具数量较多，初次使用有一定学习成本
- 部分高级功能（如代理设置）需要一定技术背景
- Linux 下 Wayland + NVIDIA 组合可能遇到显示问题（需设置环境变量）

**推荐指数**：⭐⭐⭐⭐☆（4.5/5）

对于同时使用多个 AI 编码工具的用户来说，CC Switch 几乎是必装工具。它不仅解决了配置管理的痛点，还通过本地代理和故障转移功能帮助降低 API 费用。如果你正在为多个 AI 工具的重复配置而烦恼，CC Switch 值得尝试。
