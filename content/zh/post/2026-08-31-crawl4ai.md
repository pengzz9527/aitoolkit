## 核心功能

### 1. LLM 友好的 Markdown 输出

Crawl4AI 最核心的卖点是「智能 Markdown 生成」。它不只是简单地把 HTML 转成文本，而是通过多种策略对内容进行清洗和结构化：

- **Clean Markdown**：生成结构清晰、格式规范的 Markdown，保留标题层级、表格、代码块等关键元素
- **Fit Markdown**：基于启发式算法自动过滤噪声内容，只保留对 AI 最有价值的核心信息
- **BM25 内容过滤**：结合 BM25 算法，根据用户查询智能筛选最相关的内容段落
- **引用与参考**：自动将页面链接转为带编号的参考文献列表，方便后续溯源

### 2. 强大的结构化数据提取

Crawl4AI 提供了两种 Extraction 策略：

- **CSS/XPath 提取**：定义 JSON Schema 后用 CSS 选择器快速提取结构化数据，无需调用 LLM，速度快、成本低
- **LLM 驱动提取**：支持 OpenAI、Ollama 等任何 Litellm 兼容的模型，自动从网页内容中提取符合指定 Schema 的结构化数据，还支持余弦相似度语义搜索

### 3. 浏览器级渲染与反爬能力

- **Playwright 内核**：完整执行 JavaScript，渲染动态内容，支持等待异步加载
- **Shadow DOM 扁平化**：自动提取隐藏在 Shadow DOM 中的内容
- **反检测机制**：3 层反爬检测（已知厂商、通用拦截信号、结构完整性检查），自动切换代理重试
- **持久化浏览器 Profile**：保存登录状态、Cookie，实现多步骤会话式爬取
- **懒加载处理**：自动等待图片等媒体资源加载完成

### 4. 灵活的部署方式

- **Python SDK**：`pip install crawl4ai` 即可使用，async/await 原生支持
- **CLI 命令行**：`crwl https://example.com -o markdown` 一行命令搞定
- **Docker 容器**：官方镜像一键部署，内置 FastAPI 服务、实时监控面板和 Playground
- **MCP 集成**：可直接连接 Claude Code 等 AI 工具

### 5. 深度爬取与智能调度

- 支持 BFS、DFS、Best-First 三种深度爬取策略
- 崩溃恢复机制：通过 `on_state_change` 回调持久化状态，支持断点续爬
- Prefetch 模式：跳过处理和渲染，仅做 URL 发现，速度提升 5-10 倍

## 如何使用

### 快速安装

```bash
pip install -U crawl4ai
crawl4ai-setup
crawl4ai-doctor
```

如果浏览器安装有问题，可手动安装：
```bash
python -m playwright install --with-deps chromium
```

### Python 示例：基础爬虫

```python
import asyncio
from crawl4ai import AsyncWebCrawler

async def main():
    async with AsyncWebCrawler() as crawler:
        result = await crawler.arun(
            url="https://docs.crawl4ai.com",
        )
        print(result.markdown)

if __name__ == "__main__":
    asyncio.run(main())
```

### Python 示例：LLM 结构化提取

```python
import asyncio, os
from crawl4ai import AsyncWebCrawler, BrowserConfig, CrawlerRunConfig
from crawl4ai import LLMExtractionStrategy
from pydantic import BaseModel

class Product(BaseModel):
    name: str
    price: str
    description: str

async def main():
    config = CrawlerRunConfig(
        extraction_strategy=LLMExtractionStrategy(
            llm_config={"provider": "openai/gpt-4o", "api_token": os.getenv("OPENAI_API_KEY")},
            schema=Product.model_json_schema(),
            instruction="从页面中提取所有商品信息",
        )
    )
    async with AsyncWebCrawler() as crawler:
        result = await crawler.arun(url="https://example.com/products", config=config)
        print(result.extracted_content)

asyncio.run(main())
```

### CLI 示例

```bash
# 基本爬取
crwl https://example.com -o markdown

# 深度爬取
crwl https://docs.example.com --deep-crawl bfs --max-pages 20

# LLM 提取
crwl https://example.com -q "提取所有产品定价信息"
```

### Docker 部署

```bash
docker pull unclecode/crawl4ai:latest
docker run -d -p 11235:11235 --name crawl4ai --shm-size=1g unclecode/crawl4ai:latest
# 访问 http://localhost:11235/dashboard 查看监控面板
```
