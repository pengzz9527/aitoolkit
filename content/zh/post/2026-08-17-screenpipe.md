## 工具简介

**Screenpipe** 是一款由 Y Combinator S26 孵化支持的开源 AI 记忆工具。它的核心理念很简单：让你的电脑成为一个真正"记得一切"的个人 AI——24 小时记录你看到的内容、听到的对话、所做的操作，然后把这些数据转化为可搜索的记忆、标准操作流程（SOP）和自动化触发器，供 AI Agent 调用。

与 Rewind AI、Mem0 等同类产品不同，Screenpipe 的最大亮点是**完全本地运行**，所有数据仅存储在用户设备上，不上传云端。它与 Hermes Agent、OpenClaw 等主流 AI Agent 框架深度集成，是目前最贴合本地 AI 工作流的记忆层解决方案之一。

## 核心功能

### 1. 24/7 全量本地录制

Screenpipe 全天候运行，持续捕获屏幕画面（含 OCR 文字识别）、系统音频转录、键盘输入、应用切换记录，以及完整的无障碍树（accessibility tree）。所有数据本地存储，不依赖任何云服务。

### 2. AI 驱动的语义搜索

内置多模态 AI 模型，支持用自然语言搜索你的屏幕历史。例如你可以问"昨天我看了什么网页？"或"上周会议里提到了什么？"，Screenpipe 会从数月的录制数据中精准检索相关内容。

### 3. Pipes 自动化触发器

这是 Screenpipe 最具创新性的功能。你可以创建"Pipes"——即基于特定工作模式自动触发的 Agent 管道。例如：

- 每当你在某款代码编辑器中工作时，自动记录上下文并生成摘要
- 每当会议应用启动时，自动转录对话并提炼行动项
- 每当处理特定文件类型时，自动触发预设的 AI 工作流

Pipes 可以与 Hermes Agent、Claude、ChatGPT 等 AI 工具无缝对接。

### 4. 隐私优先设计

- 数据 100% 本地存储，不上传任何云端
- 内置 AI PII 识别模型，自动过滤敏感信息（已于 2026-05 发布 alpha 版，性能超越 Google、Microsoft、OpenAI 的同类模型）
- 可选磁盘加密
- 离线可用，无网络依赖
- 开源可审计（source-available 许可证）

### 5. 低资源占用

- CPU 占用：5-10%
- 内存占用：0.5-3 GB
- 月存储：约 20 GB
- 支持窗口、应用、Chrome 扩展级别过滤

## 如何使用

### 安装

**方式一：桌面应用（推荐新手）**

访问 [screenpipe.com/how-to-install](https://screenpipe.com/how-to-install?download=1) 下载对应平台的桌面客户端，安装后自动更新。

**方式二：CLI 命令行**

```bash
# 安装
npx screenpipe record

# 初始化配置
npx screenpipe setup
```

### 配置 MCP 集成（适用于 Hermes Agent）

```bash
# 添加 Screenpipe MCP 服务器到 Hermes
claude mcp add screenpipe -- npx -y screenpipe-mcp@latest
```

### 基本使用

1. **启动录制**：运行 `screenpipe record` 或打开桌面应用
2. **搜索历史**：通过自然语言查询"昨天我做了什么"、"上周的代码讨论"等
3. **创建 Pipes**：在设置中定义自动化规则，例如"当打开 VS Code 时，记录工作上下文并生成日报"
4. **与 Agent 对话**：直接询问 Hermes Agent "根据我今天的屏幕记录，总结一下我完成了哪些工作"

### 高级配置

Screenpipe 支持精细化的过滤规则：

- **窗口/应用过滤**：指定只录制特定应用
- **Chrome 扩展过滤**：排除特定网页
- **密码/敏感信息过滤**：自动屏蔽密码输入
- **PII AI 模型**：自动识别并脱敏个人身份信息

- ✅ **完全本地**：数据不离开本机，隐私安全性极高
- ✅ **Hermes 原生集成**：专为 Hermes Agent 生态设计，MCP 支持完善
- ✅ **创新 Pipes 系统**：基于工作模式的自动触发器，远超传统"回放"工具
- ✅ **低资源占用**：Rust 编写，性能优秀
- ✅ **AI PII 模型**：内置隐私保护，自动过滤敏感信息
- ✅ **活跃开发**：YC 加持，日更级别的迭代速度
