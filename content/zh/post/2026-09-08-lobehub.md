# LobeHub — 82K Stars 的 Agent 编排中枢，你的私人 AI 团队管理器

![LobeHub](https://raw.githubusercontent.com/lobehub/lobehub/main/.github/assets/cover.png)

**LobeHub** 是一个开源的 **Chief Agent Operator（首席 Agent 操作员）** 平台，Stars 数已超过 82,000。它的核心理念是：不再让每个 AI Agent 独立运行、各自为政，而是将所有智能体统一管理——像管理团队一样，招聘 Agent、安排任务、定时执行、跟踪汇报。项目使用 TypeScript 构建，支持桌面端、Web 端和自托管部署，持续活跃迭代中。

## 核心功能

1. **统一 Agent 管理**：在一个界面里创建、配置和管理多个 AI Agent，每个 Agent 可以绑定不同的模型（GPT、Claude、DeepSeek、GLM 等）、不同的系统提示和工具权限，实现专业化分工。

2. **10,000+ Skills 生态**：内置技能库覆盖 10,000+ 工具和能力，支持 MCP（Model Context Protocol）兼容插件，可轻松接入文件系统、浏览器、数据库、API 服务等外部资源，让 Agent 真正拥有操作能力。

3. **IM 网关集成**：支持将 Agent 接入 Telegram、Discord、Slack、WeChat 等即时通讯平台，随时随地通过消息与 AI 对话，无需打开浏览器。

4. **Pages（协作写作）**：多人共享上下文的多 Agent 协作写作空间，适合需要多个 AI 共同完成一篇文章、一份报告或一个项目的场景，上下文在 Agent 之间无缝流转。

5. **Schedule（定时调度）**：支持为 Agent 设置定时任务，在指定时间自动执行复杂工作流，比如每天早晨自动汇总新闻、睡前检查项目状态、周期性数据分析等。

6. **Workspace（团队协作）**：为团队提供共享的 Agent 工作空间，支持任务分配、权限管理和进度追踪，让组织内部的 AI 能力建设更加规范。

## 适用人群

- **AI 多面手用户**：同时使用多个 AI 工具（ChatGPT、Claude、Gemini 等），希望在一个入口统一管理所有对话和操作。
- **团队负责人**：需要协调多个 AI Agent 完成不同任务，希望有可视化的任务调度和进度追踪。
- **自动化爱好者**：希望设置定时任务让 AI 在后台自主执行重复性工作，而不需要人工干预。
- **技术团队**：需要构建基于 MCP 的插件生态，让 Agent 能接入企业内部系统和数据源。
- **IM 重度用户**：习惯在微信、Telegram、Discord 上处理信息，希望 AI 助手能无缝融入现有通讯流程。

## 如何使用

### 桌面端快速启动（推荐）

从 [GitHub Releases](https://github.com/lobehub/lobehub/releases) 下载对应平台的安装包：

```bash
# macOS
# 下载 .dmg 文件后拖入 Applications 即可

# Windows
# 下载 .exe 安装程序

# Linux
# 下载 .AppImage 或 .deb 包
```

### 自托管部署（Docker）

```bash
git clone https://github.com/lobehub/lobehub.git
cd lobehub
cp .env.example .env
# 编辑 .env 配置模型 API Key 和其他参数
docker compose up -d --build
```

访问 `http://localhost:3210` 即可使用。

### 配置模型后端

在 `.env` 中配置你使用的 AI 模型：

```bash
# OpenAI 兼容 API
OPENAI_API_KEY=sk-xxx
OPENAI_BASE_URL=https://api.openai.com/v1

# DeepSeek
DEEPSEEK_API_KEY=sk-xxx

# Claude
ANTHROPIC_API_KEY=sk-ant-xxx

# Ollama 本地模型
OLLAMA_BASE_URL=http://localhost:11434/v1
```

### 启用 IM 网关

在 Web UI 的 Settings → IM Gateway 中配置 Telegram Bot Token、Discord Bot 等信息，即可通过消息平台与 Agent 交互。

### 安装 Skills 插件

进入 Skills 市场或手动安装 MCP 插件：

```bash
# 通过 CLI 安装 MCP 插件
lobehub skills add github-mcp-server
lobehub skills add filesystem-mcp-server
```

也可在 Web UI 中直接浏览和安装 10,000+ 技能。

### 创建定时任务

在 Schedule 模块中设置任务：
1. 选择目标 Agent
2. 设置执行频率（每日/每周/自定义 Cron）
3. 编写触发指令和预期输出格式
4. 保存并开启定时调度
