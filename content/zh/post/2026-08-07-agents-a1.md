## 一句话介绍

**Agents-A1** 是 InternScience 开源的 35B 专家混合（MoE）智能体模型，通过扩展智能体决策深度（而非盲目堆叠参数量），在多个科学推理、代码生成和浏览器操作基准上达到万亿参数级性能，超越 Kimi-K2.6 和 DeepSeek-V4-pro 等超大模型。

---

## 它是什么？

AI 模型的发展长期遵循"越大越好"的路径——参数量从几十亿到几千亿再到万亿，训练成本呈指数级增长。但 InternScience 的研究团队提出了一个完全不同的思路：**与其增加模型的参数量，不如扩展智能体的"视野"和"能力边界"**。

Agents-A1 正是这一理念的成果。该模型于 2026 年 6 月发布论文（arXiv:2606.30616），采用 Apache-2.0 许可证开源，在 Hugging Face 上获得了 16.7 万+ 下载和 721+ Likes，成为智能体模型领域的现象级作品。

模型基于 Qwen3.5-35B-A3B 基础架构（35B 总参数，活跃 3B），是一个多模态（图像-文本到文本）的视觉语言模型（VLM），专门针对智能体任务进行训练。其核心创新在于构建了平均长度达 45K token 的长周期智能体轨迹，将外部知识、行动、观察和验证器结果连接起来，让模型学会"深度思考、多步推理"的智能体行为。

---

## 核心功能

### 1. 三阶段训练管线

Agents-A1 采用独特的三阶段训练方案，确保模型在保持高效的同时获得强大能力：

- **全领域监督微调（SFT）**：将基础模型与广泛的智能体行为对齐，奠定通用能力基础
- **领域教师模型训练**：在六个不同领域分别训练专家教师模型，捕获专业化知识
- **多教师领域路由蒸馏**：提出带显著词汇对齐的多教师在线策略蒸馏，提升跨领域知识转移效率

### 2. 六领域统一能力

Agents-A1 将六个异构领域统一到一个可部署的学生模型中：

| 领域 | 基准测试 | Agents-A1 得分 |
|------|----------|----------------|
| 科学推理 | FrontierScience-Olympiad | 79.0 |
| 交互式基准 | IFBench | 80.6 |
| 科学计算 | SciCode | 44.3 |
| 高阶推理 | HLE | 47.6 |
| 浏览能力 | BrowseComp | 75.5 |
| 分子科学 | MolBench-Bind | 56.8 |

### 3. 超越万亿参数模型的性能

在多个基准测试上，35B 的 Agents-A1 击败了参数量高达 1 万亿的模型：

- **SEAL-0**：56.4（领先 Kimi-K2.6 和 DeepSeek-V4-pro）
- **IFBench**：80.6
- **HiPhO**：46.4

这一成绩证明了"扩展智能体视野"策略的有效性和可扩展性。

### 4. 多模态智能体能力

作为视觉语言模型，Agents-A1 支持图像-文本到文本的生成，能够：

- 理解屏幕截图并做出操作决策
- 读取文档、图表和界面元素
- 在多步骤任务中保持视觉上下文

## 如何使用

### 方式一：Hugging Face 直接推理

```python
from transformers import AutoModelForCausalLM, AutoTokenizer

model_id = "InternScience/Agents-A1"
model = AutoModelForCausalLM.from_pretrained(model_id, trust_remote_code=True)
tokenizer = AutoTokenizer.from_pretrained(model_id, trust_remote_code=True)

# 输入多模态提示
messages = [{"role": "user", "content": "请分析这张截图并描述当前界面状态"}]
# 配合图像输入调用模型
```

### 方式二：Ollama 本地部署

```bash
ollama pull internscience/agents-a1
ollama run agents-a1 "分析这个代码库的结构"
```

### 方式三：OpenRouter API

```bash
# 通过 OpenRouter 调用
curl https://openrouter.ai/api/v1/chat/completions \
  -H "Authorization: Bearer $OPENROUTER_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "internscience/agents-a1",
    "messages": [{"role": "user", "content": "帮我完成这个多步骤任务..."}]
  }'
```

### 方式四：本地 GGUF 量化版本

对于资源受限的机器，可以使用量化版本：
- `InternScience/Agents-A1-Q4_K_M-GGUF`（4-bit 量化，适合 8GB+ 显存）
- `r0b0tlab/Agents-A1-NVFP4`（NVFP4 量化，适合 NVIDIA GPU）

## 总结与推荐

**推荐指数：⭐⭐⭐⭐⭐（5/5）**

Agents-A1 代表了当前智能体模型发展的一个重要方向——**不追求盲目扩大参数量，而是通过扩展智能体的决策深度和能力边界来实现性能突破**。

**核心亮点**：
- ✅ 35B 参数实现万亿参数级性能，性价比极高
- ✅ 六个异构领域统一模型，通用能力强
- ✅ Apache-2.0 开源许可证，可自由商用
- ✅ 多模态支持，可理解图像和界面
- ✅ 论文开源，研究方法可复现

**需要注意**：
- ⚠️ 模型仍基于 Qwen3.5 架构，部分领域支持依赖基础模型能力
- ⚠️ 中文场景的支持需要额外评估

对于追求高效智能体部署、希望在小参数规模下获得高性能的团队来说，Agents-A1 是目前最值得关注的开源模型之一。
