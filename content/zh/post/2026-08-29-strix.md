# Strix：开源 AI 渗透测试工具

**一句话简介**：Strix 是一款开源的自主 AI 渗透测试代理框架，模拟真实黑客行为动态运行你的代码、发现漏洞并通过实际概念验证（PoC）来验证，同时自动生成修复补丁和合规报告。

## 核心功能

### 1. 自主 AI 渗透测试代理

Strix 最核心的创新在于它不是传统的静态扫描工具，而是通过多个专门的 AI 代理协作来完成完整的渗透测试流程。这些代理具备与真实黑客相同的工作方式——动态运行代码、发现漏洞并验证利用路径。内置的渗透测试工具包包括 HTTP 拦截代理（基于 Caido）、自动化浏览器（用于 XSS、CSRF、点击劫持等测试）、交互式终端、Python 沙箱（用于编写概念验证 exploits）以及自动化攻击面映射和子域名枚举。

### 2. 多智能体协作编排

Strix 采用"代理图"（Graph of Agents）架构，将渗透测试拆分为侦察、利用和后渗透三个专业化阶段，每个阶段由不同的 AI 代理负责。这些代理可以共享发现、链式利用漏洞，像真实的红队一样协同工作。在多个目标上支持并行执行，大幅缩短全面安全测试的时间。

### 3. 真实漏洞验证（零误报承诺）

与 Legacy 漏洞扫描器依赖特征匹配不同，Strix 对每个发现都生成可工作的概念验证（Proof-of-Concept）。这意味着报告中的每一个漏洞都有一个实际的利用演示，从根本上消除了传统工具的高误报率问题。支持检测的漏洞类型覆盖 OWASP Top 10 及更多，包括 IDOR、SQL 注入、SSRF、JWT 攻击、反序列化漏洞、业务逻辑缺陷等。

### 4. 一键自动修复与报告生成

发现漏洞后，Strix 不仅提供详细的修复建议，还能自动生成可直接应用的安全补丁。对于 Strix 平台用户，还可以一键生成准备就绪的 Pull Request。同时支持生成符合合规要求的渗透测试报告，包含 CVSS 评分和 OWASP 分类。

### 5. 本地 Web 查看器与实时操控

每次扫描的结果实时写入磁盘，通过 `strix view` 命令即可在本地启动一个轻量级仪表盘。这个查看器展示运行状态、漏洞详情、代理协作图和实时操控面板——你可以在扫描过程中通过浏览器发送指令来调整代理行为。所有数据完全本地存储，无需联网或注册账号。

### 6. 多 LLM 支持与 CI/CD 集成

Strix 支持 OpenAI、Anthropic、Google、OpenRouter 等多种 LLM 提供商，并可通过 `npx skills add usestrix/strix` 轻松集成到 Claude Code、Cursor、Codex 等编程代理中。同时提供 GitHub Actions 集成，可在每次 PR 提交时自动扫描漏洞并阻止不安全代码进入生产环境。

## 如何使用

### 快速安装与首次扫描

```bash
# 安装 Strix
curl -sSL https://strix.ai/install | bash

# 配置 LLM API
export STRIX_LLM="openai/gpt-5.4"
export LLM_API_KEY="your-api-key"

# 对本地应用目录进行安全评估
strix --target ./your-app-directory
```

首次运行会自动拉取沙箱 Docker 镜像，扫描结果保存至 `strix_runs/<run-name>` 目录。

### 查看扫描结果

```bash
# 打开最新扫描的本地仪表盘
strix view

# 查看指定扫描
strix view my-first-scan

# 对外暴露查看器（供团队协作）
strix view --host 0.0.0.0 --port 8080 --no-open
```

### 集成到 CI/CD

Strix 支持 GitHub Actions 一键集成，在每次 PR 提交时自动扫描并阻断包含漏洞的代码：

```yaml
- uses: usestrix/strix-action@v1
  with:
    target: './src'
    llm: 'openai/gpt-5.4'
    fail-on-critical: true
```

### 集成编程代理

通过 skills 系统可将 Strix 能力注入到主流编程代理中：

```bash
# 为 Claude Code / Cursor / Codex 等安装 Strix 技能
npx skills add usestrix/strix
```

这将安装 9 个技能模块，包括渗透测试、漏洞修复、CI 扫描和 OWASP Top 10 专项测试等。

### 使用云端平台

对于不想本地部署 Docker 的场景，可直接使用 [app.strix.ai](https://app.strix.ai)，注册后即可连接仓库和域名，几分钟内启动渗透测试。平台支持连续学习和自适应优化，随着使用时间增长准确率会不断提升。
