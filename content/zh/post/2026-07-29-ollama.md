## 一句话介绍

**Ollama** 是由社区开发者打造的轻量级大语言模型运行框架，主打\"像 Docker 一样简单\"的本地模型体验——只需一条命令即可下载并运行任何主流大模型，目前已获 GitHub **14.5 万+ Stars**，成为本地 LLM 运行的事实标准。

## 它是什么？

在本地部署大语言模型的曾经是个充满门槛的过程：需要配置复杂的环境参数、手动下载模型权重、编写启动脚本、管理依赖包……这些障碍将绝大多数普通用户挡在了本地 AI 的大门外。**Ollama** 的出现彻底改变了这一局面，它把本地 LLM 的部署复杂度降低到了极致。

Ollama 是一个跨平台的应用程序，支持 Windows、macOS 和 Linux，提供简洁的命令行客户端和 RESTful API。它的核心理念非常简单：**所有操作只需一行命令**。你可以像下载运行一个软件包一样，直接 `ollama run llama3` 或 `ollama run qwen`，Ollama 会自动从云端下载对应模型、加载到显存中并开始等待你的输入。

该项目由 [ollama](https://github.com/ollama/ollama) 组织维护，采用 **Apache 2.0** 许可证开放源代码。截至 2026 年 7 月，Ollama 仓库已收获 **145,000+ Stars**、**25,000+ Forks**，拥有活跃的 GitHub Issues 和每周发布的稳定版本更新。配套的 Web UI [Ollama WebUI](https://github.com/ogogman/oobabooga-webui) 和第三方整合生态也日益丰富，用户可以通过浏览器直接对话本地模型。

Ollama 的核心优势在于它的**模型库丰富性**和**易用性**——内置支持包括 Meta 的 Llama 系列、Google 的 Gemma、Mistral AI 的 Mixtral/Mistral、微软的 Phi、阿里巴巴的 Qwen、智谱的 GLM 等数十种主流模型，每种模型都有不同参数量版本可选（如 Llama-3-8B、Llama-3-70B、Qwen-72B 等）。

## 核心功能

### 1. 极简的模型管理

Ollama 最引人注目的特点是其极致的简洁性：

```bash
# 下载并运行一个模型（首次会自动下载）
ollama run llama3

# 列出已下载的所有模型
ollama list

# 删除一个模型
ollama rm llama3

# 复制/重命名模型
ollama copy llama3 llama3-finetuned
```

这种 `docker run` 般的设计哲学让模型管理的复杂度降到最低。模型以 `.gguf` 格式存储于本地磁盘，每个模型占用空间从几百 MB（如 TinyLlama）到几十 GB（如 Llama-70B）不等。

### 2. 丰富的模型库

Ollama 官方网站维护着一个庞大的模型库（[https://ollama.com/library](https://ollama.com/library)），包含以下主要类别：

| 模型家族 | 典型模型 | 参数量 | 适用场景 |
|----------|---------|--------|---------|
| Meta Llama | llama3 | 8B / 70B | 通用对话、代码生成 |
| Mistral | mistral | 7B | 高效推理、多语言 |
| Google | gemma | 2B / 7B | 移动端部署、快速响应 |
| Microsoft | phi | 1.3B / 3.8B | 边缘设备、低资源环境 |
| Alibaba | qwen | 7B / 72B | 中文优化、长上下文 |
| Intel | mixtral | 8x7B | 高性能推理 |
| Others | stable-diffusion | —— | 文生图支持 |

每次新版本发布，Ollama 都会更新模型列表，新增更多开源优秀模型。

### 3. API 服务与集成

除了 CLI，Ollama 还内置了兼容 OpenAI 格式的 REST API（默认端口 `11434`），这使得它与现有的 AI 工具和框架无缝集成：

```bash
# 启动 Ollama API 服务
ollama serve
```

使用示例（OpenAI SDK 兼容）：
```python
from openai import OpenAI

client = OpenAI(base_url="http://localhost:11434/v1")

chat = client.chat.completions.create(
    model="llama3",
    messages=[{"role": "user", "content": "你好！请介绍一下你自己。"}],
)
print(chat.choices[0].message.content)
```

这种兼容性意味着你可以用 Ollama 替换 OpenAI API 而不修改业务代码，极大降低了本地化部署的成本。

### 4. 模型微调与自定义

Ollama 支持基于现有模型进行微调，通过定义 Modfile 可以指定模型的行为指令、系统提示、上下文窗口等：

```Modfile
FROM llama3

PARAMETER temperature 0.7

SYSTEM """你是一个乐于助事的助手。回答要用中文。"""

ALLOW_DOWNLOADS true
```

然后使用 `ollama create mymodel --modfile=Modfile` 创建自定义模型版本，再像普通模型一样调用：`ollama run mymodel`。

此外，Ollama 还支持通过其 API 进行指令微调（RLHF/SFT 流程），社区也提供了基于 Fine-tuning 的各种工具链。

### 5. 并行推理与 GPU 加速

Ollama 利用 GPU 加速推理性能，支持以下后端：

| GPU 后端 | 说明 |
|----------|------|
| CUDA (NVIDIA) | 完整的 NVIDIA GPU 加速支持 |
| MPS (Apple Silicon) | Mac 设备的 Metal 引擎加速 |
| ROCm (AMD) | AMD GPU 支持（实验性） |
| CPU-only | 无 GPU 时的备选方案 |

对于多 GPU 场景，Ollama 可以自动分配层到不同显卡上；通过环境变量控制 `OLLAMA_GPU_MEMORY` 等参数可精细调整显存使用。

### 6. 持续改进与生态扩展

Ollama 团队持续在功能上进行迭代，近期增强包括：

- **长上下文支持**：部分模型支持 128K 上下文的扩展版本
- **多模态模型集成**：开始逐步纳入支持图文理解的多模态模型
- **RAG 插件生态**：通过与各种向量数据库（Chroma、Pinecone 等）的连接实现检索增强生成
- **Web 界面支持**：官方推出的 Ollama WebUI 以及第三方如 `llama.cpp`、`oobabooga` 的图形化前端完善

此外，Ollama 还与 VS Code、JetBrains 等 IDE 插件深度集成，允许用户在编程环境中直接调用本地 LLM 进行代码补全、注释生成等操作。

## 适用人群

- **开发者**：希望在项目中集成本地 AI 功能、保护数据隐私的开发人员，可通过 Ollama 快速搭建私有化 AI 服务。

- **研究人员**：需要进行模型实验、调参、对比分析的研究者，Ollama 提供的便捷模型切换能力大幅缩短实验周期。

- **企业 IT 人员**：需要对敏感数据进行本地化处理而不上云的企业用户，Ollama 满足数据不出内网的需求。

- **个人爱好者**：想用最新大模型但又不想受制于云服务费用或个人数据上传风险的单机玩家。

- **教育从业者**：希望为学生提供安全的本地 AI 学习环境，避免学生数据和代码泄露至公共云端的教学机构。

- **系统运维工程师**：需要将大模型服务部署到服务器集群、容器化编排（Docker/Kubernetes）的场景专家，Ollama 的轻量特性和 API 友好设计非常适合自动化部署。

## 如何使用

### 第一步：安装 Ollama

访问 [https://ollama.com](https://ollama.com) 获取你操作系统的安装包：

**macOS (Homebrew):**
```bash
brew install ollama
```

**Linux:**
```bash
curl -fsSL https://ollama.com/install.sh | sh
```

**Windows:**
下载 [Ollama Windows Installer](https://ollama.com/download) 并运行。

安装完成后验证：
```bash
ollama version
# 应显示类似 "ollama version is 0.5.4"
```

### 第二步：运行第一个模型

首次运行 Ollama 会自动下载模型：

```bash
ollama run llama3
```

你将进入交互式对话终端，输入问题即可得到模型回复。按 `Ctrl+C` 退出。

如果你只想运行而不进入交互模式：
```bash
ollama generate llama3 "你好世界！"
```

### 第三步：查看可用模型

浏览官方模型库或搜索已有模型：

```bash
# 列出已下载的模型
ollama list

# 查看所有可用模型（部分）
curl http://localhost:11434/api/tags
```

### 第四步：使用 API（编程集成）

Ollama 默认启动时提供本地服务。确认服务已运行：

```bash
ollama serve
```

或在后台运行：
```bash
ollama serve &
```

使用 Python 客户端调用：
```python
import requests

response = requests.post(
    "http://localhost:11434/api/generate",
    json={
        "model": "llama3",
        "prompt": "请介绍 Ollama 的主要特点。"
    },
    stream=True,
)

for chunk in response.iter_lines():
    if chunk:
        print(chunk.decode("utf-8"))
```

### 第五步：创建自定义模型（高级用法）

使用 Modfile 定制模型行为：

```Modfile
FROM qwen7b

PARAMETER temperature 0.5
PARAMETER repetition_penalty 1.2

SYSTEM """你是一个专业的技术文档撰写者，用清晰准确的语言回答问题。"""

ALLOW_DOWNLOADS false
```

创建模型：
```bash
ollama create my-qwen --modfile=Modfile
```

运行自定义模型：
```bash
ollama run my-qwen
```

### 第六步：Docker 部署（生产环境）

Ollama 提供官方 Docker 镜像，适合容器化部署：

```bash
# 运行容器，挂载模型目录以便持久化
docker run -d -p 11434:11434 --name ollama --add-host=host.docker.internal:host-gateway -v ollama-storage:/root/.ollama ollama/ollama
```

访问 API: `http://localhost:11434`

也可以通过 Compose 文件编排：

```yaml
version: "3.8"
services:
  ollama:
    image: ollama/ollama
    ports:
      - "11434:11434"
    volumes:
      - ollama-data:/root/.ollama
    restart: always

volumes:
  ollama-data:
```

### 第七步：多模型并发管理

虽然 Ollama 默认一次只运行一个模型实例，但你可以通过多实例运行来并行服务多个模型：

```bash
# 终端1: 运行 llama3
ollama run llama3

# 终端2: 运行 mistral  
ollama run mistral
```

或使用 `systemd` 或 Docker Compose 管理服务进程。

## 总结推荐指数

**Ollama** 重新定义了本地大语言模型的获取和使用方式，它将复杂的模型部署抽象为简单的几行命令，使非专业用户也能轻松尝鲜最先进的 AI 能力。凭借其优雅的 API 设计、活跃的社区维护和持续的功能演进，Ollama 已成为连接用户与本地 AI 模型的理想桥梁。

**优点：**
- 🌟 **安装极其简单**：一行命令完成全部安装，无需额外配置
- 🌟 **开箱即用**：预置大量热门模型，秒级启动对话
- 🌟 **API 友好**：OpenAI 兼容接口，无缝替换云端 API
- 🌟 **跨平台支持完美**：Windows/macOS/Linux 均有原生体验，Apple Silicon 专有加速
- 🌟 **灵活扩展性强**：支持 Modfile 定制、Docker 部署、IDE 插件集成
- 🌟 **社区活跃**：GitHub 贡献频繁，issue 响应快，第三方插件生态繁荣
- 🌟 **数据隐私可控**：所有模型和数据完全本地化处理，不上传云端

**不足：**
- ⚠️ **显存要求**：运行大尺寸模型（如 70B 系列）仍需大容量显卡（建议 24GB+）
- ⚠️ **默认单实例**：多个模型需同时运行时需启动多个实例，不如某些专业平台方便
- ⚠️ **功能聚焦基础**：相比 Text Generation WebUI 等界面，原生功能较精简（但这正是其设计理念）
- ⚠️ **训练功能偏弱**：主要用于推理，微调和 SFT 需配合外部工具链，不够一体化
- ⚠️ **中文优化虽有进步**：部分模型对中文支持仍不及专门为中文优化的本地方案

**综合评分：8.9/10**

Ollama 无疑是当前本地大模型部署领域的**标杆之作**。它成功地在"易用性"与"功能性"之间找到了绝佳平衡点——既照顾到新手用户的需求，也保留了足够的灵活性供进阶玩家探索。对于大多数只想体验本地大能力的用户而言，Ollama 是首选中的首选；而对于追求更深定制化、希望构建复杂 AI 流水线的专业开发者来说，Ollama 同样可以作为稳固的基础设施层与其他工具配合使用。

如果你是开发者、研究者或任何关心数据隐私并希望亲身体验最新 AI 技术的人，**Ollama 绝对值得立即安装尝试**。无论是用于日常问答辅助、编程生产力提升、还是企业私有化 AI 部署，它都能提供可靠而高效的解决方案。随着大模型技术的不断进步和 Ollama 自身的持续迭代，我们有理由相信它将在本地 AI 领域扮演越来越重要的角色。
