# VoiceStudio：本地化 ElevenLabs 替代品，646 种语言的语音克隆与视频配音神器

**VoiceStudio**（原名 OmniVoice-Studio）是一款开源的本地优先语音 AI 工具，被称为"开源版 ElevenLabs"。它集语音克隆、语音设计、视频配音、听写转录和有声书制作于一体，支持 16 种 TTS 引擎和 11 种 ASR 引擎，覆盖 646 种语言，且本地工作流无需账户、API Key 或订阅费。

- **GitHub 星标**：27,450+
- **GitHub 仓库**：https://github.com/debpalash/VoiceStudio
- **许可证**：AGPL-3.0
- **语言**：Python / Tauri（桌面端 Electron 重写中）
- **支持平台**：macOS、Windows、Linux、Docker
- **当前状态**：活跃 Beta 开发中

---

## 核心功能

### 1. 多引擎 TTS 语音合成

VoiceStudio 内置 **16 种 TTS 引擎**，包括 Coqui TTS、VALL-E X、Piper、Bark、Whisper 生态模型等，用户可以在 GUI 中一键切换引擎，对比不同语音风格和质量，选择最适合场景的合成方案。

### 2. 语音克隆与语音设计

支持从短音频样本中克隆任意音色，同时提供语音设计功能——通过调整音高、语速、情感等参数生成全新的虚拟声音，无需真实录音样本。

### 3. 视频配音与字幕生成

可导入视频文件，自动识别语音内容并生成多语言配音和字幕，支持 646 种语言互译配音，非常适合 YouTube 频道多语言版本制作、影视剧字幕翻译等场景。

### 4. 听写转录与语音转文字

集成 **11 种 ASR 引擎**（包括 Whisper 系列），支持高精度语音转文字，可对长时间音频进行分段转录，输出带时间戳的 SRT 字幕文件或纯文本稿。

### 5. 有声书批量制作

支持长文本输入，可分段合成并保持角色声音一致，批量导出为 MP3 等格式，满足有声书、播客内容的制作需求。

## 如何使用

### 安装

**方式一：桌面客户端（推荐新手）**

访问 https://github.com/debpalash/VoiceStudio/releases 下载对应系统的安装包（macOS / Windows / Linux），安装后直接启动使用。

**方式二：Docker 部署**

```bash
docker pull ghcr.io/debpalash/voicestudio:latest
docker run -d -p 8080:8080 ghcr.io/debpalash/voicestudio:latest
```

**方式三：源码安装（适合开发者）**

```bash
git clone https://github.com/debpalash/VoiceStudio.git
cd VoiceStudio
pip install -e .
```

### 基本使用流程

1. **启动 VoiceStudio**，进入主界面
2. **选择 TTS 引擎**：从右上角状态栏切换不同语音引擎
3. **输入文本**：粘贴或输入要合成的文字内容
4. **调整参数**：设置语速、音调、情感等
5. **点击生成**：等待合成完成后下载音频文件
6. **视频配音**：导入视频文件，选择配音引擎，自动生成多语言配音版本

### 硬件建议

- **最低配置**：8GB 内存，支持 CUDA 的 NVIDIA 显卡（推荐）
- **推荐配置**：16GB 内存 + NVIDIA RTX 3060 及以上，可获得更好的推理速度和音质
- **无 GPU 环境**：也可使用 CPU 模式，但速度较慢
