# MathModelAgent — 智能数学建模助手，3 天工作量压缩到 1 小时

![MathModelAgent](https://raw.githubusercontent.com/jihe520/MathModelAgent/main/docs/chat.png)

**MathModelAgent** 是一款专为数学建模竞赛和科研场景设计的 AI Agent 工具，由国内开发者 jihe520 打造，目前 GitHub 星标已超 4,900。它面向的核心痛点很明确：传统数学建模需要从问题分析、建模仿真、代码实现到论文撰写全流程手工完成，通常需要 3 天以上，而 MathModelAgent 希望通过 AI 自动化将这些工作压缩到 1 小时内。

## 核心功能

### 1. 端到端自动化建模流水线

MathModelAgent 提供一条完整的自动化流水线：从问题理解 → 数学建模 → 代码编写 → 仿真运行 → 可视化绘图 → 论文排版，全程无需人工介入。用户只需输入题目或问题描述，Agent 即可自动完成后续所有步骤，最终生成一份可直接提交的格式规范的论文文档。

### 2. 多 Agent 协作架构

工具采用 multi-agent 设计，内置建模手、代码手、论文手等多个专业角色。每个 Agent 负责不同阶段的工作，并且可以为每个角色配置不同的 LLM 模型——比如建模用推理强的模型，代码生成用编程能力强的模型，论文撰写用写作能力强的模型，实现各环节的最优配置。

### 3. RAG 知识库增强

MathModelAgent 内置基于 ChromaDB 的 RAG 知识库，汇聚了大量经典建模方法、代码模板和优秀论文参考。当遇到新问题时，Agent 会先从知识库中检索相似案例和解决方案，再结合具体问题生成定制化的建模方案，大幅提升了答案的准确性和专业性。

### 4. 灵活的网络搜索与云端执行

Agent 支持通过 Tavily API 自主搜索互联网获取真实数据，也支持接入 E2B 和 Daytona 等云端 Code Interpreter 进行代码执行。这意味着对于需要实时数据或复杂计算的建模任务，Agent 可以在线获取最新数据并在安全的沙箱环境中运行代码，结果直接反馈回建模流程。

### 5. 人机协作（HIL）模式

在全自动模式之外，MathModelAgent 还提供了 HIL（Human-in-the-Loop）人机协作模式。在关键决策节点，Agent 会暂停并等待用户审批，支持确认、编辑、重新生成、询问、跳过和中止等 6 种决策动作，让用户在重要环节保持对流程的控制权。

## 如何使用

### 方式一：桌面版（推荐，开箱即用）

1. 前往 [GitHub Releases 页面](https://github.com/jihe520/MathModelAgent/releases/latest) 下载对应系统的安装包（macOS ARM64 / macOS Intel / Windows 64位）。
2. 安装完成后打开应用，填入你的 LLM API Key（支持 Claude、GPT、DeepSeek 等各类模型）。
3. 在输入框中粘贴或输入数学建模题目描述，点击开始即可。
4. 全程会自动完成分析、建模、编码、绘图、写论文，最终生成完整文档。

> macOS 安装包已通过 Apple 公证，Windows 用户首次运行如遇 SmartScreen 提示，点击「更多信息」→「仍要运行」即可。

### 方式二：在线体验版

如果不想本地安装，可以直接访问 [mathmodel.top/home](https://mathmodel.top/home) 在线体验基础功能。

### 方式三：开发者自部署

1. 克隆仓库：`git clone https://github.com/jihe520/MathModelAgent.git && cd MathModelAgent`
2. 安装依赖：`pip install -r requirements.txt`
3. 配置环境变量（API Key、RAG 知识库路径等）
4. 运行主程序启动 Agent 服务

## 总结

MathModelAgent 是目前 GitHub 上最活跃的中文 AI 建模工具之一，它的核心价值在于把数学建模这一高度专业化、耗时的任务，通过 AI Agent 实现了真正的端到端自动化。无论是竞赛备赛还是科研探索，它都能显著降低门槛、提高效率。

**推荐指数**：⭐⭐⭐⭐☆（4/5）

**优点**：开箱即用的桌面版、多 Agent 协作、RAG 知识库、人机协作模式、支持多模型接入。

对于正在准备数学建模竞赛的同学，或需要在短时间内完成建模任务的研究人员来说，MathModelAgent 是一个非常值得尝试的利器。
