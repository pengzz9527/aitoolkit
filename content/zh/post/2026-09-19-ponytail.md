# Ponytail：让 AI 编程助手学会"偷懒"，代码量减少 54%

## 一句话简介

**Ponytail** 是一个 AI 编程助手的技能插件，它的核心理念很简单——让 AI 像办公室里那位留长发、戴 oval 眼镜、工龄比你版本号还长的资深工程师一样思考：**不写多余的代码**。它通过 YAGNI（You Aren't Gonna Need It）原则约束 AI 的过度设计倾向，实测可减少 54% 代码量，节省 20% 费用，提升 27% 速度。

## 核心功能

### 1. YAGNI 原则驱动的代码精简

Ponytail 的核心是一张"阶梯决策表"，在 AI 写代码之前，让它依次判断：

```
1. 这个功能有必要存在吗？  → 不需要：跳过（YAGNI）
2. 项目里已有实现吗？      → 复用，不要重写
3. 标准库能搞定吗？        → 用标准库
4. 原生平台特性能用吗？    → 用原生特性
5. 已安装的依赖能解决吗？  → 用现有依赖
6. 一行代码能写吗？        → 就写一行
7. 最后才考虑：最小可用方案
```

经典案例：让你写一个日期选择器，普通 AI 会安装 flatpickr、写包装组件、加样式表、讨论时区问题；而 Ponytail 直接输出一行：

```html
<!-- ponytail: browser has one -->
<input type="date">
```

### 2. 三种强度模式，按需调整

Ponytail 提供三个级别，适应不同场景：

| 模式 | 适用场景 |
|------|---------|
| `lite` | 轻度精简，适合对代码风格有严格要求的项目 |
| `full`（默认） | 平衡模式，推荐日常使用 |
| `ultra` | 极致精简，当你被过度设计的代码激怒时使用 |

通过命令随时切换：`/ponytail ultra`

### 3. 全面的代码审查工具

除了被动约束，Ponytail 还提供主动审查能力：

- **`/ponytail-review`**：审查当前 diff，找出过度设计的地方，生成删除清单
- **`/ponytail-audit`**：对整个仓库进行过度设计审计，不限于当前修改
- **`/ponytail-debt`**：收集你 Deferred 的简化机会，形成"技术债账本"
- **`/ponytail-gain`**：展示性能得分板（代码量、成本、速度的优化数据）

### 4. 广泛的兼容性

Ponytail 几乎支持所有主流 AI 编程助手，包括：

- **Claude Code**：`/plugin marketplace add DietrichGebert/ponytail`
- **OpenAI Codex**：`codex plugin marketplace add DietrichGebert/ponytail`
- **Cursor**：安装 hooks 脚本或复制规则文件
- **Gemini CLI**：`gemini extensions install https://github.com/DietrichGebert/ponytail`
- **Hermes Agent**：`hermes plugins install DietrichGebert/ponytail --enable`
- **Grok Build**、**OpenCode**、**Devin CLI**、**Qoder** 等

### 5. 安全保证

与一些激进的精简方案不同，Ponytail 明确承诺：**信任边界验证、数据丢失处理、安全性和可访问性永远不会被砍掉**。它节省的是"不必要的代码"，而不是"必要的防护"。在基准测试中，Ponytail 保持了 100% 的安全性评分。

## 如何使用

### 第一步：安装（以 Claude Code 为例）

Ponytail 的安装极其简单，只需两条命令：

```
/plugin marketplace add DietrichGebert/ponytail
/plugin install ponytail@ponytail
```

**注意**：这两条命令需要分别发送，第一条执行完后再发第二条才能安装成功。

### 第二步：安装其他助手

**Cursor**：
```bash
git clone https://github.com/DietrichGebert/ponytail
node ponytail/scripts/cursor-hooks.js install
```

**Gemini CLI**：
```bash
gemini extensions install https://github.com/DietrichGebert/ponytail
```

**Hermes Agent**：
```bash
hermes plugins install DietrichGebert/ponytail --enable
```

**Codex**：
```bash
codex plugin marketplace add DietrichGebert/ponytail
codex plugin add ponytail@ponytail
```

### 第三步：开始使用

安装完成后，Ponytail 会自动生效。你可以通过以下命令控制它：

```
/ponytail              # 查看当前模式
/ponytail lite         # 切换到轻量模式
/ponytail full         # 切换到标准模式
/ponytail ultra        # 切换到极致精简模式
/ponytail off          # 关闭 Ponytail
/ponytail-review       # 审查当前 diff
/ponytail-audit        # 审计整个仓库
```

### 第四步：配置默认模式（可选）

设置环境变量：
```bash
export PONYTAIL_DEFAULT_MODE=ultra
```

或创建配置文件 `~/.config/ponytail/config.json`：
```json
{
  "defaultMode": "full"
}
```
