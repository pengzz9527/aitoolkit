# Orca 评测：100x 构建者的 AI 编排器，把多个编程 agent 装进同一个 worktree 里统一管理

你同时跑 Claude Code 和 Codex 做同一个任务，想看两个结果哪个好——现在是开两个终端、来回切窗口、手动 diff。Orca 把这件事变成：一键 fan-out 到 5 个隔离 worktree，每个 agent 各跑各的，结果并排对比，合并赢家。

**Orca** 是 Stably AI（一个 2026 年 3 月才成立的小团队）在 7 个月内做到 **10 万+ 星标** 的开源 AI 编排器，MIT 协议，支持 macOS / Windows / Linux 三平台桌面端 + iOS App Store / Android APK 移动端。它的核心理念只有一句话：**Run any CLI agent in its own git worktree, tracked in one place.** 当前版本 v1.4.235，每天都在 ship 新版本，8600+ open issues 也说明社区活跃度极高。

## 工具简介

**Orca** 是一个跨平台的 AI agent 编排桌面应用，核心是「多 agent 并行 worktree 管理 + 统一 UI」，不是聊天机器人，也不是代码编辑器，而是 agent 调度层。

- **GitHub**: https://github.com/stablyai/orca
- **语言**: TypeScript（前端 + 桌面端），Rust（核心终端渲染）
- **开源协议**: MIT
- **平台**: macOS（Apple Silicon / Intel）、Windows 10/11、Linux（AppImage / deb / rpm / Arch AUR）
- **移动端**: iOS 15+（App Store 免费）、Android 11+（APK 直接安装）
- **定位**: 多 CLI agent 并行编排 + 终端 + 编辑器 + 浏览器 + 代码评审 + 远程 worktree，一站式替代「终端 + VS Code + 浏览器 + GitHub Web」

## 核心功能

1. **并行 Git Worktree 编排**：一条提示词 fan-out 到 5 个（或更多）agent，每个 agent 在独立 git worktree 里运行，互不干扰。完成后并排对比 diff，选中赢家合并回主分支。这是 Orca 最核心的差异化能力，比手动开多个终端快一个数量级。

2. **Ghostty 级终端分屏**：WebGL 渲染，支持无限分屏，滚动历史重启后保留。每个 agent 会话对应一个独立终端 pane，可以横向/纵向自由分割，比 iTerm2 和 Windows Terminal 都更轻。

3. **Design Mode 浏览器**：内置真实 Chromium 窗口，点击任意 UI 元素，自动把 HTML + CSS + 裁剪截图直接注入 agent 提示——做前端时不用再手动复制选择器和截图，agent 直接拿到精确的 DOM 上下文。

4. **GitHub & Linear 原生集成**：在应用内浏览 PR、issue、Linear 项目看板；从任意任务一键打开 worktree，完成评审和代码修改，全程无需切到浏览器。支持从 PR 里直接 diff 标注（Annotate AI Diff），评论发回给 agent 继续改。

5. **移动端 Companion**：iOS App Store 免费 + Android APK，配对桌面端后手机可实时监控 agent 进度，agent 完成时推通知，随时从手机发后续指令。Android 通过局域网（Wi-Fi）连接，iOS 走 iCloud 同步。

6. **SSH 远程 Worktree**：把 agent 跑在远程高性能机器上（GPU 服务器、云主机），Orca 自动处理文件同步、git 操作和端口转发，本地 IDE 体验不变。

7. **Orca CLI**：agent 本身也能驱动 Orca——`orca worktree create`、`orca snapshot`、`orca click`、`orca fill` 等命令，把整个工作流脚本化，适合 CI/CD 或 agent 自主决策场景。

## 适用人群

- 同时用 2 种以上 AI 编程 agent（Claude Code + Codex + OpenCode 等）做并行任务的开发者
- 前端 / 全栈开发者：Design Mode 浏览器 + 拖文件进 agent 提示的组合非常高效
- 小团队 / 独立开发者：想替代「终端 + VS Code + 浏览器 + GitHub Web」的组合，用一个 app 管所有事
- 需要把 agent 跑在远程 GPU 机器（SSH worktree）的 ML 工程师
- 想在手机上跟踪 agent 进度的远程办公者（iOS App Store 免费）
- **不适合**：只用单个 agent 且始终盯着终端的人；不想离开 VS Code 工作流的人；对 8600+ open issues 背后的早期项目质量有顾虑的企业用户（个人/团队完全没问题）

## 如何使用（具体步骤）

**1. 安装桌面端**

```bash
# macOS（Homebrew）
brew install --cask stablyai/orca/orca

# macOS（手动）
# 从 https://github.com/stablyai/orca/releases/latest 下载
# Apple Silicon: orca-macos-arm64.dmg
# Intel:         orca-macos-x64.dmg
# 解压后拖到 /Applications

# Windows
# 下载 orca-windows-setup.exe，运行时 SmartScreen 会警告
# 点 More info → Run anyway（SignPath 签名版在 Releases 页可选）

# Linux（Arch / AUR）
yay -S stably-orca-bin
# 或下载 orca-linux.AppImage
chmod +x orca-linux.AppImage
./orca-linux.AppImage
```

**2. 安装移动 companion（可选）**

```bash
# iOS：App Store 搜索 Orca IDE（免费）
# Android：从 https://www.onorca.dev/download/android 下载 APK 直接安装
# 手机和电脑须在同一局域网（Wi-Fi），启动桌面端后手机 App 自动发现
```

**3. 连接你的 agent（按需）**

```bash
# Orca 支持 30+ 种 CLI agent，只要 agent 能在终端里跑，就能接
# 打开 Orca → New Agent → 选择 agent 类型（Claude Code / Codex / OpenCode / Pi 等）
# 按提示填入对应的 API key 或账号
# 例如 Claude Code：已安装的 claude CLI 会被自动检测
```

**4. 创建并行 worktree（核心工作流）**

```bash
# 打开一个 git 仓库（File → Open Project）
# 点击顶部 + 按钮 → Fan Out
# 输入提示词，例如：'实现一个 React 列表组件，支持虚拟滚动'
# 选择要并行跑的 agent（例如 Claude Code + Codex + OpenCode）
# Orca 自动创建 3 个隔离 git worktree，各 agent 独立运行
# 完成后在 Orca 里并排 diff，选中最优方案 → Merge
```

**5. 使用 Design Mode（前端开发）**

```bash
# Orca 内置浏览器（顶部工具栏 Browser 图标）
# 打开你要开发的网页，进入 Design Mode（点击画模式图标）
# 点击任意 UI 元素 → 自动把 HTML + CSS + 裁剪截图注入当前 agent 提示
# agent 直接拿到精确 DOM 上下文，无需手动复制选择器
```

**6. GitHub / Linear 工作流**

```bash
# 侧边栏 GitHub 图标 → 登录 → 浏览 PR / Issue
# 从任意 PR 或 Linear 卡片 → Open Worktree
# 在 worktree 里让 agent 修改代码 → Annotate AI Diff（在 diff 行上加评论）
# 评论自动发回 agent → agent 继续修改 → 提交 PR，全程不离开 Orca
```

**7. SSH 远程 worktree**

```bash
# Orca → New Remote Worktree → 输入 SSH host（例如 gpu-server）
# 自动同步文件、建立端口转发
# 在远程机器上跑 agent（需要 GPU 的任务）
# 本地 Orca 体验不变，自动重连
```

**小贴士**：
- 每个 worktree 完全隔离（独立 `.git` 目录），agent 崩溃不影响其他 worktree
- 终端滚动历史持久化，重启 Orca 后依然可回滚
- 支持 14 种语言界面（含简体中文），Settings → Language 切换
- Windows 版使用 SignPath Foundation 代码签名，Releases 页有签名说明
- 所有 agent 会话记录保存在本地，无账号系统，无强制遥测（可关闭）
