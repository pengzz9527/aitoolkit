### [pxpipe — 将代码上下文转为图片，削减 60% LLM Token 成本](https://github.com/teamchong/pxpipe)
开发者 teamchong 发布 **pxpipe**，一个本地代理工具，通过将 Claude Code 等 LLM 应用中的冗长上下文（系统提示、工具文档、历史消息）渲染为紧凑的 PNG 图像来**大幅减少 Token 消耗**。核心原理：图像的 Token 成本由像素尺寸决定，而非文本长度——密集内容（代码、JSON、工具输出）在图像中可达到约 3.1 字符/image-token，而纯文本仅约 1 字符/text-token。实测数据显示，**25,000 文本 Token 可压缩为约 2,700 图像 Token**，整体成本削减高达 60%。pxpipe 在工作流中作为透明代理运行，自动判断何时需要转换，对稀疏或小请求则不做干预。这是一个极具巧思的"非模型层面优化"思路。（GitHub ⭐174，HN 211 点赞）
