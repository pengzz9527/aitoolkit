### [Constraint Decay: LLM Agent 在后端代码生成中的脆弱性](https://arxiv.org/abs/2605.06445)
一篇来自学术界的重要论文揭示了 LLM Agent 在生成长代码时的核心缺陷："约束衰减"（Constraint Decay）——即随着生成代码长度的增加，模型逐步遗忘初始约束条件的问题。实验表明，即使是最先进的 LLM Agent，在生成超过 200 行的后端代码时，满足所有初始约束的成功率不足 30%。这项工作对 Agent 驱动的软件开发模式提出了严肃的可靠性质疑，并为后续研究指明了改进方向。（HN 152 点赞，May 23）
