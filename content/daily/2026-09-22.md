### Kev —— 基于 Qwen3.5 的微型 Jev 家族决策模型

由 Jared Palmer 开源的 **Kev** 是一个「微型 Jev 式」决策模型家族，构建于 Qwen3.5 之上，延续了近两日 OpenJev 引发的双系统架构热潮。Kev 的核心理念是：**不依赖重型框架，而是用轻量级模型家族实现「快/慢双轨」决策切换**——一个负责高吞吐直觉响应，另一个在需要时接管深度推理。项目支持自定义模型组合策略，开发者可根据场景灵活配置快慢比例。Kev 在 HN 获得 **384 点赞**，社区对其「小型模型也能承载双系统架构」的设计思路评价积极。（[GitHub](https://github.com/jaredpalmer/kev)，HN 384 点赞）

### Foremerge —— 捕获并行 Coding Agent 间意图冲突（Show HN）

Show HN 项目 **Foremerge** 解决了一个日益突出的问题：当多个 AI Coding Agent 并行工作时，它们可能做出相互矛盾的决策——例如 Agent A 重构了函数签名，Agent B 仍按旧签名调用，导致 CI 静默失败。Foremerge 通过监控并行 Agent 的操作轨迹，在提交前识别并标记潜在意图冲突，提供自动合并建议。该项目虽处于早期阶段（**7 条评论**），但精准切中了多 Agent 协作时代的核心痛点。（[GitHub](https://github.com/naw103/foremerge)，Show HN）
