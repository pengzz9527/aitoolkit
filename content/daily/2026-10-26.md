## 🛠️ 新工具

### Cloudflare 开源 security-audit：把编码 Agent 变成安全审计员

**链接:** [https://github.com/cloudflare/security-audit-skill](https://github.com/cloudflare/security-audit-skill)

**描述:** Cloudflare 将其内部漏洞挖掘流水线的「种子版本」开源为单个 Agent Skill。它把一次完整审计拆成六个阶段：侦察建模（产出 `architecture.md` 与 `coverage-ledger.json`）、按覆盖账本分派隔离的「猎手」Agent、对每个候选漏洞交给全新验证 Agent 尝试反驳、结构化输出 `findings.json`、再由新 Agent 独立校验源码断言，最后由已验证记录派生 `REPORT.md`/`FINDINGS-DETAIL.md`。结论被严格区分为 confirmed / needs_validation / rejected 三档。今日 GitHub 单日新增 2.8k+ 星，总星数已约 4.7 万。

**影响力:** 「多阶段 + 独立复核 + 可机器校验的中间产物」正在成为 Agent 做高风险工作的标准范式，安全审计是最先被工业化的场景之一。

### VoiceStudio：完全本地的开源 ElevenLabs 替代品

**链接:** [https://github.com/debpalash/VoiceStudio](https://github.com/debpalash/VoiceStudio)

**描述:** 一个桌面端语音工作台，覆盖声音克隆、声音设计、视频配音、听写、转写与有声书批量生产，官方宣称支持 646 种语言。默认引擎为 `k2-fsa/OmniVoice`，全部可在本地硬件运行，远程服务可选；同时提供 Local API 与 MCP 接口，便于 Agent 调用。一条命令即可安装（macOS/Linux/Windows 均有脚本）。

**影响力:** 语音克隆的能力边界被拉到「笔记本可跑」，「数据不出本机」也让它在隐私敏感行业具备直接落地可能。

### Cerebras 公开万亿参数模型推理方案：59 片晶圆跑 Kimi K3

**链接:** [https://www.cerebras.ai/blog/how-we-deploy-trillion-parameter-frontier-models-on-cerebras](https://www.cerebras.ai/blog/how-we-deploy-trillion-parameter-frontier-models-on-cerebras)

**描述:** 单片 WSE-3T 只有 44GB 片上内存，而万亿参数模型的权重就需要 TB 级。Cerebras 详细拆解了如何把约 3 万亿参数的开源模型 Kimi K3（69 层线性注意力 + 24 层全注意力）以 4bit 权重量化、8bit KV cache 切分到 59 片晶圆上：线性注意力层每片放 2 层，全注意力层每片 1 层并预留 KV cache 空间，晶圆间仅传递激活值、走 RDMA over Ethernet 流水线执行。文中同时给出 Kimi K3 的成绩：Terminal-Bench 2.1 88.3%（GPT-5.6 Sol 为 88.8%）、BrowseComp 91.2%（Sol 为 90.4%）。

**影响力:** 这是罕见的高透明度超大模型部署工程公开课，也在证明「开源万亿参数模型 + 专用推理硬件」组合已能对标闭源前沿模型。
