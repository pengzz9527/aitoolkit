## 🛠️ 新工具

### [Axe — 12MB 二进制文件，取代你的 AI 框架](https://github.com/jrswab/axe)
**Axe** 是一款面向单任务 AI Agent 的轻量级 CLI 工具，采用 TOML 配置文件定义每个 Agent 的系统提示和模型选择。与当前主流 AI 工具假设用户需要"长会话+大上下文窗口"的设计不同，Axe 借鉴 Unix 哲学——每个 Agent 只做一件事并做好。支持从管道、Git hooks、Cron 或终端触发，单个二进制仅 12MB，适合嵌入自动化工作流。（HN 227 点赞）

### [Hyperbrowser MCP Server — 让 AI Agent 通过浏览器连接互联网](https://github.com/hyperbrowserai/mcp)
**Hyperbrowser** 推出了官方的 Model Context Protocol (MCP) Server，让 AI Agent 能够直接通过浏览器进行网页抓取和结构化数据提取。对于需要实时浏览互联网、获取动态内容的 AI Agent 而言，这一 MCP Server 提供了标准化的接入方式，填补了"静态知识"与"实时信息"之间的缺口。（HN 63 点赞）

### [Mcp-Agent — 用 MCP 构建高效的 Agent 应用](https://github.com/lastmile-ai/mcp-agent)
**Mcp-Agent** 由 Last Mile AI 开发，提供了基于 Model Context Protocol 的最简 Agent 构建方式。支持 map-reduce、编排器、评估器-优化器、路由器等可组合的 Agent 模式，只需两分钟即可上手。更独特的是，它允许将 Agent 本身暴露为 MCP Server，实现了 Agent 之间的互操作性。（HN 80 点赞）

## 🔬 开源项目

### [Evolving Agents Framework — 自主演化的 Agent 生态系统](https://github.com/matiasmolinas/evolving-agents)
**Evolving Agents** 是一套面向自主演化 Agent 生态系统的工具包，支持 Agent 从经验中学习、协作、构建新能力，并在定义的安全边界内运行。项目包含了 Agent 总线、智能内存管理等 12 个子系统的完整组件库，代表了对当前 Agent 框架"静态配置"范式的突破——让 Agent 具备持续进化的能力。（HN 139 点赞）

### [Rowboat — 带记忆的开源 AI 同事](https://github.com/rowboatlabs/rowboat)
**Rowboat** 是一款开源的桌面 AI 同事，核心特色是内置"记忆"系统——它会将用户的工作内容索引为动态知识图谱，并基于此主动协助完成任务。与仅凭对话历史工作的 AI 助手不同，Rowboat 真正理解用户的工作上下文，适合需要长期协作的开发者和知识工作者。（Launch HN，66 点赞）

### [AgentKit — 原生支持 MCP 的 JavaScript Agent SDK](https://github.com/inngest/agent-kit)
**AgentKit** 是 Inngest 推出的 JavaScript/TypeScript Agent SDK，原生支持 Model Context Protocol，让 JS 生态中的开发者能够以最少代码构建具备工具调用能力的 AI Agent。它的出现标志着 MCP 协议正在快速渗透到各个编程语言生态，成为 AI Agent 工具调用的事实标准。（HN 64 点赞）
