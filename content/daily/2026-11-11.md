### [Vercel Labs agent-browser：把浏览器变成 Agent 的一条条 shell 命令](https://github.com/vercel-labs/agent-browser)
**agent-browser** 今日新增 **712 ⭐**，总计 **49.8k ⭐**，Apache-2.0。它是 Vercel Labs 出品的**原生 Rust CLI**，给 AI Agent 一个可以逐步驱动的浏览器：`snapshot` 把页面返回成紧凑文本，每个元素带一个 `@e1` 这样的引用；Agent 对引用执行动作，再重新读页面确认结果，如此循环。关键设计是**浏览器在命令之间保持常驻**，所以每一步只是一次很短 shell 调用——这解决了 Agent 做网页操作时最烦的两个成本：上下文爆炸和会话状态丢失。安装只需 `npm install -g agent-browser` 加一次 `agent-browser install` 下载 Chrome for Testing，另有 Homebrew 与 Linux 包。在 United 起诉禁止 AI Agent 订票的同一天看到这个项目，对照意义很强：**Agent 操作网页的能力正在标准化，而拦不拦得住是另一回事**。（GitHub ⭐49.8k，Apache-2.0）
