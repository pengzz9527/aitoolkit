### [从 Lemmalog 看 LLM Agent 的记忆难题：为什么"记住"不够，需要"理解"](https://pwning.systems/posts/llm-memory-program-analysis/)
Lemmalog 项目揭示了一个 LLM Agent 领域的深层问题：当前的记忆系统大多停留在"存储-检索"层面，本质上是对历史对话的向量存档，而非对知识的结构化理解。当 Agent 在长期任务中遇到新信息推翻旧假设时，传统方案需要重新推理整个上下文，极易产生矛盾和幻觉。Lemmalog 的思路是将 Agent 记忆转化为一个带有溯源关系的知识图谱——每个结论都关联到其证据链，当证据变化时，下游结论自动失效。这种"程序化记忆"的理念如果得到更广泛的应用，将显著提升 Agent 在复杂任务（如漏洞研究、科学发现、法律分析）中的可靠性和可解释性，是构建真正可信 AI 系统的关键一步。
