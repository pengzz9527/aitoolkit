## 一、为什么需要周度复盘

先说一个很多人忽略的事实：**大脑不擅长记住细节，但擅长发现模式。**

你每天经历很多事，但一周后大部分细节都模糊了。只有定期回顾，才能把零散的经历串联成清晰的认知。这就是复盘的价值——它不是记录，而是从记录中发现**重复出现的模式和可改进的盲点**。

研究显示，有定期复盘习惯的人，目标达成率比没有复盘的人高47%（来自Journal of Behavioral Decision Making）。关键不在于写了多少字，而在于是否建立了**可追溯的追踪系统**。

但手工复盘有两个致命问题：
1. **坚持不了**——太耗时，一周后热度就降了
2. **看不清模式**——凭记忆整理，容易遗漏关键信息

用AI做复盘，解决的就是这两个问题：降低启动门槛，同时提供人类视角看不到的洞察。

## 二、搭建你的记录系统

复盘的前提是**有东西可以复盘**。很多人跳过这一步直接问AI，结果得到泛泛而谈的回复。正确的顺序是先建记录系统，再让AI分析。

### 步骤1：创建周记录模板

在你常用的笔记工具里（飞书文档、Notion、Obsidian都可以），创建一个每周一新建的周记录页面，模板结构如下：

```
## 📅 第X周（MM.DD - MM.DD）

### 🎯 本周核心目标
- [ ] 目标1：________
- [ ] 目标2：________
- [ ] 目标3：________

### 📝 每日要点记录
#### 周一
- 完成事项：
- 遇到的问题：
- 情绪状态（1-10）：

#### 周二
- ...

### 📊 数据追踪
- 工作时长：___小时
- 学习时长：___小时
- 运动次数：___次
- 睡眠平均：___小时

### 💡 本周洞察
- （周末填写）
```

关键是**只记要点，不写长篇大论**。每天的记录控制在5-10行，用关键词和短语，不要写成完整句子。这样周末汇总时才不至于看着头疼。

### 步骤2：建立低门槛的记录习惯

不要指望自己每天认真写日记。降低标准：

- **早上30秒**：写下今天最重要的1件事
- **晚上2分钟**：补充2-3个要点，记录情绪数字
- **周末20分钟**：填入目标完成情况和数据追踪

这个频率足够产生有质量的复盘材料，又不构成负担。

## 三、让AI做你的复盘分析师

现在进入核心环节——如何用ChatGPT把碎片记录变成有价值的洞察。

### 方法1：一键生成周复盘报告

每周日晚，把这一周的记录全选复制，发给ChatGPT，附上这段提示词：

```
我这一周的生活记录如下，请帮我生成一份结构化复盘报告：

[粘贴你的周记录]

请按以下格式输出：
1. 【目标完成度】逐条列出目标及完成情况，标注完成/部分完成/未开始
2. 【时间分配分析】根据记录推断你本周时间分配比例（工作/学习/休息/其他），指出最耗时的领域
3. 【行为模式识别】找出本周重复出现的3个正面行为模式和3个负面行为模式
4. 【情绪趋势】根据每日情绪数字，画出周情绪曲线并分析原因
5. 【下周建议】基于以上分析，给出3条具体可执行的改进建议
```

效果示例（简化版）：

```
1. 【目标完成度】
   - 完成项目A上线：✅ 完成
   - 读完《原子习惯》：🔄 部分完成（读到第4章）
   - 减脂1kg：❌ 未开始

2. 【时间分配分析】
   工作：55% | 学习：15% | 社交：12% | 休闲：18%
   → 休闲时间占比偏高，建议压缩至12%以内

3. 【行为模式识别】
   ✅ 正面：周三、周五效率最高（深度工作完成多）
   ❌ 负面：每天下午3-4点出现明显效率下降（刷手机时间增加）
   ❌ 负面：周日晚上普遍焦虑感上升（与下周压力相关）

4. 【情绪趋势】
   周一(6) → 周二(7) → 周三(8) → 周四(7) → 周五(6) → 周六(9) → 周日(5)
   → 典型"周日低谷"，建议周六安排轻松活动作为缓冲

5. 【下周建议】
   - 将深度工作安排在周三上午，利用效率高峰
   - 每天下午3点设置"手机锁定时段"（20分钟）
   - 周日中午安排户外活动，避免宅家导致情绪下滑
```

**这就是AI复盘的价值**——你看到了自己的模式，但这些模式是你自己看不到的。

### 方法2：对比多周数据发现长期趋势

单周复盘是快照，多周对比才是趋势。当你积累了3-4周的记录后，做一次深度分析：

```
这是我这四周的复盘摘要：

第1周：[粘贴周报内容]
第2周：[粘贴周报内容]
第3周：[粘贴周报内容]
第4周：[粘贴周报内容]

请分析：
1. 哪些行为模式持续存在？哪些有改善？
2. 情绪最低谷通常出现在哪一天？原因是什么？
3. 目标完成率的变化趋势如何？
4. 基于4周数据，制定下一月的改进重点
```

这种跨周对比能帮你识别真正的变化，而不是被某一周的波动误导。

## 四、自动化：让复盘变成习惯

手动复制粘贴毕竟是体力活，我们可以把它变成半自动化流程。

### 方案1：设定每周提醒

在你的日历或手机里设置一个固定提醒——比如每周日晚8点，标题写「复盘时间」。配套的提示词可以存成一个快捷指令：

```
请帮我复盘本周记录：

[自动带入本周笔记链接或内容]

格式要求：
1. 目标完成度
2. 时间分配分析
3. 行为模式识别
```

连续21天后，这会变成一个自动触发的习惯，不需要额外意志力。

如果你用Notion或飞书，可以设置一个简单的模板按钮——每次点击自动生成新的一周页面，带上固定的结构。这样你只需要填内容，不用操心格式。

## 五、进阶：个性化复盘维度

基础模板适合所有人，但每个人的成长重点不同。根据你的核心关注领域，可以增加专属维度：

### 职场成长型
```
新增维度：
- 本周技能提升：学了什么新东西
- 关键对话记录：重要沟通的要点
- 上级反馈：收到的评价和建议
- 下一步行动：为了晋升/转岗需要做什么
```

### 学习精进型
```
新增维度：
- 今日输入：看了什么书/文章/课程
- 核心收获：一句话总结今天学到的最重要的事
- 输出检验：有没有应用所学？效果如何？
- 遗忘预警：哪些内容已经模糊需要复习？
```

### 生活平衡型
```
新增维度：
- 社交质量：本周和谁进行了深入交流
- 健康指标：睡眠、运动、饮食是否达标
- 财务记录：本周支出分类和异常情况
- 关系维护：有没有给重要的人发消息/打电话
```

你可以把专属维度加进周记录模板，让AI在复盘时同时关注这些维度。

## 六、常见坑和避坑指南

### 坑1：记录太详细，反而不想复盘
**症状**：每周花了30分钟写记录，周末看到厚厚一篇笔记就放弃复盘了。
**解法**：严格限制每日记录长度，5-10行就够了。AI不需要完整句子，关键词就能提取足够信息做分析。

### 坑2：只记录不反思
**症状**：每周都填了模板，但没仔细看AI的复盘报告，等于白做。
**解法**：复盘报告生成后，至少花5分钟仔细阅读，并在"下周建议"部分选择1-2条立刻执行。**不改进行为的复盘毫无意义。**

### 坑3：目标定太多，永远完不成
**症状**：每周设5-6个目标，最后全部飘红，产生挫败感。
**解法**：每周核心目标不超过3个，且必须满足"可验证完成"的标准。与其写"锻炼身体"，不如写"完成3次30分钟以上运动"。

### 坑4：过度依赖AI，失去自主判断
**症状**：完全照搬AI的建议，没有自己的思考。
**解法**：把AI当作分析助手，不是决策者。AI指出模式，你来决定是否接受。如果某条建议明显不符合你的实际情况，跳过它。
