## 一、简历优化：从"已读不回"到"面试邀约"

简历是求职的第一道坎。大多数人简历的问题是：**经历写得太泛、成果没有量化、关键词没对齐岗位要求**。AI 可以帮你逐一解决。

### 1.1 用 AI 提取岗位关键词

先别急着改简历。第一步是把目标岗位描述扔给 ChatGPT，让它提炼出真正的筛选标准：

> **提示词：**
> ```
> 你是资深 HR，帮我分析以下岗位描述的核心关键词。列出：
> 1. 硬性技能要求（不会就不行）
> 2. 加分技能要求（会了加分）
> 3. 软素质关键词（团队协作、抗压等）
> 4. 行业背景要求
> 
> 岗位描述：
> [粘贴 JD]
> ```

有了这份关键词清单，你就能针对性地调整简历内容，让简历和岗位描述在关键词层面高度对齐——HR 第一轮筛选其实就是关键词匹配。

### 1.2 针对每个经历做"STAR 润色"

这段是核心操作。不要直接把整个简历扔给 AI 去写——**要分段处理**，每一段工作经历单独优化：

> **提示词：**
> ```
> 用 STAR 法则重写以下简历经历，要求：
> - 突出量化成果（用数字说话）
> - 每段控制在 2-3 行
> - 使用强动词开头（主导/推动/优化/搭建）
> - 语气符合互联网行业风格
> 
> 背景信息：
> [写出你的原始经历描述]
> 
> 目标岗位：数据分析师
> ```

AI 生成的结果通常需要 2-3 轮迭代。你可以追加："成果数字不够有说服力，帮我重新组织"或"语气太啰嗦，删掉修饰词"。

> 💡 **小技巧：** 生成后把结果贴回 [198007.xyz 的 JSON 格式化工具](https://198007.xyz/tools/json-formatter/) 检查格式——有些招聘系统要求简历上传为 JSON 格式时，格式规范很重要。

### 1.3 简历 ATS 兼容性检查

很多招聘系统用 ATS（Applicant Tracking System）自动筛选简历。AI 可以帮你预测通过率：

> **提示词：**
> ```
> 假设你是 ATS 简历筛选系统，评估以下简历内容与目标岗位的匹配度。按 0-100 打分，并给出：
> 1. 匹配得分及原因
> 2. 丢失的关键词
> 3. 被扣分的表达方式
> 4. 前三优先修改项
> ```

## 二、求职信：再也不用手写

大部分招聘平台（如 BOSS 直聘、LinkedIn）的求职信打开率远高于简历。但问题是——没人愿意每家公司写一封。

用 AI 批量生产定制化求职信的核心方法：**模板 + 变量替换**。

### 2.1 建立你的求职信模板

> **提示词：**
> ```
> 帮我写 3 种风格的求职信模板：
> 1. 专业稳重版（适用于传统行业/外企）
> 2. 热情主动版（适用于创业公司/互联网)
> 3. 技术聚焦版（适用于技术岗位）
> 
> 我的背景：[简述你的核心经历和技能]
> 占位符用 {{公司名称}} {{岗位名称}} {{具体项目}} 表示
> ```

拿到模板后，每次投递前只需简单替换变量，再让 AI 针对公司特色做微调。

> **提示词：**
> ```
> 在求职信模板中，增加一段提及目标公司的内容，表达我对这家公司的了解。以下是公司信息：
> [粘贴公司官网/产品/近期新闻]
> ```

### 2.2 附上作品集文案

如果你的岗位需要作品集（设计、文案、数据分析等），求职信里附上一句话说明作品集亮点非常加分：

> **提示词：**
> ```
> 针对 [岗位名称]，写一句 20 字以内的作品集亮点介绍，用于求职信中附在作品集链接前。要求简洁有力。
> ```

## 三、模拟面试：把 AI 当成面试官

这是 AI 求职最被低估的功能——**用 AI 做 1v1 模拟面试**。它不会不耐烦，不会评价你，可以随时喊停重来。

### 3.1 行为面试模拟

> **提示词：**
> ```
> 你是某大厂的高级面试官，现在为我模拟一场行为面试。
> 
> 岗位：产品经理（3-5年经验）
> 面试风格：追问型（每道题都会追问 2-3 层）
> 面试时长：30 分钟
> 
> 规则：
> 1. 一次只问我一个问题
> 2. 我回答完之后，你给我反馈（优点+缺点+改进方向）
> 3. 然后追问下一个问题
> 4. 面试结束后，给我一个综合评分和改进建议
> 开始吧
> ```

用这个模式，AI 可以扮演你需要的任何面试角色——从技术面到 HR 面到压力面。

### 3.2 技术面试：系统设计/代码题

如果你是程序员，可以让 AI 出题并评估你的答案：

> **提示词：**
> ```
> 你是一个资深后端面试官，针对 3 年经验的后端开发岗位，出一道系统设计题。先出题，我回答后你：
> 1. 评价我的设计思路
> 2. 指出我遗漏的关键模块
> 3. 给出参考方案
> 4. 按 BAT 标准打分（0-10）
> 5. 给出下一步学习建议
> ```

### 3.3 制作你的"面试问题库"

面试前，让 AI 根据你的简历生成预测问题清单：

> **提示词：**
> ```
> 基于我以下简历内容，预测面试官可能问的 10 个问题，按可能性从高到低排列。对每个问题附上回答思路和需要准备的素材/数据。
> 
> 简历：
> [粘贴简历核心内容]
> ```

这份清单就是你的面试备考资料——对着它练 3 遍，面试表现能提升一大截。

## 四、公司背调：AI 帮你做功课

面试前了解公司，能让你在回答"你为什么想来我们公司"时脱颖而出。AI 可以快速帮你整理公开信息：

### 4.1 快速了解一家公司

> **提示词：**
> ```
> 帮我搜集 [公司名称] 的以下信息：
> 1. 核心业务和盈利模式
> 2. 最近半年的大新闻/融资/产品发布
> 3. 竞争对手和行业地位
> 4. 公司文化特点（从公开员工评价推断）
> 5. 该岗位面试的常见考察重点
> 
> 来源要求：只基于可验证的公开信息，不要编造
> ```

### 4.2 准备"你有没有什么问题想问"

面试结尾的提问环节，是加分的关键时刻：

> **提示词：**
> ```
> 我要面试 [公司名称] 的 [岗位名称] 岗位，帮我构思 5 个有深度的问题问面试官。要求：
> - 显示我对公司和行业做了功课
> - 不要问"福利待遇"这种 HR 环节的问题
> - 2 个关于业务方向，2 个关于团队协作，1 个关于成长路径
> ```

## 五、Offer 谈判：AI 帮你算

收到 Offer 后别急着签。用 AI 做谈判支持：

> **提示词：**
> ```
> 我收到了一份 offer，以下是信息：
> - 公司：[名称]
> - 岗位：[名称]
> - 薪资：[数字]（含股票/期权）
> - 地点：[城市]
> - 我已工作 [N] 年
> 
> 帮我：
> 1. 参考行业水平和城市生活成本，评估这个 offer 的竞争力
> 2. 给出 3 个有说服力的谈判理由（基于我的背景和技能）
> 3. 设计谈判话术（email 版本和电话版本各一个）
> ```
