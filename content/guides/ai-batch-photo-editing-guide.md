你是不是也遇到过这种崩溃场景：拍了几百张照片要发朋友圈九宫格，一张张调亮度、裁切比例、加水印，折腾到半夜还没弄完；或者做电商需要给商品图统一换白色背景，一张手动抠图要 5 分钟，100 张就是 8 个小时……

## 一、批量调色：一张调好，全部套用

### 场景

你参加了一场活动，拍了 200 张照片，光线条件差不多，每张都需要稍微提亮、增加对比度、暖色调一点。一张张调？那得调到明年。

### 实操步骤

**第 1 步：用 ChatGPT 生成调色参数**

把一张典型照片发给 ChatGPT（或者描述照片的色调情况），让它告诉你具体的调整参数：

> **指令模板：**
> "我有一张活动现场照片，整体偏暗、颜色发灰。我想让照片更明亮温暖，请告诉我用哪些参数调整？需要提亮多少、对比度加多少、饱和度怎么调？"

ChatGPT 会给你一个类似这样的参数列表：
- 曝光度：+0.4
- 对比度：+15
- 高光：-20
- 阴影：+30
- 色温：+10（偏暖）
- 饱和度：+10

**第 2 步：用免费工具批量应用**

推荐用 [Squoosh](https://squoosh.app/)（Google 出品，免费在线）或 [Photopea](https://www.photopea.com/)（在线版 Photoshop）。

以 Photopea 为例：

1. 打开 Photopea，点击 `文件 → 打开`，一次性选中所有需要处理的照片
2. 在图层面板右侧找到`图层 → 新建调整图层 → 曲线`，按照 ChatGPT 给的参数设置
3. 点击 `文件 → 自动 → 动作`，把刚才的调整保存为一个"动作"
4. 再次进入 `文件 → 自动 → 批处理`，选择刚才保存的动作，指定输出文件夹
5. 点击确定，200 张照片自动处理完毕

**第 3 步：用 ChatGPT 优化批量脚本（进阶）**

如果你经常需要批量调色，可以让 ChatGPT 帮你写一个 Python 脚本：

> **指令模板：**
> "请帮我写一个 Python 脚本，使用 Pillow 库批量处理一个文件夹里的所有 JPG 照片。要求：每张提亮 20%、对比度增加 15%、饱和度增加 10%，处理后的照片保存到新文件夹。"

ChatGPT 会给你完整的代码，你只需要：
1. 安装 Python（如果还没有的话）
2. 运行 `pip install pillow`
3. 把照片放进指定文件夹
4. 执行脚本

整个过程大约 10 分钟就能搞定 200 张照片的调色。

## 二、批量抠图换背景：电商必备技能

### 场景

你需要给 50 件商品换上统一的白色背景，用于电商平台上架。手动用 PS 抠图？一天都搞不定。

### 实操步骤

**第 1 步：用 AI 抠图工具批量处理**

目前有几个优秀的免费 AI 抠图工具：

- **Remove.bg**：上传即抠，免费版每次 1 张高清图
- **Clipdrop.co**：支持批量，免费版有一定额度
- **Photoroom**：手机 App 端也很好用

**第 2 步：让 ChatGPT 帮你选择最佳工具**

> **指令模板：**
> "我有 50 张商品照片需要批量抠图并换成白色背景，要求免费或低成本方案，请推荐最适合的工具和操作步骤。"

ChatGPT 会根据你的具体需求给出方案。比如它会建议你：

1. 先用 Clipdrop 的批量功能处理前 20 张
2. 剩余的用 Python + rembg 库免费处理（ChatGPT 会给你代码）

**第 3 步：用 ChatGPT 生成 Python 批量抠图脚本**

> **指令模板：**
> "请帮我写一个 Python 脚本，使用 rembg 库批量抠除一个文件夹里所有 PNG/JPG 图片的背景，输出为透明背景的 PNG 文件。"

ChatGPT 生成的脚本大致如下：

```python
from rembg import remove
from PIL import Image
import os
import glob

input_folder = "photos/"
output_folder = "output/"
os.makedirs(output_folder, exist_ok=True)

for filepath in glob.glob(input_folder + "*.jpg"):
    img = Image.open(filepath)
    result = remove(img)
    name = os.path.basename(filepath).replace(".jpg", ".png")
    result.save(os.path.join(output_folder, name))
    print(f"Done: {name}")
```

运行前需要：`pip install rembg pillow`

**第 4 步：添加白色背景**

抠出来的透明 PNG 如果需要白色背景，让 ChatGPT 再加一行代码：

> "请在上面的脚本基础上，给每张抠好的图添加纯白色背景，而不是保持透明。"

ChatGPT 会告诉你如何合并白色图层和抠图结果。

### 场景

你的摄影作品经常被未经授权地使用，需要在每张照片上加上水印。100 张照片，每张手动加水印？

### 实操步骤

**第 1 步：设计水印文案**

> **指令模板：**
> "我是摄影师，需要给我的作品加半透明的水印。请帮我设计 3 种不同风格的水印文案，要求简洁、不影响画面美感、能体现版权信息。"

ChatGPT 会给你类似这样的建议：
- 角落小字："© 张三摄影 | 禁止转载"
- 斜向重复："张三是摄影"（半透明平铺）
- 右下角签名式："Zhang San Photography"

**第 2 步：用 ChatGPT 生成批量加水印脚本**

> **指令模板：**
> "请帮我写一个 Python 脚本，使用 Pillow 库给一个文件夹里所有 JPG 图片的右下角添加半透明文字水印。水印文字是'© 张三摄影 | 禁止转载'，字体大小根据图片宽度自适应，透明度 40%。"

ChatGPT 会生成完整的加水印脚本，包括：
- 自动检测图片尺寸并调整水印大小
- 设置半透明效果
- 指定水印位置（右下角）
- 批量遍历文件夹

**第 3 步：处理中文字体问题**

Windows 和 Mac 自带中文字体，Linux 服务器可能需要安装。ChatGPT 会告诉你如何获取和安装中文字体文件（如思源黑体）。

## 四、批量压缩和尺寸转换

### 场景

200 张照片要发到微信群，每张 5MB，根本传不动。需要压缩到 500KB 以内，同时保持可接受的画质。

### 实操步骤

**第 1 步：用 ChatGPT 确定合适的压缩参数**

> **指令模板：**
> "我有 200 张手机拍摄的照片（约 5MB 每张），需要压缩到 500KB 以内以便微信传输，同时保持肉眼可接受的画质。请告诉我应该用什么格式、什么压缩质量。"

ChatGPT 会建议：
- 格式：WebP 或 JPEG（质量 75-80%）
- 分辨率：如果原图是 4000x3000，压缩到 1920x1440 足够微信显示
- 批量处理工具推荐

**第 2 步：使用在线批量压缩工具**

推荐几个免费方案：

1. **Squoosh.app**（Google 出品）：支持批量拖拽，可选择 WebP/JPEG 格式，实时预览压缩效果
2. **TinyPNG/TinyJPG**：智能压缩，体积减少 50-80% 且画质几乎无损
3. **ImageOptim**（Mac）：拖入文件夹即可批量处理

**第 3 步：用 ChatGPT 生成命令行批量压缩脚本**

> **指令模板：**
> "请帮我写一个 Bash 脚本，使用 ImageMagick 的 convert 命令，把一个文件夹里所有的 JPG 图片压缩到最大宽度 1920 像素、质量 75%，输出到新文件夹。"

ChatGPT 会给你类似这样的脚本：

```bash
#!/bin/bash
mkdir -p compressed
for img in *.jpg; do
    convert "$img" -resize 1920x1920\> -quality 75 "compressed/$img"
done
echo "压缩完成！"
```

## 六、完整工作流：从拍照到发布一站式搞定

### 终极场景

你参加了一场行业峰会，拍了 300 张照片，需要在 2 小时内选出 20 张发到公众号。

**用 AI 的完整流程：**

1. **第 1 分钟：导入 + 初筛**
   把所有照片导入电脑，让 ChatGPT 写一个脚本，用图像相似度算法找出重复/模糊的照片并标记出来

2. **第 5 分钟：智能选图**
   把候选照片的描述发给 ChatGPT：
   > "以下是 300 张照片的文件名和简单描述（由 AI 自动生成），请帮我选出 20 张最适合发公众号的，要求包含：会场全景 3 张、演讲者特写 5 张、观众互动 4 张、细节图 8 张。"

3. **第 10 分钟：批量调色**
   选中的 20 张照片，用第一步的方法批量应用统一调色参数

4. **第 15 分钟：裁剪 + 加水印**
   用 ChatGPT 生成的脚本批量裁剪为公众号所需的 2000×1200 尺寸，并添加水印

5. **第 20 分钟：压缩 + 导出**
   批量压缩到合适的文件大小，准备上传

**从 300 张到 20 张精修成品，总耗时不到 30 分钟。** 如果不借助 AI，这个过程至少需要 3-4 小时。

## 七、常见坑和避坑指南

### 坑 1：批量处理后颜色不一致

**原因**：不同照片的原始白平衡不同，统一调色参数会导致部分照片偏色。

**解决**：先让 ChatGPT 帮你分析几张典型照片的色调差异，然后生成一个"自适应调色"脚本，根据每张照片的实际亮度自动调整参数幅度。

### 坑 2：抠图边缘有白边

**原因**：AI 抠图在毛发、半透明区域容易留下残留背景色。

**解决**：让 ChatGPT 生成一个后续处理脚本，用 Color Range 功能自动去除边缘杂色。

### 坑 3：批量压缩后图片模糊

**原因**：压缩率设置过高。

**解决**：用 ChatGPT 帮你做参数测试：
> "请帮我写一个 Python 脚本，对同一张图片分别用质量 60/70/80/90 压缩，输出 4 个文件并标注各自的大小，方便我对比选择最佳参数。"

### 坑 4：水印遮挡了图片主体

**原因**：水印位置和大小没有适配图片内容。

**解决**：用 ChatGPT 生成一个智能水印脚本，先检测图片中是否有文字区域（用 OCR），然后自动避开文字区域放置水印。
