## 一、为什么你需要正则表达式？

正则表达式（Regular Expression，简称 Regex）是一种用来匹配文本模式的工具。它看似复杂，但实际上你在日常生活中经常用到它——只是你可能不知道那个名字。

**常见场景：**

- 从一段文字中提取所有手机号：`1\d{10}`
- 验证邮箱格式是否正确：`^[^@]+@[^@]+\.[^@]+$`
- 把文档里所有的日期统一格式：`(\d{4})-(\d{2})-(\d{2})` → `$1年$2月$3日`
- 从HTML代码里提取所有链接：`href="([^"]+)"`
- 批量删除文本中的空行和多余空格

如果你会写正则，处理这些任务只需要几秒钟。但如果要手写正则，很多人会在语法上卡很久。

**用AI写正则，比你翻手册快10倍。** ChatGPT、Claude这些AI助手能听懂你的自然语言描述，直接生成可执行的正则表达式。你只需要说"帮我匹配所有中国大陆手机号"，AI就能给你正确的正则，还能解释每一部分的含义。

## 二、第一步：用AI生成正则表达式

### 2.1 明确你的匹配需求

在找AI之前，先想清楚你要做什么。以最常见的几个场景为例：

**场景1：提取手机号**
你需要从一段文字里找出所有中国大陆手机号（11位，以1开头，第二位是3-9）。

**场景2：验证邮箱格式**
你需要检查用户输入的邮箱是否符合规范。

**场景3：批量替换日期格式**
你有一批数据，日期格式是 `2026-09-02`，需要改成 `2026年09月02日`。

**场景4：提取特定模式**
你要从日志文件里提取所有的IP地址。

### 2.2 向AI描述你的需求

打开ChatGPT或Claude，用自然语言描述你的需求。以下是一些经过验证的提示词模板，直接复制使用：

**提取类需求：**
> 请帮我写一个正则表达式，从文本中提取所有中国大陆手机号。要求：只匹配11位数字，以1开头，第二位是3-9。请同时告诉我每个部分的含义。

**验证类需求：**
> 请帮我写一个正则表达式，用于验证邮箱格式。要求：符合标准邮箱格式，包含@符号和域名。请测试以下几个例子：test@example.com、invalid@、@example.com

**替换类需求：**
> 请帮我写一个正则表达式，把文本中的日期格式从 "2026-09-02" 替换为 "2026年09月02日"。请提供替换后的完整示例。

AI会给你一个完整的正则表达式，并用中文解释每一部分的含义。比如上面手机号的例子，AI可能会返回：

```
^1[3-9]\d{9}$
```

然后解释：
- `^` — 匹配字符串开头
- `1` — 以数字1开头
- `[3-9]` — 第二位是3到9之间的任意数字
- `\d{9}` — 后面跟着9个任意数字
- `$` — 匹配字符串结尾

### 2.3 快速验证你的正则

拿到AI生成的正则后，不要急着用到实际数据里。**先用在线工具测试一下**，确保它能按预期工作。

访问 **[正则表达式测试器](https://198007.xyz/tools/regex-tester/)**，把AI给你的正则粘贴进去，再把测试文本贴到输入框，就能看到实时匹配结果。如果匹配不对，直接把测试结果反馈给AI，让它调整：

> 这个正则匹配到了不需要的结果，比如下面这段文本里不应该匹配到 "12345678901"，请修正。

通过这种"生成→测试→修正"的循环，很快你就能得到精准的正则。

## 三、第二步：用正则做批量文本清洗

正则表达式不只是用来匹配，更重要的是用来做批量处理。下面教你几个最实用的清洗场景。

### 3.1 批量去重：清理重复条目

假设你有一份名单，里面有重复的名字：

```
张三
李四
张三
王五
李四
赵六
张三
```

**方法1：用AI生成去重规则**

> 请帮我写一个正则表达式，用来检测文本中连续重复的行。如果两行内容完全相同，只保留第一行。

AI可能不会直接给你去重的正则（因为去重通常需要程序逻辑），但它会告诉你用Python或Shell怎么实现：

```python
import re
text = """张三
李四
张三
王五
李四
赵六
张三"""
# 使用正则找出所有不重复的行
lines = re.sub(r'^(.+)$', r'\1', text, flags=re.MULTILINE)
# 再去重
unique_lines = list(dict.fromkeys(lines.split('\n')))
print('\n'.join(unique_lines))
```

**方法2：直接用在线工具**

更简单的方式是打开 **[文本去重工具](https://198007.xyz/tools/text-deduplicator/)**，把数据粘贴进去，一键去重。这个工具支持区分大小写和不区分大小写两种模式，还能选择保留首次出现还是末次出现的行。

### 3.2 批量替换：统一格式

你有一份数据，里面的日期格式不统一：

```
2026/09/02
2026-09-02
09-02-2026
2026.09.02
```

你需要把它们全部统一成 `YYYY-MM-DD` 格式。

**向AI提问：**
> 请帮我写一个正则表达式，把以下不同格式的日期统一替换为 YYYY-MM-DD 格式。需要支持的格式包括：2026/09/02、2026-09-02、09-02-2026、2026.09.02。请提供替换命令和示例。

AI会给你类似这样的答案：

```
匹配：(\d{4})[/-\.](\d{1,2})[/-\.](\d{1,2})
替换：\1-\2-\3
```

这意味着把所有 `XXXX/XX/XX` 或 `XXXX-XX-XX` 格式，统一替换为 `XXXX-XX-XX`。

**实操：** 打开 **[文本替换工具](https://198007.xyz/tools/text-replacer/)**，选择"正则替换"模式，粘贴AI给你的匹配规则和替换规则，一键批量替换。

### 3.3 批量提取：从杂乱文本中捞出关键信息

这是正则最强大的应用场景。假设你有一段会议记录：

```
【会议1】时间：2026-09-01 14:00，议题：Q3复盘，参会：张三、李四、王五
【会议2】时间：2026-09-03 10:00，议题：产品评审，参会：赵六、孙七
【会议3】时间：2026-09-05 16:00，议题：技术方案讨论，参会：周八、吴九、郑十、冯十一
```

你需要提取所有会议的时间、议题和参会人，整理成表格。

**向AI提问：**
> 请帮我写一个正则表达式，从下面的会议记录中提取会议时间、议题和参会人。每个会议的格式是固定的，以【会议N】开头。请提供匹配规则和提取方式。

AI会返回：

```
匹配整条会议记录：
\【会议(\d+)】时间：(\d{4}-\d{2}-\d{2}) \d{2}:\d{2}，议题：([^，]+)，参会：(.+)

捕获组：
$1 = 会议编号
$2 = 日期
$3 = 议题
$4 = 参会人员名单
```

然后你可以把匹配结果粘贴到 **[CSV在线查看器](https://198007.xyz/tools/csv-viewer/)** 中，快速预览整理后的结果。如果需要进一步分析，可以用 **[CSV SQL分析器](https://198007.xyz/tools/csv-sql-analyzer/)** 进行筛选和汇总。

## 四、第三步：进阶技巧——让AI帮你优化正则

### 4.1 性能优化：大数据量下的正则陷阱

当处理大量文本时，某些正则表达式会导致性能问题。常见的陷阱是"灾难性回溯"——正则引擎在匹配失败时会尝试无数种组合，导致程序卡死。

**如何避免：** 让AI帮你优化：
> 我这个正则表达式在处理大文本时非常慢，请帮我优化它，避免灾难性回溯。

AI通常会建议你：
- 用原子分组代替贪婪匹配
- 用字符类代替嵌套量词
- 用非捕获组减少开销

### 4.2 跨语言兼容性

正则表达式在不同编程语言中略有差异。比如Python的`re`模块和JavaScript的RegExp在有些细节上不一样。

如果你要把正则用在特定编程语言中，告诉AI：
> 我需要在Python的re模块中使用这个正则，请确认语法兼容性。

### 4.3 结合DuckDB做大规模数据清洗

如果你的数据量很大（几万行甚至更多），单个文件处理起来很慢，可以考虑用DuckDB来做批量清洗。DuckDB支持SQL中的正则表达式函数，可以直接在数据库层面完成文本提取和替换。

访问 [DuckDB Lab](https://duckdblab.org/zh/) 学习如何用DuckDB做高级数据清洗。比如：

```sql
-- 从文本中提取所有手机号
SELECT regexp_extract(text_column, '1[3-9]\d{9}') AS phone
FROM your_table;

-- 批量替换日期格式
SELECT regexp_replace(date_column, '(\d{4})[/-\.](\d{2})[/-\.](\d{2})', '\1-\2-\3')
FROM your_table;
```

## 六、常见问题速查

**Q1：AI生成的正则不对怎么办？**
直接告诉AI哪里错了，让它修正。比如："这个正则在匹配邮箱时，把 'test@.com' 也匹配了，请修复。"

**Q2：正则太复杂看不懂怎么办？**
让AI用中文逐条解释每个符号的含义，或者让它用类比的方式解释。

**Q3：我需要在Excel里用正则怎么办？**
Excel 365版本支持`REGEXEXTRACT`和`REGEXREPLACE`函数。把AI生成的正则放进函数参数即可。

**Q4：正则和Python脚本该怎么配合使用？**
AI可以同时给你正则表达式和Python代码。你只需要把正则粘贴到代码中，运行脚本就能批量处理。
