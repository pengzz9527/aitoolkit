## 一、AI 辅助市场调研与选品

选品决定了生意的上限。传统做法是翻数据后台、看 Best Seller 榜单、手动分析竞品，一个新手要花一周才能完成调研。用 AI，30 分钟搞定。

### 实操步骤

**第一步：让 AI 分析品类趋势**

把以下提示词发给 ChatGPT（建议用 GPT-4 或 Claude，分析更准）：

```
你是亚马逊美国站的资深选品分析师。请分析"kitchen gadgets"这个品类在2026年的趋势，包括：
1. 当前增长最快的5个子品类
2. 消费者在评论中抱怨最多的问题（痛点）
3. 价格带分布和利润空间估算
4. 品牌集中度——是否被大品牌垄断
基于以上分析，推荐3个有潜力的细分方向并给出理由。
```

ChatGPT 会根据它训练数据中的行业知识和评论洞察，给出一个分析框架。**这个分析不可能 100% 精确，但它能帮你快速缩小范围。** 拿到 AI 的建议后，再去亚马逊前台验证一遍，效率比从头开始高 10 倍。

**第二步：提取评论中的关键词**

选出一个细分方向后，让 AI 帮你分析竞品的评论：

```
请分析以下20条亚马逊用户的差评，提取出：
1. 出现频率最高的5个痛点关键词
2. 用户期望的改进方向
3. 可以用于Listing关键词的搜索热词
[粘贴差评内容]
```

> 💡 **小技巧：** 你可以用 198007.xyz 的 [CSV 查看器](/tools/csv-viewer/) 先把从后台导出的评论数据格式化，再逐批复制给 ChatGPT，避免一次性输入超出上下文长度。

## 二、AI 写 SEO 优化的产品标题

亚马逊的标题不光给人看，更给搜索引擎看。一个标题写得好不好，直接决定了你的产品有没有曝光。

### 实操指令

给 ChatGPT 这个提示词：

```
你是亚马逊Listing优化专家。请为我的一款产品撰写标题，要求：
- 产品：不锈钢便携保温杯，500ml容量，12小时保温
- 目标关键词：insulated water bottle, stainless steel, leak proof
- 主推站点：美国站
- 标题长度不超过200个字符
- 必须包含核心关键词+卖点+差异化优势
- 提供3个版本供选择（长标题/中标题/简洁版）
```

**结果处理：** ChatGPT 会给你 3 个版本。你可以在 198007.xyz 的 [在线 JSON 格式化工具](/tools/json-formatter/) 里整理 ChatGPT 返回的结构化数据，看起来更清晰。然后对照亚马逊的搜索建议，确认关键词没有被过度堆砌——自然才是王道。

### 要避开的坑

- ❌ **不要直接用 AI 的第一个版本**。AI 生成的关键词可能不是真实搜索热词，需要用 Helium 10 或卖家后台的 ABA 数据验证
- ❌ **不要超过字符限制**。亚马逊不同类目的标题长度限制不同，写之前查清楚
- ✅ **人工微调语序**：让 AI 生成后再自己读一遍，不通顺的地方手动改一下

## 三、AI 写五点描述与产品详情

五点描述（Bullet Points）是转化率的关键。用户扫一眼这五句话，就决定要不要继续看你的产品。

### 实操指令

```
你是一名亚马逊转化率优化专家。请为以下产品撰写五点描述：
产品：不锈钢保温杯，500ml，12小时保温
核心卖点：食品级316不锈钢、防漏设计、适合运动/通勤、可放入杯架

请遵循以下规则：
1. 每一点以核心卖点开头（加粗）
2. 每点包含1-2个具体使用场景
3. 融入3个以上的长尾关键词
4. 语气专业但不生硬
5. 每点控制在200字符以内
```

**进阶技巧：** 让 AI 为每一点写两个版本——一个偏功能型（适合 B2B 客户），一个偏生活方式型（适合 C 端消费者）。测试一周看哪个版本转化率高，保留效果好的。

## 四、AI 处理客户邮件与差评回复

差评是每个卖家的噩梦。回复得好，客户可能修改评价；回复得差，直接影响 listing 评分。但很多人不知道怎么说才得体。

### 差评回复模板

```
请写一封亚马逊差评回复，要求：
- 客户差评内容：[粘贴差评]
- 态度：诚恳道歉 + 说明改进措施 + 提供解决方案（退款或补发）
- 语气：专业、友善、不推卸责任
- 不要提及具体金额
- 不超过1000字符
```

**库存管理的补充建议：** 对于需要批量处理客户数据的场景，推荐配合 [DuckDB Lab](https://duckdblab.org/zh/) 做轻量级数据查询——把客户反馈表格导出后用 SQL 分析高频问题词，比手动翻效率高得多。

## 五、AI 翻译与多站点内容适配

如果你做多站点（美国站 + 欧洲站 + 日本站），翻译量巨大。AI 翻译的质量现在已经接近专业人工水平，关键是**给对上下文**。

### 实操指令

```
请将以下亚马逊产品描述翻译为德语，注意：
1. 保留SEO关键结构
2. 德语中"保温杯"使用"Isolierflasche"而非直接翻译
3. 适应德国消费者的语气（更直接、强调技术参数）
4. 长度不超过原文的120%
5. 标注出与中国站/美国站不同的文化敏感点

原文：[粘贴英文描述]
```

**文化适配比翻译更重要。** 比如日本站需要更礼貌的语气，欧洲站需要标注环保属性。每到一个新站点之前，让 AI 先分析该市场的文化特征，再根据分析结果调整文案。
