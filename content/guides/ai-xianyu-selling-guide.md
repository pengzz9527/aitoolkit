## 一、选品：让AI帮你找利润空间最大的品类

选品的核心逻辑就一个：**别人懒得做的事，你替别人做了，就能赚差价。**

用 ChatGPT 做选品，关键不是让它"推荐"，而是给它明确的限制条件，让它做结构化分析。

**实操指令：**

```
你是一个有5年闲鱼运营经验的选品顾问。请根据以下条件，帮我分析3个适合新手入手的闲鱼品类：

条件：
1. 无需囤货，一件代发或二手转卖模式
2. 客单价在50-200元之间
3. 复购率较高或需求稳定
4. 竞争对手文案水平普遍较差，有优化空间
5. 不需要特殊资质或授权

对每个品类，请列出：
- 该品类的供需缺口分析（为什么能卖）
- 目标用户画像（谁会买）
- 差异化切入点（怎么跟别人不一样）
- 预估利润率区间
```

ChatGPT 会给你一个结构化的选品报告。但光看不够，你需要验证——把它的建议扔进 [DuckDB Lab](https://duckdblab.org/zh/) 或者用 AI 帮你写一段 SQL 查询闲鱼公开数据来交叉验证。

## 二、文案：爆款标题+_description_是转化率的生命线

闲鱼搜索排名很大程度上取决于标题和描述的关键字匹配。**AI 的核心价值在这里：它能在30秒内生成50个不同角度的标题变体，而以前你需要花半小时想。**

### 第一步：生成爆款标题

```
请根据以下产品描述，帮我生成20个闲鱼标题，要求：

产品信息：[粘贴你的产品描述]
目标人群：[比如：租房党、学生党、宝妈]
情绪钩子：[比如：限时清仓、只此一件、搬家急售]

标题要求：
- 前10个字必须抓住眼球
- 包含搜索热词（如：全新、几乎无使用痕迹、急出）
- 不超过30个字
- 每条标题风格不同（实用型/悬念型/稀缺型/故事型）
```

生成的标题太多了怎么办？用 [198007.xyz 的文字计数器](https://198007.xyz/tools/text-counter/) 统计一下每个标题的字数和关键词密度，选出最优的。

### 第二步：写好描述

闲鱼描述的黄金公式是：**痛点 + 解决方案 + 信任感 + 行动指令**。

```
请帮我写一段闲鱼商品描述，要求：

产品：[具体产品信息]
购买理由：[为什么值得买]
成色说明：[新/二手/使用时长]
交易方式：[面交/快递/自提]
额外福利：[送配件/包邮/可小刀等]

描述风格：真诚接地气，像朋友推荐一样，不要广告腔。
```

**一个高阶技巧：** 把你选中的标题和描述复制出来，让 AI 扮演买家来看——"这段描述里你有什么疑问？你会担心什么？"——AI 会以买家视角指出描述的漏洞，你据此再改一轮，转化率至少提升 20%。

## 三、图片处理：一张好图抵得上十句文案

闲鱼图片的规则很简单：**首图决定点击，详情图决定信任。**

很多新手亏就亏在随手拍两张就挂上去——色差严重、背景杂乱、没有细节特写。

### AI 修图工作流

**第一步：批量抠图和去背景**

不用 Photoshop，用手机上的免抠图 AI 工具（比如美图秀秀的AI抠图、或者免费的 Remove.bg）把商品抠出来，放到干净的白色或渐变色背景上。这一步能让你的主图看起来像专业电商拍出来的。

**第二步：图片增强**

用 AI 图片工具（比如 ChatGPT 的 DALL·E 或者即梦 AI）对图片进行局部增强——把模糊的细节拉清晰、调整曝光、加产品标签文字。

**第三步：拼图和排版**

把多张细节图拼成一张长图，用 AI 工具自动生成统一的边框和标注。闲鱼允许上传最多9张图片，合理利用每一张：
- 图1：干净白底主图（吸引点击）
- 图2-4：多角度实拍（展示真实）
- 图5-6：细节特写（消除疑虑）
- 图7-8：包装/配件（增加价值感）
- 图9：交易说明（促单）

如果你需要做数据对比（比如不同品类的销量趋势），可以把闲鱼公开的搜索热度数据用 [198007.xyz 的 CSV 分析器](https://198007.xyz/tools/csv-sql-analyzer/) 导入 DuckDB 做可视化分析，比凭感觉选品靠谱得多。

## 四、回复话术：让AI替你当客服

闲鱼最烦人的不是卖东西，而是来回扯皮。一个高效的客服话术库能让你的时间成本降低 80%。

**第一步：建一个FAQ知识库**

```
根据闲鱼交易常见问题，帮我整理一份客服话术库，分类如下：

1. 还价类（太贵了、能便宜点吗、最低价多少）
2. 细节询问类（新旧程度、有没有磕碰、还能用吗）
3. 物流类（多久发货、发什么快递、包邮吗）
4. 售后类（收到有问题怎么办、能退换吗）
5. 警惕类（骗子话术应对、假转账识别）

每条话术要求：
- 语气亲切但不卑微
- 简洁有力，不超过3行
- 包含促成成交的暗示
```

**第二步：建立快捷回复模板**

把 AI 生成的话术存成文本片段，闲鱼客户端支持保存常用语。每次回复只需要选一下，几秒钟搞定。

**第三步：用AI做风险预警**

在每次对话前，把买家的消息发给 AI 快速过一遍：

```
请分析这段买家消息是否有异常风险，用"正常/可疑/危险"三级判断，并说明原因：

[粘贴买家消息]
```

常见的骗子套路：假链接确认、要求加微信交易、催促发货不付款、发二维码让扫码等。AI 对这些模式已经训练得很熟了，能快速给你警报。

## 五、运营复盘：让数据告诉你该做什么

很多人卖东西纯粹靠感觉——今天挂这个，明天换那个，从来没有系统地回顾过。

**用 AI 帮你做每周复盘：**

```
这是我本周闲鱼运营数据：
- 上架商品：X件
- 浏览量：XXX次
- 收藏数：XX个
- 咨询量：XX次
- 成交：X件
- 成交额：XXX元

请帮我分析：
1. 哪个品类的转化率最高？为什么？
2. 标题和描述有哪些可以优化的地方？
3. 下周应该重点卖什么？
4. 给出3条具体的改进建议
```

## 六、进阶：批量运营和自动化

当你跑通了单个品类的流程，下一步就是规模化。

**批量上架：** 用 AI 一次生成20个商品的完整上架信息（标题+描述+关键词），然后分批执行。

**关键词矩阵：** 同一个商品，用不同的关键词组合挂多个链接（注意不要重复挂完全相同的标题）。AI 可以帮你生成差异化的版本：

```
基于以下产品，生成5个不同关键词组合的上架方案：
产品：[产品信息]
要求：每个方案侧重不同卖点（功能型/价格型/稀缺型/场景型/礼品型）
```
