## 第一步：把广告平台的数据"喂"给 AI

各平台（抖音巨量、腾讯广告、百度 SEM、Google Ads）都能导出 CSV 或 JSON 格式的数据报告。先做好数据准备。

**实操步骤：**

1. 从广告后台导出**近 14 天**的投放数据（包含日期、渠道、素材 ID、展示量、点击量、消耗、转化数、GMV 等字段）
2. 如果导出的是 JSON 格式（比如 API 拉取的结果），先用 [JSON 格式化工具](/tools/json-formatter/) 检查格式是否正确，确认字段没有嵌套错误
3. 如果是 CSV，用 [CSV/SQL 在线分析器](/tools/csv-sql-analyzer/) 上传，先跑一条简单的 SQL 看数据完整性：

```sql
SELECT COUNT(*) as 总行数,
       COUNT(DISTINCT 渠道) as 渠道数,
       MIN(日期) as 最早,
       MAX(日期) as 最晚
FROM ad_data
```

如果某天的数据缺失，先补全或标注，再交给 AI。

---

## 第二步：让 AI 帮你算 ROI 和关键指标

原始数据里"消耗"和"GMV"是两个孤立的数字，AI 能帮你算出真正有意义的指标。

**实操指令（直接复制用）：**

```
我上传了一份广告数据 CSV，包含字段：日期、渠道、素材ID、展示量、点击量、
消耗（元）、转化数、GMV（元）。

请帮我：
1. 按渠道汇总：总消耗、总 GMV、ROI（GMV/消耗）、CPC（消耗/点击量）、
   CVR（转化数/点击量）、客单价（GMV/转化数）
2. 按素材 ID 汇总，找出 ROI 最高的前 5 条素材和最低的后 5 条素材
3. 按日期看整体 ROI 趋势，标出 ROI 突然下降的日期，并分析可能的原因
4. 输出一张 Markdown 表格，按 ROI 从高到低排序
```

**小技巧：** 如果数据量大（超过 5000 行），先在 [CSV/SQL 在线分析器](/tools/csv-sql-analyzer/) 里把数据按渠道分组聚合，再把聚合结果喂给 AI，能省 token 且结果更准。

## 第三步：素材效果归因——哪条素材真的有效

很多投放者的误区是"只看点击量"，但点击量高不代表 ROI 高。AI 能帮你做更细的归因。

**实操指令：**

```
基于上面的渠道和素材汇总数据，请帮我做素材归因分析：

1. 把素材按 ROI 分成三档：
   - 高效（ROI > 3）：标注特征，比如"前 3 秒有冲突画面"
   - 中效（1 < ROI < 3）
   - 低效（ROI < 1）：分析共同特征，比如"前 5 秒没有钩子"、"CTA 不明显"

2. 找出"高点击但低转化"的素材（点击率 > 均值但 ROI < 1），
   列出这些素材的 ID，并推测原因（落地页不匹配？人群不精准？）

3. 对每条高效素材，给出"为什么有效"的一句话总结
4. 对低效素材，给出 3 条具体的优化建议（改开头、换 CTA、调人群等）
```

**如果你有多条素材的视频链接或截图，直接贴给 AI，让它结合画面描述和数据分析。**

## 第四步：批量生成下一轮素材文案

复盘完数据，最直接的行动是换素材。AI 能根据高效素材的特征批量生成新文案。

**实操指令：**

```
基于上面分析出的高效素材共同特征：
- 前 3 秒有冲突或反常识画面
- 中间用具体数字强化信任
- 结尾 CTA 是"点击领取"而不是"立即购买"

请帮我生成 10 条新素材文案，每条 15 字以内，格式：
【开头钩子 + 中间数字 + CTA】
要求：
1. 覆盖 3 个不同人群（20-30 岁学生 / 30-45 岁宝妈 / 45+ 岁退休族）
2. 每条标注适用渠道（短视频 / 信息流 / 搜索）
3. 避免和现有素材文案重复，用不同的数字或场景切入
```

**批量替换技巧：** 如果文案里需要替换品牌名、价格等变量，生成后用 [文本替换工具](/tools/text-replacer/) 批量处理，不用手动一条一条改。

## 第五步：设定下一轮投放策略

数据复盘的终点不是报告，而是"下周怎么投"。让 AI 帮你把策略写出来。

**实操指令：**

```
基于本次复盘结果（高效渠道：X、低效渠道：Y；高效素材特征：Z），
请帮我制定下一轮 14 天的投放策略：

1. 预算分配：总预算 5 万，按渠道拆分配额，给出理由
2. 素材策略：用哪 3 条现有高效素材 + 新生成 5 条文案的组合测试
3. 人群定向：每个渠道建议的年龄 / 兴趣标签
4. 预算止损规则：如果某天 ROI 低于 1.2 持续 3 天，触发什么操作
5. 每日复盘指标：列出需要每天看的关键数字，以及达标线
```

## 避坑指南：广告数据复盘的 3 条红线

**1. 数据口径要先对齐。** 广告平台的"转化"和你实际收到的订单可能不一致（归因窗口、去重逻辑不同）。把平台的转化数和 CRM 里的实际订单数都喂给 AI，让它对比差异。

**2. 别只看 ROI，也要看 LTV。** 如果客单价低但用户会复购，短期 ROI 低不代表要停投。在指令里加一句："假设复购率为 30%，90 天 LTV 为首次客单价的 2.5 倍，重新计算 LTV 口径下的 ROI。"

**3. 时间戳别搞混。** 各平台的"日期"字段有的是 UTC 时间，有的是北京时间，导出时很容易错。用 [时间戳转换工具](/tools/timestamp-converter/) 把可疑的时间戳转成北京时间，确认后再分析。

## 总结：一次完整的复盘，1 小时搞定

以前做一次广告复盘，要手动拉数据、做透视表、写结论、出策略，至少 2 天。现在：

1. 导出数据 → 用工具检查格式（5 分钟）
2. 喂给 AI 算指标 → 出渠道和素材汇总（10 分钟）
3. 素材归因分析 → 找出高效/低效特征（15 分钟）
4. 批量生成新文案 → 文本替换工具处理变量（15 分钟）
5. 出下一轮策略 → 直接可执行的投放计划（15 分钟）

**核心思路不变：数据 → 洞察 → 行动。AI 只是把中间"翻译"的环节压缩到了最短。**
