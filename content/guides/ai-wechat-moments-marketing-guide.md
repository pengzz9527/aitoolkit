## 一、产品种草型朋友圈：让读者自己想来问

产品种草是朋友圈营销最核心的场景。关键不是"推销"，而是让读者看完产生"我也想要"的冲动。

### 操作步骤

**第一步：给 AI 输入产品核心信息**

打开 ChatGPT，输入：

```
我正在推广一个产品，请帮我写 5 条朋友圈种草文案。

产品信息：
- 产品名称：[填写产品名称]
- 核心卖点（1-3 个）：[填写卖点]
- 目标用户：[填写目标用户]
- 价格/优惠：[填写价格信息]
- 使用场景：[填写典型使用场景]

要求：
- 每条 80-150 字
- 开头要有"钩子"（引发好奇或共鸣）
- 不要像广告，像朋友在推荐
- 每条结尾加一句引导互动的提问
```

**第二步：调整语气和风格**

AI 第一版通常比较正式。用这个提示词让它改得更"朋友圈化"：

```
把上面第 [X] 条文案改得更口语化，要求：
- 加入一句个人使用感受（比如"我自己用了两周，确实..."）
- 用更短的句子，像微信聊天
- 加入 1-2 个合适的 emoji
- 不要出现"推荐""好物""绝了"这些被用烂的词
```

**第三步：配上合适的图**

朋友圈文案要配图。建议每张图配一条文案，不要九宫格配一条。图片选择：
- 产品实拍图（手机拍即可，真实感比精修更有信任度）
- 使用场景图（用户在使用中的照片）
- 对比图（使用前后的变化）

**关键技巧**：发朋友圈的最佳时间是中午 12:00-13:00 和晚上 20:00-22:00。用 [198007.xyz 的倒计时工具](/tools/countdown-timer/) 设置提醒，别错过黄金时间段。

## 二、客户案例型朋友圈：用真实故事代替硬广

客户案例是朋友圈里转化最高的类型。但很多人不知道怎么写——直接发客户反馈截图太生硬，写成完整故事又没精力。

### 操作步骤

**第一步：让 AI 帮你提炼故事框架**

```
以下是我的客户反馈（可以直接粘贴客户的原话）：
"[粘贴客户反馈]"

请帮我把这段反馈改写成一条朋友圈案例文案，要求：
- 用第三人称叙述（"我有一个客户叫小王..."）
- 突出客户原来的痛点
- 描述使用产品后的变化
- 结尾加入客户的真实感受
- 100-150 字
```

**第二步：增加真实细节**

AI 写的案例通常缺少细节。加这个提示词：

```
在上面文案中加入以下细节：
- 客户的具体行业/职业：[填写]
- 客户遇到问题的具体场景：[填写]
- 使用产品后具体的改变（数字/结果）：[填写]
- 客户现在的生活/工作状态：[填写]
```

**第三步：配上案例截图**

案例文案一定要配截图——聊天截图、收款截图、使用效果对比图。截图本身是最好的信任背书。

## 三、节日/热点型朋友圈：借势营销不踩雷

节日和热点是朋友圈曝光的最佳时机。但很多人要么错过，要么蹭得太生硬。

### 操作步骤

**第一步：提前规划节日节点**

用 AI 帮你列节日营销日历：

```
请列出 2026 年下半年（7-12 月）所有值得做朋友圈营销的节日和节点，包括：
1. 传统节日（中秋、国庆、双11、双12、元旦等）
2. 电商节点（618、双11、双12、年货节等）
3. 行业相关节点（根据你的行业）
4. 每个节点适合什么类型的朋友圈内容
输出格式：表格
```

**第二步：提前一周准备文案**

不要当天现写。提前用 AI 批量生成：

```
请为即将到来的 [节日名称] 写 3 条朋友圈文案：
- 节日前一天：预热型（引发期待）
- 节日当天：氛围型（蹭热度）
- 节日后一天：回顾型（制造紧迫感）

产品信息：[填写产品]
目标用户：[填写]
```

**第三步：热点快速反应**

遇到突发热点时，快速用 AI 生成蹭热点文案：

```
最近 [热点事件] 很火，请帮我写一条朋友圈文案蹭这个热点。要求：
- 自然关联到 [你的产品/服务]
- 不要硬蹭，要有合理的连接点
- 口语化，100 字以内
- 结尾加一句互动提问
```

**关键技巧**：热点文案要趁热发，一般 24 小时内效果最好。超过 48 小时就过时了。

## 四、AI 写朋友圈的常见坑

### 坑一：AI 味太重

症状：读起来像公众号文章，不像朋友圈。

解法：在提示词里明确说"用口语化表达，像在微信聊天"，并在 AI 输出后自己加一两个语气词（"说实话""真的"）。

### 坑二：频率太高变成刷屏

症状：一天发 5 条以上，被好友屏蔽。

解法：每天发 2-3 条为宜。用 [198007.xyz 的 Cron 表达式生成器](/tools/cron-builder/) 规划发圈时间，比如 12:00、18:00、21:00 各一条。

### 坑三：没有互动引导

症状：发完就没下文了。

解法：每条朋友圈结尾加一句互动问题，比如"你们遇到过这种情况吗？""有没有人试过这个方法？"评论区回复才是真正转化的开始。
