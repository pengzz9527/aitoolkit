## 正文

每天打开冰箱不知道做什么菜？点外卖吃腻了又担心营养不均衡？今天教你用 ChatGPT 实现真正的「智能菜谱生成」——不只是随便给几个菜名，而是根据你的口味偏好、身体指标、甚至冰箱里现有的食材，自动生成完整的一周健康食谱，精确到每道菜的热量、蛋白质、碳水比例。

这套方法我已经用了大半年，不仅帮自己解决了"今天吃什么"的世纪难题，还让家里人的饮食结构明显改善。整个过程不需要会写一行代码，只需要会用 ChatGPT 的文字对话功能。

### 第一步：准备你的个人饮食档案

好的菜谱推荐需要先了解"你是谁"。打开 ChatGPT，输入以下信息：

```
我需要你帮我制定一周的饮食计划。请先收集我的基本信息：

1. 我的基本情况：[性别]、[年龄]、[身高]cm、[体重]kg
2. 我的目标：[减脂/增肌/维持体重/改善睡眠/控制血糖等]
3. 我的饮食限制：[不吃辣/素食/海鲜过敏/乳糖不耐受等，没有就写无]
4. 我的口味偏好：[喜欢川菜/清淡/面食为主等]
5. 我每天几餐：[三餐/两餐/轻断食]
6. 我做饭的时间：[每天最多30分钟/愿意花1小时/完全不会做饭只能简单烹饪]
7. 我家冰箱常备食材：[鸡蛋、西红柿、鸡胸肉、大米等]

请根据以上信息先帮我估算每日所需热量和三大营养素比例。
```

ChatGPT 会基于 Mifflin-St Jeor 公式帮你计算基础代谢率（BMR），再结合活动系数给出每日总消耗量（TDEE）。比如一个 30 岁、身高 170cm、体重 70kg 的上班族，日常活动量中等，TDEE 大约在 2200-2400 千卡之间。

> 💡 **关键技巧**：如果你的目标是减脂，可以在 TDEE 基础上减少 300-500 千卡；如果是增肌，则增加 200-400 千卡。这个数值是动态的，建议每两周重新评估一次。

### 第二步：生成一周详细菜谱

有了个人档案后，让 ChatGPT 生成具体菜谱：

```
请根据上面的信息，为我生成接下来7天的完整食谱，要求：

1. 每天包含早餐、午餐、晚餐和一份加餐
2. 每道菜标注大致热量（±10%即可）
3. 每天的营养配比：蛋白质25-30%，碳水40-45%，脂肪25-30%
4. 不要重复的菜式，尽量使用不同食材
5. 标注每道菜的烹饪时间
6. 列出每天的采购清单（去重合并）

请用表格形式输出，方便我保存。
```

生成的结果大致如下：

| 日期 | 餐次 | 菜名 | 热量(kcal) | 烹饪时间 |
|------|------|------|-----------|---------|
| 周一 | 早餐 | 燕麦牛奶粥+水煮蛋 | 380 | 10分钟 |
| 周一 | 午餐 | 香煎鸡胸肉配西兰花糙米饭 | 620 | 25分钟 |
| 周一 | 晚餐 | 番茄豆腐汤+凉拌黄瓜 | 350 | 15分钟 |
| ... | ... | ... | ... | ... |

### 第三步：智能食材替换和弹性调整

现实情况是，计划赶不上变化。超市没货、临时加班、朋友聚餐……这时候需要 AI 帮你灵活调整：

**场景一：某样食材买不到**

```
周一午餐的鸡胸肉超市卖完了，请帮我替换成同等蛋白质含量的其他肉类，保持总热量和营养配比不变。
```

ChatGPT 会自动推荐替代品，比如换成瘦牛肉（蛋白质含量相近，铁含量更高）或鱼肉（优质蛋白且富含Omega-3）。

**场景二：当天不想做饭**

```
周三晚上我要加班，没法做饭。请把晚餐替换成方便的外卖选择，同时给出点餐时的注意事项。
```

ChatGPT 会建议你点轻食沙拉、蒸菜类或日式定食，并告诉你如何避免踩坑（比如酱汁单独放、米饭减半等）。

**场景三：食材余量管理**

```
冰箱里还剩半颗卷心菜、两个土豆、一块五花肉，明天早餐和午餐怎么安排比较合理？
```

这种"清冰箱"式的提问非常实用。ChatGPT 会根据现有食材推荐合适的菜谱，避免浪费的同时保证营养。

### 第四步：追踪和调整你的饮食数据

光有菜谱不够，还需要知道实际执行情况。这里有个很多人忽略的技巧：**用 AI 做饮食日记**。

每天吃完饭，拍张照片发给 ChatGPT（支持图片上传的版本），然后说：

```
这是今天的午餐，请帮我估算这份食物的热量和主要营养成分。
如果热量超标，请告诉我明天应该如何调整。
```

AI 能相当准确地识别常见食物并估算份量。虽然不如专业体脂秤精确，但对于日常追踪来说完全够用。

> 📊 **进阶用法**：把一周的饮食记录整理成 CSV 格式，导入本站的 [CSV-SQL 分析器](https://198007.xyz/tools/csv-sql-analyzer/)（基于 DuckDB WASM 引擎，浏览器内运行，数据不会离开你的设备），用 SQL 查询来分析你的饮食趋势。比如：
>
> ```sql
> -- 计算每天的平均热量摄入
> SELECT strftime('%Y-%m-%d', date) as 日期, 
>        AVG(calories) as 平均热量,
>        SUM(calories) as 当日总热量
> FROM diet_log
> GROUP BY date;
>
> -- 找出蛋白质摄入最低的日子
> SELECT * FROM diet_log 
> WHERE protein < 60 
> ORDER BY date DESC LIMIT 5;
> ```
>
> 这样你就能一目了然地看到自己的饮食模式，及时调整。

### 第五步：特殊场景定制

除了日常饮食，AI 菜谱还能应对很多特殊需求：

**孕期饮食**：
```
我怀孕28周了，需要高蛋白低糖的饮食方案。请给我一份适合孕晚期的三天食谱，注意补充铁质和叶酸。
```

**运动前后饮食**：
```
我今晚要跑5公里，请给我跑前2小时的加餐建议和跑后的恢复餐方案，重点补充碳水化合物和蛋白质。
```

**家庭聚餐菜单**：
```
周末有6个朋友来家里吃饭，其中2个素食者。请帮我设计一套适合多人分享的菜单，包含主菜、配菜、汤和甜点，总预算控制在300元以内。

**带孩子的饮食**：
```
我儿子5岁，挑食严重，不爱吃蔬菜。请设计一周的儿童食谱，把蔬菜"藏"在不显眼的菜里，同时确保钙质和维生素摄入充足。
```

### 常见问题解答

**Q：AI 推荐的菜谱真的靠谱吗？**

A：ChatGPT 的营养学知识基于大量公开数据训练而成，对于常规饮食建议是可靠的。但如果你有特殊的健康状况（糖尿病、肾病等），建议在医生或营养师指导下使用 AI 辅助，而不是完全依赖它。

**Q：每次都要手动输入这么多信息，太麻烦了。**

A：确实如此。一个高效的办法是创建一份"个人饮食档案"模板，每次开始新周期时直接复制粘贴。你也可以让 ChatGPT 帮你把这个模板做成一个可复用的提示词（prompt），以后每次只需要微调即可。

**Q：如何判断 AI 给出的热量估算是否准确？**

A：AI 的估算会有 ±15-20% 的误差，这在日常追踪中是可以接受的。如果你需要更精确的数据，可以使用 [DuckDB Lab](https://duckdblab.org/zh/) 中的食物数据库进行交叉验证，或者下载 USDA 食品营养数据库配合 DuckDB 做批量分析。

**Q：一个人做饭和两个人做饭的菜谱有什么区别？**

A：本质上是食材用量按比例放大。你可以让 ChatGPT 先生成单人菜谱，然后说"请把所有食材用量乘以1.8倍"即可。不过要注意，有些炖煮类菜肴放大后烹饪时间需要适当延长。
