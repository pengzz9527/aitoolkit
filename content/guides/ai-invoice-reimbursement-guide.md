每到报销季，你是不是要对着几百张发票一张张撕下来、填单据、核金额、算税额？手工处理不仅慢，还容易把税点算错、把重复发票漏掉，真金白银的损失。

2026年这件事可以完全交给AI。这篇教程带你把发票管理变成一条流水线：**拍照识别 → 自动分类 → 查重去重 → 生成报销单 → 一键做账**，全程零代码，一台手机加一台电脑就够。

> 先说结论：一个普通行政/财务岗位每月 200-500 张发票，手工处理约 4-6 小时；用这套 AI 流程压到 30 分钟以内，且错误率大幅降低。

---

## 一、全流程总览：发票管理到底要做什么

别一上来就找工具，先把整条线理清楚。一个完整的发票处理流程包含五步：

1. **收集**：发票散落在手机相册、微信收藏、邮箱附件里，需要统一导出
2. **识别**：把图片里的发票要素（金额、税点、开票方、发票代码号）变成结构化数据
3. **校验**：查重（同一张发票报两次？）、合规校验（抬头对不对、税号全不全）
4. **分类入账**：差旅费、招待费、采购费……分到正确的会计科目
5. **出报表**：月度费用汇总、部门占比、预算执行率

AI 在 **2、3、4** 这三步上效率提升最明显，后面每一步都给你写好了具体可操作的提示词。

---

## 二、第一步：统一收集发票素材（10分钟）

### 2.1 手机端集中管理

微信、支付宝、邮箱里散落的发票，先用统一规则归拢：

- **微信**：搜索"发票"，在聊天记录里找到开票方发来的电子发票，逐张保存
- **支付宝**：账单 → 发票助手，一键下载本月全部电子发票
- **邮箱**：搜索 `发票`，筛选 1 个月内的邮件，全部下载附件

> 小建议：所有发票统一存到一个文件夹，命名为 `发票-2026-10`，这样后面喂给 AI 时不会出现"张冠李戴"。

### 2.2 电子发票（OFD/PDF）直接复用，照片才需要识别

- **全电发票（PDF）**：自带结构化数据，直接提取即可，AI 识别更精准
- **拍照发票（JPG/PNG）**：AI OCR 识别，准确率 95%+，但需要人工抽检

---

## 三、第二步：让AI识别发票要素（5分钟/100张）

这是整个流程里最核心的一步。直接用最朴素的方法：

### 3.1 方法A：全电发票用AI读PDF

把 10-20 张全电发票打包，直接喂给 AI：

```
你是发票数据提取员。请从这批全电发票中逐张提取以下字段，
输出为 JSON 数组，每个对象包含：
- invoice_no（发票号码）
- code（发票代码，全电发票为 20 位）
- seller（销售方名称）
- buyer（购买方名称）
- buyer_tax_id（购买方税号）
- amount（不含税金额）
- tax_rate（税率，如 0.06）
- tax_amount（税额）
- total（价税合计）
- issue_date（开票日期，YYYY-MM-DD）

如果遇到重复发票号码，标记 "duplicate": true。
不要省略、不要总结，每张发票都要输出。
```

识别完后，把 JSON 存为 `invoices.json`，这是后面所有步骤的数据底座。

### 3.2 方法B：拍照发票用AI OCR

拍照发票无法直接提取结构化数据，用 AI 视觉模型识别：

```
下面这张图片是一张发票。请识别其中的：
1. 发票代码 / 号码
2. 开票日期
3. 销售方名称和税号
4. 金额（不含税）、税率、税额、价税合计
5. 购买方名称和税号

输出 JSON 格式，无法识别的字段填 null，并标注 "confidence": 低/中/高。
```

每张发票 10-20 秒，100 张大约 20-30 分钟。识别完的 JSON 结构和方法A一致，方便后续统一处理。

### 3.3 批量处理技巧

如果发票特别多（500张以上），分批喂给AI，每批 30-50 张，避免上下文过长导致识别质量下降。每批识别完人工抽检 10%，发现错误率高就缩小批次。

## 四、第三步：查重去重（AI帮你找"重复报销"）

重复报销是财务风险的重灾区。拿到 `invoices.json` 后，让 AI 直接跑一遍：

```
这是本月所有发票的结构化数据（JSON 数组）。请执行：
1. 按"发票代码+发票号码"分组，找出重复发票，输出重复清单
2. 按"销售方+金额+开票日期"二次模糊匹配（同一张发票可能拍照角度不同、编号识别有小误差）
3. 输出重复嫌疑清单，标注匹配依据（是编号重复还是模糊匹配）
```

> 查重建议人工复核：AI 会把"同一家供应商、同金额、同日期"的两张**不同**发票误判为重复，最后一步一定要人工看一遍。

另外，AI 还能帮你做**合规校验**：

```
请检查这批发票的合规性：
- 购买方名称是否全部等于"XX科技有限公司"（替换成你公司全称）
- 购买方税号是否为"91110108XXXXXXXX"（替换成你税号）
- 税率是否与商品类别匹配（餐饮 6%、住宿 6%、运输 9%、办公用品 13%）
- 开票日期是否在报销周期内（本月1日-月底）

输出不合规清单，每条标注不合规原因。
```

---

## 五、第四步：自动分类入账（AI直接给出会计科目）

财务最烦的一步——给每张发票定科目。AI 可以基于金额、备注、商品名称自动分类：

```
根据这批发票的商品/服务描述和金额，按以下规则分类到会计科目：

| 关键词 | 科目 |
|--------|------|
| 餐饮、餐费、酒店、招待 | 管理费用-业务招待费 |
| 差旅、机票、高铁、打车 | 差旅费 |
| 办公用品、打印、纸张 | 管理费用-办公费 |
| 服务器、软件、云服务、域名 | 研发支出-软件服务费 |
| 广告、推广、投放 | 销售费用-广告宣传费 |
| 水电、物业、房租 | 管理费用-水电物业 |

输出：每张发票 → 对应科目 + 建议入账金额（含税/不含税分开列）
分类不确定的标注"待确认"，附理由。
```

> 规则表可以按你们公司的实际科目体系调整，让 AI 学一遍，以后每月都通用。

---

## 六、第五步：一键生成报销单和月度报表（5分钟）

### 6.1 生成 Excel 报销单

让 AI 直接输出 CSV，Excel 打开就是报销单：

```
把上面分类好的发票汇总成报销单 CSV，列：
发票代码、发票号码、开票日期、销售方、商品描述、不含税金额、税率、税额、价税合计、会计科目、备注

CSV 格式，UTF-8 编码，逗号分隔，金额保留两位小数。
```

### 6.2 生成月度费用分析

```
基于这批发票数据，生成本月费用分析报告：
1. 按会计科目汇总金额和占比（降序排列）
2. 按销售方汇总 TOP10 供应商金额
3. 与上月对比（如有历史数据），列出环比变化最大的 3 个科目
4. 指出预算超支风险：哪些科目连续 2 个月上升且本月占比 > 15%
```

如果数据量很大（几百张以上、跨月对比），推荐用 [DuckDB AI](https://duckdblab.org/zh/) 做本地数据分析——把发票 JSON 加载进 DuckDB，写 SQL 就能跑分组汇总、同比环比，比让 AI 在对话里算快得多，还能存成文件复用。

### 6.3 站内工具联动

- 识别出的 JSON 数据，可以用 [JSON 格式化工具](https://198007.xyz/tools/json-formatter/) 先做一次结构校验，避免字段缺失
- 报销单 CSV 想在线预览、做简单统计，直接用 [CSV 在线分析器](https://198007.xyz/tools/csv-sql-analyzer/) 拖进去查
- 需要生成对账差异报告，用 [文本去重器](https://198007.xyz/tools/text-deduplicator/) 辅助去重

## 七、把流程变成每月固定动作（持续复用）

跑通一次不等于以后每月都能快速跑通。把这次的提示词存成模板，每月只需换数据：

1. **建一个文件夹**：`发票-2026-11/`，里面放原图、识别出的 `invoices.json`、生成的 `报销单.csv`
2. **提示词模板化**：把第三步到第六步的提示词存到 Notion/备忘录，标注 `本月只需替换 JSON 数据`
3. **建立供应商白名单**：每月核对销售方是否在白名单里，AI 可以批量比对，发现陌生供应商直接标红

> 持续做下去，你会发现发票管理真正变成"10分钟操作 + 5分钟审核"，剩下的时间可以用来做预算分析和成本优化，这才是财务该干的事。

## 八、常见问题

**Q：AI 识别错误怎么办？**
A：识别错误主要出现在拍照发票上。建议：拍照时保持发票平整、光线充足；识别后人工抽检 10%；金额差异超过 1% 的直接查原件。

**Q：不同公司抬头怎么识别？**
A：在提示词里把"购买方名称"规则改成"购买方名称应为 XXX 或 YYY（多抬头）"，AI 会自动分桶。

**Q：数据量太大（上千张）怎么办？**
A：先用 DuckDB 做结构化清洗和查重，再让 AI 做分类和报表。DuckDB 本地处理百万行级数据毫无压力，比 AI 对话里硬算快一个量级。

**Q：全电发票可以直接做自动化识别吗？**
A：可以，全电发票是结构化 PDF，AI 读取精度最高。建议优先用全电发票，拍照发票作为补充。

## 结语

发票管理这件事，真正卡住你的不是"识别"这一步，而是**把识别结果用起来**——查重、分类、出报表。这条链路里，AI 的价值在于把"逐张处理"变成"批量处理"，把"手动填表"变成"一句提示词"。

跑通这套流程之后，每月报销工作从 4-6 小时压缩到 30 分钟以内，而且错误率显著下降。工具都在上面链接里了，打开就能用。
