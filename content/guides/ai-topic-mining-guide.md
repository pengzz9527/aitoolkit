做自媒体的人都有一个共同的烦恼：**每天打开电脑，脑子一片空白，不知道该写什么。**

你刷了半天小红书、微博、B站，看似找到了灵感，但真要动笔时又发现——"这个话题已经被写烂了""这个角度我想不到""用户到底想看什么？"

问题不在于你没有灵感，而在于你**缺少数据支撑的选题判断**。凭感觉选出来的话题，要么竞争太激烈打不过，要么需求根本不存在。

本文教你一套**数据驱动的AI选题挖掘工作流**：用 ChatGPT 帮你分析平台数据、发现趋势、预测爆款，从"凭感觉选题"变成"用数据选题"。

## 一、为什么你的选题总是不准

先说一个残酷的事实：**90%的自媒体人选题靠直觉，只有10%靠数据。**

直觉选题的问题在哪？

1. **幸存者偏差**：你看到某个话题火了，就去追，但追的时候热度已经过去了
2. **信息茧房**：你关注的内容和你想的内容高度重叠，看不到其他机会
3. **反馈滞后**：文章发出去才知道数据好不好，错过了最佳发布时机
4. **同质化严重**：所有人都在追同一个热点，竞争白热化

而数据驱动选题的核心逻辑很简单：**找到那些正在上升但还没有被写烂的话题，在合适的时机切入。**

怎么做？三步：

1. **数据采集**：收集平台上的热门内容数据
2. **趋势分析**：用AI识别哪些话题在上升
3. **选题生成**：让AI基于数据生成差异化选题

下面一步步来。

## 二、数据采集：从哪里获取选题素材

选题的第一步不是"想写什么"，而是**"别人在搜什么、看什么、讨论什么"**。

### 2.1 用 ChatGPT 做平台数据调研

这是最简单的方式。打开 ChatGPT，用以下提示词：

```
你是一个自媒体运营专家。我正在做[你的领域]方向的自媒体，目标用户是[用户画像]。

请帮我完成以下调研：

1. 列出小红书/知乎/B站上关于"[领域]"最近30天最热的20个话题，按热度排序
2. 每个话题标注：热度级别（高/中/低）、竞争程度（红海/蓝海）、内容缺口（什么角度还没人写）
3. 找出3个"正在上升但还没被写烂"的细分话题

输出格式：表格形式
```

**示例（假设做效率工具方向）：**

> 1. 「Notion模板分享」- 热度高，竞争红海，内容缺口：垂直场景模板（如学生党Notion）
> 2. 「AI写作工具推荐」- 热度中，竞争中等，内容缺口：特定场景AI写作（如公文、邮件）
> 3. 「时间管理APP对比」- 热度上升中，竞争蓝海，内容缺口：国产时间管理工具测评

### 2.2 用免费工具做数据沉淀

ChatGPT 给的是定性判断，你还需要**结构化的数据来跟踪趋势**。

**推荐方案**：把 ChatGPT 的输出整理成 CSV 格式，导入 198007.xyz 的 [CSV/SQL 在线分析器](/tools/csv-sql-analyzer/)，用 SQL 做趋势分析。

具体做法：

**步骤 1**：让 ChatGPT 输出 CSV 格式

在提示词末尾加上：

```
最后，请把所有话题数据输出为 CSV 格式，包含字段：话题名称、热度、竞争程度、内容缺口、推荐理由
```

**步骤 2**：上传到 CSV 分析器

把 CSV 文件上传到 [CSV/SQL 在线分析器](/tools/csv-sql-analyzer/)，你可以：

- 按热度排序，快速找到高潜力话题
- 用 SQL 过滤"蓝海"话题：`SELECT * FROM data WHERE 竞争程度='蓝海' ORDER BY 热度 DESC`
- 用 SQL 做交叉分析：`SELECT 竞争程度, COUNT(*) FROM data GROUP BY 竞争程度`

**步骤 3**：定期更新

每周重复这个流程，把新的数据追加到同一个 CSV 文件里。几个月后，你就会有一个**属于自己的选题数据库**，可以分析趋势、对比不同时期的热门话题。

### 2.3 手动采集：平台自带的"热搜"功能

不要忽略平台自己的数据：

- **小红书**：搜索框的"热搜榜"、同领域博主的笔记数据
- **知乎**：热榜、话题页的"关注人数增长"
- **B站**：排行榜、搜索联想词
- **微博**：热搜榜、话题页
- **微信公众号**：搜一搜的"热门文章"

把这些数据手动整理进你的 CSV 文件，每次更新时追加新的行。

## 三、趋势分析：用 AI 识别上升话题

有了数据，下一步是**识别哪些话题在上升**。这比看"当前最热"更重要——你要的是**明天会火的话题**，不是今天已经火的话题。

### 3.1 用 ChatGPT 做趋势判断

把你的 CSV 数据发给 ChatGPT，用以下提示词：

```
我整理了过去4周的自媒体选题数据（见下方CSV）。请帮我分析：

1. 哪些话题在持续上升（连续几周热度增加）
2. 哪些话题正在降温（连续几周热度下降）
3. 哪个话题出现了"突然爆发"的特征（一周内热度翻倍）
4. 基于趋势，推荐3个我应该本周重点做的选题

数据：
[粘贴CSV内容]
```

**输出示例：**

> 上升话题：「AI办公效率工具」（连续3周热度增加，从1200→3500）
> 降温话题：「Markdown编辑器推荐」（连续2周热度下降，从800→400）
> 爆发话题：「Cursor编辑器教程」（本周突然从200跳到1800）
> 推荐选题：「Cursor编辑器入门教程」「AI办公效率工具横评」「Markdown编辑器替代品推荐」

### 3.2 用 SQL 做量化趋势分析

如果你有足够多的历史数据（比如20条以上的历史记录），可以用 SQL 做更精确的趋势分析：

```sql
-- 找出连续上升的话题
WITH trend_data AS (
  SELECT 
    话题名称, 
    周期, 
    热度,
    LAG(热度, 1) OVER (PARTITION BY 话题名称 ORDER BY 周期) as 上周热度,
    LAG(热度, 2) OVER (PARTITION BY 话题名称 ORDER BY 周期) as 前周热度
  FROM data
)
SELECT 
  话题名称, 
  热度, 
  上周热度, 
  (热度 - 上周热度) as 周增长,
  (热度 - 前周热度) as 两周增长
FROM trend_data
WHERE 上周热度 IS NOT NULL
  AND 热度 > 上周热度
  AND 上周热度 > 前周热度
ORDER BY 两周增长 DESC
LIMIT 10;
```

这段 SQL 会找出**连续两周热度都上升**的话题——这些是真正的上升趋势，不是偶然波动。

在 [CSV/SQL 在线分析器](/tools/csv-sql-analyzer/) 里直接运行这段 SQL，替换表名和字段名即可。

### 3.3 用 DuckDB 做更复杂的分析

如果你的数据量比较大（比如几百条历史记录），可以考虑用 [DuckDB Lab](https://duckdblab.org/zh/) 做更深入的分析：

- 时间序列分析：画出每个话题的热度趋势图
- 相关性分析：找出同时上升的话题组合（比如"AI写作"和"ChatGPT"经常一起出现）
- 聚类分析：把话题分成不同的类别，找到每个类别里的蓝海机会

DuckDB 的处理速度比 Pandas 快很多，几百条数据基本秒级响应。

## 四、爆款预测：让 AI 给你选题建议

有了趋势分析，最后一步是**让 AI 基于数据给你具体的选题建议**。这一步不是让 AI 凭空想象，而是让 AI 在数据的基础上做 creative thinking。

### 4.1 让 AI 生成差异化选题

把趋势分析的结果发给 ChatGPT，用以下提示词：

```
基于以下数据分析结果，帮我生成10个差异化选题，要求：

1. 每个选题必须基于真实数据趋势（不能凭空想象）
2. 每个选题要有明确的差异化角度（不能和已有内容重复）
3. 每个选题给出：标题、核心角度、目标用户、预期热度、竞争程度
4. 优先推荐蓝海话题，其次推荐上升中的红海话题

趋势分析结果：
[粘贴分析结果]

已有内容列表（避免重复）：
[粘贴你已写过的内容标题]
```

**输出示例：**

> 选题1：「Cursor编辑器入门：从0到1写出第一个AI编程项目」
> - 核心角度：零基础教程（而非高级技巧）
> - 目标用户：刚入门编程的年轻人
> - 预期热度：高（上升趋势明显）
> - 竞争程度：中（蓝海机会）
>
> 选题2：「2026年AI办公效率工具横评：Notion vs Cursor vs Claude」
> - 核心角度：横向对比（而非单点介绍）
> - 目标用户：效率工具爱好者
> - 预期热度：高（持续上升）
> - 竞争程度：中（红海但有差异化空间）

### 4.2 用 AI 做标题优化

选好选题后，让 AI 帮你优化标题：

```
请为以下选题生成10个爆款标题，要求：
- 包含数字（增加具体感）
- 包含结果/收益（读者看完能得到什么）
- 使用口语化表达
- 适合[平台]的调性

选题：Cursor编辑器入门教程
目标平台：小红书
目标用户：编程初学者
```

**标题示例：**

> 1. 「 Cursor编辑器入门：我用了3天就写出了第一个AI项目」
> 2. 「 0基础也能用Cursor！3天入门AI编程的完整教程」
> 3. 「 比ChatGPT更强大的编程神器：Cursor完全入门指南」

### 4.3 用 AI 做内容结构规划

标题确定后，让 AI 帮你规划内容结构：

```
请为以下标题生成文章大纲，要求：
- 包含5-8个章节
- 每个章节给出具体的写作要点
- 标注哪些部分需要配图
- 标注哪些部分可以插入站内工具链接

标题：Cursor编辑器入门：我用了3天就写出了第一个AI项目
目标平台：小红书
```

## 五、建立你的选题工作流

把上面的步骤整合成一套**日常选题工作流**：

### 5.1 每日选题流程（15分钟）

```
1. 打开 ChatGPT，问：「今天[你的领域]有什么新趋势？」
2. 把结果追加到 CSV 文件
3. 用 SQL 检查是否有新出现的上升话题
4. 如果有，让 AI 生成差异化选题建议
5. 选出1-2个当天要写的选题
```

### 5.2 每周选题流程（30分钟）

```
1. 回顾本周新增的所有话题数据
2. 用趋势分析 SQL 找出本周上升最快的话题
3. 对比上周的选题列表，检查哪些话题被写烂了
4. 生成下周的选题计划（5-7个选题）
5. 按优先级排序，确定本周要写的3个选题
```

### 5.3 每月选题流程（1小时）

```
1. 导出本月的全部选题数据
2. 用 DuckDB 做深度趋势分析
3. 找出本月最成功的3个选题，分析成功原因
4. 找出本月最失败的3个选题，分析失败原因
5. 更新下月的选题策略和方向
```

## 七、常见问题

### Q：我没有任何数据基础，怎么开始？

**A**：从最简单的开始——用 ChatGPT 做一次定性分析，手动整理成 CSV 表格。不需要工具，不需要技术，花10分钟就能开始。

### Q：我的数据量很少，趋势分析有意义吗？

**A**：有。哪怕只有5-10条记录，也能看出大致的方向。趋势分析的价值不在于精确预测，而在于**避免凭直觉选题**。

### Q：工具链接放哪里合适？

**A**：在涉及数据整理和分析的场景，自然插入站内工具链接即可。比如在"把数据整理成CSV"这一步，可以提到 [CSV/SQL 在线分析器](/tools/csv-sql-analyzer/)；在涉及更复杂数据分析时，可以提到 [DuckDB Lab](https://duckdblab.org/zh/)。

### Q：这套方法适合所有自媒体方向吗？

**A**：适合。无论是效率工具、AI应用、编程教程、还是生活分享，选题挖掘的逻辑是一样的：**数据驱动 + AI 辅助 + 差异化角度**。
