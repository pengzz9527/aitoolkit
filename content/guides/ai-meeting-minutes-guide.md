## 为什么你需要 AI 会议纪要

开完会最痛苦的不是开会本身，而是会后整理纪要。过去你通常需要：听录音、逐字转写、提取重点、整理待办、发给参会人——整个过程至少花掉半小时。现在用 AI 工具，全程自动化，会议结束纪要就已经在你邮箱里了。

这篇文章教你用 ChatGPT 搭配免费语音转文字工具，从零搭建一套完整的 AI 会议纪要工作流。不需要写代码，不需要买付费软件，电脑或手机都能搞定。

## 准备工作：你需要哪些工具

这套方案只需要三个免费工具：

**第一步：手机录音或电脑录屏**

如果是在线会议（腾讯会议、钉钉、飞书），这些平台本身就带录音功能。如果是线下会议，直接用手机的「录音机」App 即可。建议提前测试一下录音效果，找个安静的位置，手机放在桌子中间比拿在手里效果好得多。

**第二步：语音转文字**

国内最好用的是讯飞听见（https://www.xfyun.cn/services/aitranscript），免费版每天可以转写 2 小时语音。操作步骤很简单：打开讯飞听见网页版 → 点击「转写」→ 上传录音文件 → 等待几分钟就得到文字稿。如果你用的是 Mac，系统自带的「语音备忘录」也可以直接转文字；Windows 用户可以用 Windows 11 自带的「录音机」App，它内置了实时转录功能。

**第三步：AI 整理纪要**

把转写好的文字稿粘贴到 ChatGPT 或 Claude 中，让它帮你整理成结构化的会议纪要。这就是我们接下来要详细讲的。

## 核心步骤：用 ChatGPT 整理会议纪要

这是整个流程最关键的一步。很多人以为把文字稿丢给 AI 就行了，其实提示词的质量直接决定了纪要的好坏。下面给你一个可以直接复制使用的提示词模板：

```
你是一位专业的会议记录员。请根据以下会议录音转写稿，整理出一份结构化
的会议纪要，要求包含以下内容：

1. 【会议基本信息】会议主题、日期、参会人员（从文本中提取）
2. 【核心议题】本次讨论了哪几个主要问题
3. 【讨论要点】每个议题下各方的观点摘要，保留关键数据和决策依据
4. 【会议结论】最终达成了什么共识或决议
5. 【待办事项】列出所有 Action Item，包含负责人和截止时间（如果提到）
6. 【下次会议安排】如有提及请写明

格式要求：
- 使用简洁的语言，去除口语化表达
- 每个议题用 bullet point 列出
- 待办事项用表格形式呈现
- 总字数控制在 800 字以内
- 如果原文中有不清楚的地方，标注「待确认」

以下是会议转写稿：
[粘贴你的转写文字]
```

这个提示词的设计逻辑是：先让 AI 理解角色定位，然后明确输出结构，最后规定格式规范。你可以根据实际会议类型微调——比如技术评审会议可以增加「技术方案对比」这一项，周会可以增加「本周进展同步」。

## 实战案例：一次产品周会的完整处理

假设你们团队开了一个 45 分钟的产品周会，录音文件大约 40MB。下面是完整操作过程：

**14:00** 用手机录音 App 录制会议全过程。记得在会议开始前说一句「今天是 6 月 23 日，产品周会」，这样后面整理时方便核对日期。

**14:45** 会议结束，把录音文件导出到电脑。

**14:50** 上传到讯飞听见进行转写。上传后大概 5-10 分钟就能得到文字稿。转写完成后，花 2 分钟快速浏览一下，修正明显的识别错误（比如人名、专业术语）。

**14:55** 把修正后的文字稿粘贴到 ChatGPT，附上上面的提示词模板。

**15:00** ChatGPT 返回会议纪要。你只需要做两件事：一是核对待办事项是否遗漏，二是把纪要发到团队群里。

从录音到发出纪要，全程不到 1 小时。而传统的做法是你需要在会后花 30-40 分钟整理，而且往往拖到第二天才发出去。

## 进阶技巧：让会议纪要更专业

掌握基础流程后，试试这几个进阶用法，让你的会议纪要从「能看」变成「好用」。

### 技巧一：自动提取待办事项并生成任务列表

在提示词的最后追加一段：

```
请将所有待办事项整理成一个 Markdown 表格，列名分别为：任务描述、负责人、截止日期、优先级（高/中/低）。如果没有提到截止日期，请填写「待定」。如果没有提到负责人，请填写「需确认」。
```

这样生成的表格可以直接复制到飞书多维表格、Notion 或腾讯文档里，作为团队的任务跟踪表。

### 技巧二：按不同角色生成不同版本

同一个会议，CEO 想看战略层面的结论，项目经理想看待办事项，开发人员想看技术方案讨论。你可以在 ChatGPT 里追加指令：

```
请基于上述会议纪要，再分别生成两个版本：
- 给管理层的摘要版（200字以内，只包含决策和关键风险）
- 给执行团队的行动版（只包含待办事项和时间节点）
```

这样一份纪要就能服务不同需求的读者，再也不用反复整理了。

### 技巧三：自动关联历史会议

如果你的团队每周都有例会，可以把之前几次会议纪要也一起贴给 ChatGPT，让它做对比分析：

```
同时参考以下三次历史会议纪要，请指出本次会议与上次会议相比，有哪些任务已经完成了，有哪些是新增加的，有哪些被延后了。
```

这个功能特别适合项目进度追踪，能让你一眼看出项目的推进节奏。

### 技巧四：会议纪要自动归档

如果你正在使用我们之前教程中提到的 [零代码AI数据分析](/tools/ai-data-analysis-no-code/) 方法，可以把每次的会议纪要导出为 CSV 格式，用 ChatGPT 做简单的统计分析——比如一个月下来总共开了多少会、待办事项的完成率是多少、哪个环节的讨论最耗时。这些数据能帮你优化团队的时间分配。

对于需要深度分析会议数据的情况，推荐使用 [DuckDB](https://duckdblab.org/zh/) 来做本地数据分析。它可以在几秒内处理上万条会议记录，生成可视化报表，而且完全免费、无需联网。

## 常见问题的解决方案

**Q：语音识别不准怎么办？**

AI 语音识别对普通话的准确率已经很高了（讯飞听见普通话识别准确率达 97%），但遇到方言、专业术语或多人同时说话时会有偏差。解决方法：在转写前把录音文件降噪处理一下，可以用 Audacity（免费开源）做简单的降噪；转写后花 2 分钟快速校对关键信息，特别是人名和产品名称。

**Q：会议太长，转写超时怎么办？**

讯飞听见免费版每天限 2 小时，如果你的会议经常超过这个时长，可以这样处理：用 Audacity 把录音按 30 分钟一段切开，分段转写后再拼接到 ChatGPT 中整理。ChatGPT 一次性处理的文本上限很大，几百页都没问题。

**Q：如何保护会议内容的隐私？**

如果会议涉及敏感信息，建议使用本地部署的语音转写工具。讯飞听见提供了离线 SDK，可以在内网环境中使用。另外，ChatGPT 的企业版支持数据不用于训练，如果你担心隐私问题，可以选择企业版或使用 Claude 的隐私模式。

## 完整工作流总结

把上面的步骤串起来，你的 AI 会议纪要工作流就是：

```
线下/线上会议 → 手机录音 → 讯飞听见转写 → 人工简单校对 → ChatGPT 整理 → 发送纪要 → 归档
```

整个流程熟练后，每次会议只需要额外花 10-15 分钟，就能得到一份专业级的会议纪要。
