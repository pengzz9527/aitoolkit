做自媒体的朋友都懂——每天更新内容是最痛苦的事。选题、写标题、排版、配图，一个流程下来两三个小时就没了。更别说要保持日更，质量还不能掉。

很多人以为"用 AI 做内容"就是把需求丢给 ChatGPT，它写什么就发什么。结果发出来全是 AI 味，阅读量惨不忍睹。

本文分享一套 **真正可行的 AI 自媒体创作流程**，从选题策划到标题优化，从正文撰写到多平台适配，每一步都有具体操作和提示词模板。不需要文采，不需要设计基础，只要会复制粘贴，就能用 AI 持续产出优质内容。

## 一、爆款选题：用 AI 找到读者的真实需求

写作最难的不是写，而是"写什么"。很多人断更就是因为每天坐在电脑前不知道写啥。用 AI 做选题，核心方法是**让 ChatGPT 帮你分析平台上的热门内容模式**。

### 操作步骤

打开 ChatGPT，输入以下提示词模板：

```
你是一个资深自媒体运营。请分析小红书平台上「XX领域」的爆款笔记，告诉我：
1. 最近1个月该领域点赞过万的笔记主要集中在哪些话题
2. 每个话题下最受关注的3个具体痛点
3. 每个痛点可以切入的角度（3个）
输出格式：表格形式，包含「话题」「核心痛点」「切入角度」「参考标题示例」
```

举个例子，如果你是做「效率工具」方向的，把「XX领域」替换成「效率工具」。ChatGPT 会列出十几条热门话题和对应的切入角度。

**关键技巧**：拿到选题列表后，用 [198007.xyz 的 JSON 格式化工具](/tools/json-formatter/) 把 ChatGPT 输出的表格存成 JSON 格式，方便后续分类管理和检索，也方便你在不同 AI 工具间转移数据。

### 选题筛选标准

不是所有 AI 给出的选题都要写。用三个问题筛选：

1. **搜索量**：这个关键词在微信搜一搜或小红书搜索里有没有人搜？
2. **差异化**：现有内容是否都是千篇一律？我能不能换个角度？
3. **可执行**：这个选题我能不能写出实操步骤，而不是空谈概念？

三个都是"是"——这个选题值得写。

## 二、爆款标题公式：3秒抓住读者注意力

标题决定打开率。AI 写标题不是让它"自由发挥"，而是**给它明确的公式**。

### 实操提示词

```
请为以下文章生成10个小红书风格的标题，要求：
- 包含数字（增加具体感）
- 包含结果/收益（读者看完能得到什么）
- 使用口语化表达（像是朋友在推荐）
- 长度12-20字

文章主题：[粘贴你的选题和核心内容]

输出格式：每个标题占一行，简要说明为什么这个标题有效
```

**进阶技巧**：让 ChatGPT 分析平台爆款标题的共同特征：

```
请分析以下10个小红书爆款笔记标题的共同特征：
[粘贴10个你收集的爆款标题]

然后基于这些特征，为我当前的文章生成5个新标题。
```

### 标题测试

写好的标题不要直接发。用 [198007.xyz 的文字计数器](/tools/word-counter/) 检查标题长度——小红书标题最佳长度是 15-18 个字，超过 20 字会被截断。微信公众号标题则可以长一些，30 字以内最佳。

## 三、正文写作：从"AI 味"到"人味"的三步法

AI 写出来的内容最致命的问题是：**太完美了，没有人味**。真实的人写东西会有语气词、有个人经历、有情绪起伏。

### 第一步：让 AI 搭骨架

```
你是一个经验丰富的自媒体作者。请为以下选题写一个大纲：
选题：[粘贴选题]
目标读者：[描述读者画像]
核心要点：列出3-5个具体操作步骤

要求：
- 每个要点都要有具体的操作方法，不是空谈概念
- 开头要有"钩子"（让读者愿意继续看下去）
- 结尾要有总结和行动建议
```

### 第二步：分段填充内容

拿到大纲后，不要让它一次写完。分段来：

```
请写大纲中的第2部分「XXX」，要求：
- 用口语化的表达，像在和朋友聊天
- 包含1-2个具体的操作截图描述
- 加入一句个人的使用感受（虚构也没关系，但要真实感）
- 控制在300-500字
```

### 第三步：人工润色加"人味"

AI 写完后，你只需要做三件事：
- **加个人经历**：哪怕只是"上周我试了一下，效果确实..."，读者感受完全不同
- **加吐槽**：真实使用中的槽点——"第一次用的时候我也踩了这个坑"
- **改句式**：把"首先、其次、最后"改成"先做这步 → 然后这样 → 最后别忘了"

这样出来的文章，读者基本分不清是不是 AI 写的，只会觉得"这个作者真会写"。

## 四、多平台适配：一份内容重复利用

写一篇文章花的时间是一样的，但发一个平台和发五个平台的收益差 5 倍。

### ChatGPT 一句话转换

写好的文章不要直接复制粘贴到所有平台。用这个提示词：

```
请将以下文章分别适配到小红书、公众号、知乎三个平台：

原文：[粘贴文章]

要求：
- 小红书：口语化、短段落、emoji点缀、结论前置
- 公众号：开头有故事/场景引入、段落300字以内、金句加粗
- 知乎：条理清晰、有理有据、可以适当增加数据支撑

每个版本保留核心操作步骤，但表达方式根据不同平台调整。
```

如果你想批量处理历史文章，用 [198007.xyz 的 JSON 处理器](/tools/json-to-csv/) 把多篇文章统一管理，批量交给 ChatGPT 处理后，再转回标准格式发布。

## 五、每日30分钟创作流程

光有方法不行，关键是**流程化**。这是我在用的每日创作安排：

| 时间段 | 做什么 | 用时 |
|--------|--------|------|
| **第1-5天** | 每天用AI生成10个选题，积累50个选题库 | 10分钟/天 |
| **第6天** | 从选题库筛选本周要写的5篇，排好优先级 | 15分钟 |
| **每日** | 按上述三步法写一篇正文（AI骨架+分段填充+人工润色） | 25分钟 |
| **每日** | 适配2-3个平台，一次性发布 | 5分钟 |
| **每周** | 复盘阅读数据，调整选题方向 | 20分钟 |

这个流程的核心逻辑是：**选题提前批量准备，内容当天产出，多平台一次发布**。每天只需30分钟就能维持稳定更新。
