群里每天发生的事大同小异：组长第三遍@全员催周报，新人问"报销单交哪里"，你第五遍把同一个答案打一遍。这些活占不了多少时间，但每天都是固定成本，而且永远轮到群里资历最老的那个人。

飞书和钉钉的自定义机器人可以把这些活接过去：它就是一个往群里发消息的"专属入口"（Webhook），配合ChatGPT写文案，再配上定时任务，一个群助手就齐了。全程不需要服务器、不需要写代码，最多复制几条命令。

## 一、能做什么：三个场景先对号入座

| 场景 | 机器人做的事 | 用到的功能 |
|------|-------------|-----------|
| 定时提醒 | 每周五16:00@全员催周报 | Webhook + 定时任务 |
| FAQ自动回复 | 有人问"报销交哪里"，机器人回标准答案 | 群内关键词自动回复 |
| 周报汇总 | 收集大家的周报，生成一张总结卡片发回群里 | Webhook + 数据聚合 |

下面按顺序做，做完场景一，场景二三都能复用同一套东西。

## 二、第一步：建机器人，拿到Webhook

以飞书为例（钉钉流程在文末附了对照表）：

1. 进入目标群，点右上角「设置」→「群机器人」→「添加机器人」，选「自定义机器人」。
2. 起名，比如"周报小助手"。
3. 安全设置勾「自定义关键词」，填两个词：`提醒`、`周报`。之后机器人发的每条消息里必须包含其中一个词，否则会被拒收。
4. 复制生成的 Webhook 地址，长得像 `https://open.feishu.cn/open-apis/bot/v2/hook/xxxx`。

Webhook 等于群发消息的钥匙，任何人拿到都能冒充机器人。存到本地加密笔记或环境变量里，别写进 Git 仓库、别发到群里。

## 三、第二步：让ChatGPT写提醒文案

不要自己憋文案，直接把这段提示词丢给ChatGPT：

```
你是群提醒文案写手。写一条"周五周报提醒"，16:00发在飞书群。
要求：
- 全文不超过80字
- 开头 @所有人，一句话说明原因（周一例会要用）
- 语气友好不训人，结尾给一句轻松的鼓励
- 文案里必须包含"提醒"两个字
- 输出正式、轻松、幽默 3 个版本
```

第三版的"必须包含提醒两个字"不是随便写的——就是第二部的关键词校验，漏掉就发不出去。三个版本里挑一个，贴进下面的命令。

## 四、第三步：测试发送，一条curl搞定

把文案填进命令，终端或命令行执行一次：

```bash
curl -X POST 'https://open.feishu.cn/open-apis/bot/v2/hook/你的地址' \
  -H 'Content-Type: application/json' \
  -d '{"msg_type":"text","content":{"text":"周五提醒：@所有人，周报请在明天18:00前交给我，周一例会直接用，谢谢配合！"}}'
```

看到群里出现机器人消息就成了。失败时接口会返回一段JSON，别对着裸JSON猜，丢进 [JSON格式化器](https://198007.xyz/tools/json-formatter/) 展开看 `code` 和 `msg` 字段，常见原因就三种：消息里没带关键词、IP不在白名单、Webhook地址抄错了一位。

## 五、第四步：加定时，让它自己跑

"每周五16:00"这种表达，手写容易出错，先用 [Cron表达式生成器](https://198007.xyz/tools/cron-builder/) 输入自然语言，拿到 `0 16 * * 5`。

两种跑法，按你的条件选：

- **电脑一直开着（最简单）**：Windows「任务计划程序」→ 创建基本任务 → 触发器设每周五16:00 → 操作选"启动程序"，填上面那条 curl 命令。手机党可以先跳过，等场景三再回来做。
- **有云服务器**：`crontab -e` 加一行 `0 16 * * 5 curl -s -X POST '你的Webhook' -H 'Content-Type: application/json' -d '{"msg_type":"text","content":{"text":"周报提醒：@所有人，今天18:00前交周报，谢谢！"}}'`。

## 六、场景二：FAQ自动回复

自定义Webhook机器人只发不收，"有人问、机器人答"要靠群里的**关键词自动回复**功能（飞书群机器人里直接能配，零代码）：

1. 把近三个月群里被问过两遍以上的问题列出来，大概十来个。
2. 丢给ChatGPT：

```
你是新人答疑写手。以下是群里高频问题（每行一个）：
[粘贴你的问题列表]
要求：每个问题写一条50字以内的答复，直接可粘贴进机器人自动回复框，
涉及链接处写 [链接] 占位，输出"问题 | 答复"两列表格。
```

3. 回到飞书群设置 → 群机器人 → 对应机器人的「自动回复」，逐条填入问题和答复，关键词列填问题原文或其中最稳的一个词。
4. 在群里发一句"报销单交哪里"试试，机器人答得上来就收工。

答复里如果带"提醒"或"周报"这类词正好命中你第一部的关键词，不用担心；自动回复走的是另一条链路，不受自定义机器人关键词限制，但发出去的主动消息仍然要带关键词。

## 七、场景三：周报汇总，机器人发总结卡

1. 让大家把周报丢进一个共享表格（飞书多维表格或在线Excel都行），每人一行：姓名、本周完成、下周计划。
2. 每周五下班前导出成CSV。
3. 用 [CSV数据分析器](https://198007.xyz/tools/csv-sql-analyzer/) 上传，直接用自然语言下指令："按人统计'本周完成'列的行数，再列出'下周计划'里提到'联调'的人"，几秒钟出结果，比人工数快。
4. 把表格和统计结果贴给ChatGPT："把这份周报汇总成80字以内的群公告，突出风险和下周重点"。
5. 把生成的总结走第五部的curl发回群里。

如果周报数据量大、需要按周对比趋势，可以接着看 [duckdblab.org 的中文数据分析教程](https://duckdblab.org/zh/)，把表格存成数据库后查起来更省。

## 八、钉钉用户对照表

| 步骤 | 飞书 | 钉钉 |
|------|------|------|
| 建机器人 | 群设置→群机器人→自定义机器人 | 群设置→智能群助手→添加机器人→自定义 |
| 安全设置 | 自定义关键词 | 关键词 / 加签 二选一，加签更稳 |
| Webhook示例 | `open.feishu.cn/open-apis/bot/v2/hook/...` | `oapi.dingtalk.com/robot/send?access_token=...` |
| 消息体 | `{"msg_type":"text","content":{"text":"..."}}` | `{"msgtype":"text","text":{"content":"..."}}` |
| 关键词位置 | 消息正文 | 消息正文 |

钉钉选"加签"时，Webhook要带上时间戳和签名参数，让ChatGPT照着官方文档公式帮你生成那段计算签名的命令即可，逻辑和飞书一致。

## 九、避坑清单

- **频控**：机器人每分钟有发送上限，写循环脚本连发会整批被拒，正常业务一次发一两条完全够用。
- **关键词漏配**：消息里必须原样出现你填的关键词，"周會"不算"周报"。
- **Webhook泄露**：怀疑泄露就去机器人设置页点重置，旧地址立刻失效。
- **定时任务没跑**：先手动执行一次curl确认能发，再挂定时；挂上后第一天手动看一眼时间对不对。
- **@所有人**：飞书在消息体里加 `"content":{"text":"@all ..."}}` 或按机器人配置说明用 `@所有人`，钉钉写 `@手机号` 才能真正@到人，纯文字"@所有人"只是装饰。

做完这三件，群里最烦人的三类重复劳动就归机器人了。下一步可以把它接上更复杂的工作流，比如自动拉取项目状态再推送，思路不变：数据源 → 汇总 → 一条Webhook发出去。
