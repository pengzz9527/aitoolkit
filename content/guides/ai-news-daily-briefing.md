你是不是也有这样的困扰：想及时了解行业动态，但信息源太多——公众号、微博、知乎、Reddit、Twitter 轮流刷，一天过去什么都没记住；或者干脆被算法投喂得只剩同质化内容，根本看不到真正有价值的信息。

## 一、为什么你需要一个个性化新闻早报

在信息爆炸的时代，真正的稀缺不是信息，而是**筛选信息的能力**。

一个设计良好的新闻早报系统能帮你做到：

1. **聚焦核心信息** — 只推送你关心的领域，过滤噪音
2. **节省时间** — 每天10分钟读完，而不是刷1小时手机
3. **保持连贯** — AI 自动关联多篇报道，给你一个完整的认知框架
4. **发现盲区** — 从不同来源交叉验证，避免信息茧房

下面我们就一步步来搭建它。

## 二、第一步：收集信息源（RSS订阅）

AI 需要素材才能工作，而 RSS 是获取结构化信息最可靠的方式。

### 什么是 RSS？

RSS（简易信息聚合）是一种让网站将其最新内容以标准化格式发布的技术。你可以用一个 RSS 阅读器订阅多个来源，所有更新汇聚到一个页面。

如果你之前没接触过 RSS，不用担心——它的操作比你想的简单得多。

### 推荐的信息源配置

根据你的关注领域，选择以下来源：

**科技/AI 方向：**
- 36氪：`https://36kr.com/feed`
- TechCrunch：`https://techcrunch.com/feed/`
- Hacker News：`https://hn.algolia.com/rss`
- The Verge：`https://www.theverge.com/rss/index.xml`

**商业/投资方向：**
- 虎嗅：`https://www.huxiu.com/feed`
- 少数派：`https://sspai.com/feed`
- Bloomberg：`https://feeds.bloomberg.com/markets/news.rss`

**行业垂直方向：**
- 你所在行业的权威媒体、博客、官方公告等

> 📌 提示：如果想深入了解如何采集和管理网站数据源，可以参考本站《[用AI做定时数据采集与报表](/zh/guides/ai-data-collection-scheduled-report/)》一文，里面有更详细的采集策略。

### 推荐使用 RSSHub

很多网站没有原生 RSS，这时可以用 [RSSHub](https://docs.rsshub.app/) —— 一个开源的 RSS 生成器，支持数千个平台。比如 Bilibili UP主更新、微博热搜、即刻动态等，都能一键生成 RSS。

部署方式很简单：
1. 访问 [rsshub.app](https://rsshub.app/) 使用在线版（免费）
2. 或自行部署：`docker run -d -p 1200:1200 diygod/rsshub`（推荐有服务器的用户）

## 三、第二步：用 AI 处理信息

有了信息源之后，关键一步是让 AI 帮你「读」这些内容并生成高质量的早报。

### 方案一：用 ChatGPT + n8n 自动化（推荐）

[n8n](https://n8n.io/) 是一个强大的开源自动化工作流工具，可以连接 RSS 和 AI 接口。

**设置步骤：**

1. **安装 n8n**
   ```bash
   docker run -d --name n8n -p 5678:5678 -v ~/.n8n:/home/node/.n8n n8nio/n8n
   ```
   然后访问 `http://localhost:5678` 启动界面。

2. **创建新工作流，添加「Webhook」触发节点**
   - 设置定时触发：比如每天早上 8:00 执行
   - 或者在 n8n 中添加「Schedule Trigger」节点

3. **添加「RSS Feed Read」节点**
   - 填入你在第一步配置的所有 RSS URL
   - 设置读取最新的 10-20 条内容

4. **添加「ChatGPT (OpenAI)」节点**
   - 在提示词中输入：
     ```
     你是一位专业的资讯编辑。以下是今天收集到的{N}条科技/商业领域资讯标题和摘要：
     
     {此处插入RSS内容}
     
     请完成以下任务：
     1. 将内容按主题分类（如：AI进展、产品发布、市场分析等）
     2. 每个类别选出2-3条最重要的信息
     3. 为每条信息写一句话精简摘要（不超过50字）
     4. 最后用一段话总结今天的核心趋势
     
     输出格式要求：
     # 📰 今日资讯早报 {日期}
     
     ## 🤖 AI与科技
     - [标题](链接): 一句话摘要
     
     ## 💼 商业与投资
     - [标题](链接): 一句话摘要
     
     ## 📊 今日洞察
     （一段话总结核心趋势）
     ```
   - 设置 temperature=0.7（既有创意又不失准确）
   - 设置 max_tokens=2000

5. **添加「Email」或「Telegram」输出节点**
   - 选择你偏好的推送方式（邮件、Telegram、微信等）
   - 配置收件地址

6. **保存并激活工作流**

这样，每天早上 n8n 会自动抓取 RSS → 发送给 ChatGPT 处理 → 推送到你的收件箱。

### 方案二：用 Hermes Agent 定时任务（进阶）

如果你已经在使用 Hermes Agent，可以直接用其内置的 cronjob 功能实现同样的效果：

```bash
hermes cron create '0 8 * * *' \
  --prompt "请抓取以下RSS源的最新内容，用ChatGPT生成中文早报，推送到xxx邮箱：36kr.com, huxiu.com, techcrunch.com" \
  --delivery email \
  --workdir /root
```

> 📌 提示：如果你想深入了解 AI 定时任务的完整配置，推荐先阅读《[用AI做定时数据采集与报表](/zh/guides/ai-data-collection-scheduled-report/)》一文，里面详细介绍了 cron 配置、错误处理和推送方式的选择。

### 方案三：纯 ChatGPT 手动版（最简单）

不想搭复杂系统？也可以每天手动操作：

1. 把 RSS 阅读器（如 Feedly、Inoreader）中收藏的文章链接复制到 ChatGPT
2. 输入提示词：「请根据以下文章链接，生成一份今日科技资讯摘要，突出重点发现和趋势判断」
3. ChatGPT 会联网抓取并生成摘要
4. 手动或通过浏览器插件转发到你的邮箱/笔记

适合信息量不大的轻度用户，每天花 5 分钟即可。

## 四、第三步：优化与迭代

搭建好系统之后，持续优化才能让早报真正有用。

### 1. 调整信息源权重

每周回顾一次早报内容，标记「最有价值」和「完全无关」的条目。根据反馈调整：
- 减少低质量来源的频率
- 增加高质量来源的权重
- 尝试新的信息源

### 2. 定制提示词模板

随着使用时间增长，你会发现某些格式更适合你。例如：
- 喜欢简短列表？改成「每条不超过30字，最多10条」
- 喜欢深度分析？改成「每条选一条深度解读，附背景知识」
- 喜欢行动导向？改成「基于今日资讯，给出3个可以行动的建议」

### 3. 跨平台分发

不要只发到一个地方。一个好的早报系统应该：
- 主推送渠道（如微信）：完整版
- 备用渠道（如邮件）：精简版
- 存档位置（如 Notion 或本地知识库）：完整原文 + AI 摘要

> 📌 如果你想把早报内容存档并建立可检索的知识库，可以参考《[用AI搭建个人本地知识库](/zh/guides/local-knowledge-base-guide/)》，学习如何把零散资讯变成结构化记忆。

## 六、常见问题解答

**Q：RSS订阅会不会过时了？**

不会。RSS 虽然概念很老，但在 AI 时代反而更有价值——它是结构化数据的黄金标准，比 API 更开放，比网页抓取更稳定。所有主流自动化工具都原生支持 RSS。

**Q：用免费版够吗？**

够用。n8n 开源版免费，RSSHub 开源免费，ChatGPT 免费版也能用（只是速度稍慢）。如果你有 ChatGPT Plus，体验会好很多。

**Q：会不会侵犯版权？**

早报系统生成的是摘要和引用，不是全文搬运。符合合理使用原则。如果你要发表到公开平台，建议加上原文链接。

**Q：如何防止信息过载？**

设定明确的边界：每天最多15条精选，每个类别最多5条。宁少勿多——早报的目的是帮你聚焦，不是增加负担。
