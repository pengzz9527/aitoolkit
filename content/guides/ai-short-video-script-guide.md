做短视频最卡人的环节，往往不是拍摄和剪辑，而是"今天拍什么、第一句话说什么"。选题靠灵感、文案憋半天、拍完才发现前3秒留不住人——这是大量个人创作者的日常。

这篇教程教你一套完整的AI口播脚本工作流：先用AI批量挖选题，再针对每条选题生成带分镜标注的逐字稿，最后筛掉不合格的、直接开拍。全程不需要你写"创作灵感"，只需要把提示词喂给AI、按模板填空。

## 第一步：让AI帮你挖出20个选题

不要一次让AI写脚本，先让它做选题挖掘。用下面的提示词，一次出20条候选：

```
你是一位运营了3年、粉丝50万的抖音知识博主。
我的账号定位：【填：你的赛道，如"零基础理财"、"职场沟通"、"居家收纳"】
我的目标观众：【填：年龄/身份/痛点，如"25-35岁刚工作的年轻人，钱不多但想开始投资"】

请给我20个口播短视频选题，要求：
1. 每个选题用"一个反常识结论 + 一个具体数字"的结构，例如"为什么90%的定投都亏了"
2. 选题要能被30-60秒讲完，不要大而空
3. 标注每个选题的钩子类型：痛点型/反差型/数字型/争议型
4. 最后按"预估完播率"从高到低排序，说明理由
```

拿到20条后，人工筛掉8条太抽象的、留12条。这一步5分钟能完成，比你自己憋选题快得多。

## 第二步：把选题变成黄金前3秒

口播视频生死在前3秒。AI最容易写"大家好，今天我们来聊聊……"这种无效开头，要显式禁止它。用这个模板：

```
下面是我的选题：【粘贴你选中的选题】
写一条60秒口播脚本的前3秒开头，必须满足：
- 第1句话是钩子，直接抛出结论或反常识，不超过15个字
- 禁止"大家好"、"今天分享"、"相信很多人"这类开头
- 钩子类型：【粘贴第一步中标注的类型】

写3个候选开头，然后告诉我哪个完播率最高、为什么。
```

实测下来，"数字型"钩子（如"坚持21天后我放弃了"）在知识类赛道完播明显高于"痛点型"，但每个账号不一样——让AI给你3个候选并说理由，你拍板。

## 第三步：生成带分镜的逐字稿

开头定了，再生成完整逐字稿。关键是要求AI输出"可拍摄"的格式，而不是一篇作文：

```
基于以下开头，写完整的60秒口播逐字稿：
【粘贴选定的开头】

格式要求：
- 按时间轴输出，每10秒一个段落
- 每个段落标注：画面建议（口播/展示图表/演示操作）+ 台词逐字稿
- 台词中所有专业名词后面括号里给一句大白话解释，方便我口播时自然带出
- 结尾加一个"引导评论"话术，用提问句，不要"记得点赞关注"
```

"画面建议"这一栏别忽略。它直接决定你拍摄时手机前置还是切空镜，能帮你省一半剪辑时间。

## 第四步：批量生产和质量抽检

确认模板好用后，把12个选题套进同一套提示词，一次批量生成12条逐字稿。注意两点：

1. **每条单独喂给AI**，不要让它一次写12条——上下文太长后质量会明显下滑，第5条之后的开头会开始套路化。
2. **抽检3条**，重点看两个指标：前3秒是否还有钩子（不是复述第一句）、结尾引导评论是不是提问句。不合格的重跑单条。

12条脚本筛出10条可用，一周的拍摄内容就有了。

## 第五步：配套两个效率技巧

**用正则表达式清洗AI输出格式。** 批量生成的脚本里经常混入markdown标记（`**`、`##`），拍前需要干净的纯文本。把12条脚本存成一个txt文件，用浏览器里的正则测试工具把 `\*\*` 替换为空、把 `^#.*$` 整行删掉，两分钟处理完。

**给脚本建个索引表。** 把12条脚本整理成一张表：选题、钩子类型、已拍状态、发布日期。这张表用CSV管就行，每天勾一下状态。后期想看"哪种钩子类型拍出来数据好"，直接把CSV丢进CSV数据分析工具跑个分组统计，30秒出结果——按钩子类型分组、统计每条的播放量均值，哪个类型最能打一目了然。

## 常见翻车点和补救

**AI写的太"书面"。** 口播稿念出来别扭，就追加一句指令："把这段改写成你朋友给你发微信吐槽时的语气，可以用'说白了'、'你猜怎么着'这类口头语"。

**数据引用不靠谱。** AI说"研究表明83%的人……"时，这个83%大概率是编的。处理办法：要么让它注明"不确定具体数字就模糊化为'绝大多数'"，要么你自己补一句来源。口播视频里被评论区揪出假数据，比没数据伤号。

**钩子写不出反常识。** 换赛道视角试试——"我朋友做自媒体的，他的钩子都是这么来的"，让AI先分析5个对标账号的热门视频开头，再让你按同样的句式套自己的选题。

## 完整流程回顾

| 步骤 | 耗时 | 产出 |
|------|------|------|
| 批量挖选题 | 10分钟 | 20条候选 → 筛到12条 |
| 前3秒钩子 | 每条2分钟 | 12个候选开头 |
| 逐字稿生成 | 每条3分钟 | 12份带分镜脚本 |
| 质量抽检 | 10分钟 | 10条可用脚本 |
| 格式清洗+索引 | 10分钟 | 干净的拍摄清单 |

总共大约1.5小时，覆盖一周的内容储备。拍摄和剪辑是另一套事，但"不知道拍什么、写不出开头"这两个最大阻力，到这里就解掉了。

这套工作流的核心不是提示词有多精妙，而是把"挖选题→写钩子→出逐字稿"拆成三个独立环节，每个环节只让AI做一件事，并且都要求它给可量化的产出（排序、候选、时间轴）。任务拆得越细，AI跑偏的概率越低，你验收起来也越快。
