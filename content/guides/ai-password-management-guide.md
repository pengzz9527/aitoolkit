## 一、先搞清楚：为什么你需要一个密码管理系统？

在你动手之前，理解为什么要做这件事很重要——这样你才有动力坚持下去。

### 1.1 你的密码正在被攻击

据数据统计，普通人平均拥有 **80+ 个在线账户**，但绝大多数人只使用了不到 10 个不同的密码。更可怕的是：

- **65% 的用户在多个网站使用相同密码**，一个平台泄露等于全部中招
- **平均密码长度只有 8-10 位**，且包含大量常见组合（123456、password、abc123）
- **大部分用户从不更换密码**，即使知道存在风险

### 1.2 好的密码管理系统应该满足三个条件

| 条件 | 说明 |
|------|------|
| **唯一性** | 每个网站使用不同密码，一个泄露不影响其他 |
| **高强度** | 16位以上、混合大小写数字符号、无规律可循 |
| **可回忆/可管理** | 你不会忘记密码，也不会丢失重要密码 |

传统做法是用密码管理器（如 1Password、Bitwarden），但这些工具需要付费或配置。本文将教你用 **AI + 免费工具** 的方式，同样达到这三个目标。

## 二、第一步：用AI生成高强度密码

好密码的第一步是**真正随机且够长**。人脑生成的密码往往有模式可循（生日、名字拼音、常用词），AI可以帮你生成真正高强度的密码。

### 方法1：用AI生成随机强密码

打开ChatGPT或Claude，输入以下提示词：

> 请为我生成10个高强度密码，要求：每个密码16-20位，包含大写字母、小写字母、数字和特殊符号，不使用任何有意义的单词或序列。格式为每行一个密码，不要做任何解释。

AI会给你一组类似这样的密码：

```
kR#9mP2$vL5@nQ8x
7tY$wE3&rT6!yU1z
bN4@cV8#xD2$fG5h
```

这些密码的特点是：无规律、高熵值、无法通过字典攻击破解。

### 方法2：用本站工具一键生成

如果你不想每次都找AI，可以直接使用 198007.xyz 的 **[强密码生成器](https://198007.xyz/tools/password-generator/)** —— 在浏览器里配置密码长度和字符类型，一键生成高强度密码，所有计算都在本地完成，不会上传到任何服务器。

**操作建议**：为不同重要程度的账户设置不同长度的密码：
- 银行/支付类：20位以上
- 社交/邮箱类：16位
- 普通网站：12-14位即可

### 方法3：用密码词组法记忆复杂密码

如果你担心记不住随机密码，可以使用"密码词组"（Passphrase）策略。打开 **[随机密码词组生成器](https://198007.xyz/tools/random-password-phrase/)**，它会从常用单词中随机抽取 4-6 个单词组合成一个长密码。

例如：`CorrectHorseBatteryStaple99!`

这种密码既长又有一定的记忆线索，比纯随机密码更容易记住，同时强度也远高于短密码。你可以在词组后面加上网站名缩写和特殊符号来区分不同网站，例如：
- Gmail: `CorrectHorseBatteryStaple99!gm`
- 微信: `CorrectHorseBatteryStaple99!wx`

## 三、第二步：检测密码强度，淘汰弱密码

生成了新密码之后，还要检查你现有的密码是否足够安全。让AI帮你批量分析。

### 3.1 用AI批量检测密码强度

把你的密码列表（暂时不要包含真实密码，用脱敏后的示例）交给AI分析：

> 请分析以下密码列表的安全性，指出每个密码的问题所在，并给出改进建议。密码列表：[粘贴你的密码]

AI会从以下几个维度评估：
- **长度是否足够**（建议12位以上）
- **字符多样性**（是否包含大小写、数字、符号）
- **是否包含常见模式**（连续字母、数字序列、键盘图案）
- **是否出现在已知泄露密码库中**

### 3.2 用工具精确测试密码强度

对于精确的强度评分，使用 198007.xyz 的 **[密码强度测试](https://198007.xyz/tools/password-strength-test/)** 工具。这个工具会计算密码的熵值（entropy），给你一个量化的安全评分。

> **注意**：不要在此类在线工具中输入你的真实密码！只测试虚构的示例密码，或用本地脚本自己跑。

### 3.3 AI帮你制定密码替换优先级

让AI帮你排序哪些密码最需要优先替换：

> 以下是我所有网站的密码列表（已脱敏），请按安全风险从高到低排序，并说明每个密码的风险等级和替换优先级。

AI会这样输出：

| 网站 | 风险等级 | 原因 | 优先级 |
|------|----------|------|--------|
| 银行APP | 🔴 极高 | 密码过于简单，且涉及资金安全 | 立即更换 |
| 邮箱 | 🔴 极高 | 密码与其他网站重复 | 立即更换 |
| 社交媒体 | 🟠 高 | 密码长度不足12位 | 本周更换 |
| 购物网站 | 🟡 中 | 包含个人信息（生日） | 本月更换 |
| 论坛/博客 | 🟢 低 | 密码已较复杂 | 下次登录时更换 |

## 四、第三步：建立加密密码存储系统

生成了好密码、检测了旧密码，接下来是最关键的一步——**安全地存储这些密码**。

### 方法1：本地加密文件存储（推荐）

最安全的方式是把密码存储在**本地加密文件**中，不上传到任何云端。

#### 步骤1：用AI生成密码存储格式

让ChatGPT帮你生成一个结构化的密码清单模板：

> 请帮我生成一个CSV格式的密码清单模板，包含以下列：网站名称、网址、用户名/邮箱、密码、密码强度备注、最后更新时间。然后用Python写一个脚本，用bcrypt对密码列进行哈希加密，生成一个加密的存储文件。

AI会给你一个类似这样的Python脚本：

```python
import bcrypt
import csv
import json

def hash_password(password: str) -> str:
    """用bcrypt对密码进行哈希加密"""
    return bcrypt.hashpw(password.encode(), bcrypt.gensalt()).decode()

def save_passwords(plaintext_path: str, encrypted_path: str, master_key: str):
    """读取明文密码文件，加密后保存"""
    with open(plaintext_path, 'r') as f:
        reader = csv.DictReader(f)
        rows = list(reader)
    
    # 用主密钥派生加密盐
    salt = bcrypt.gensalt(rounds=12)
    key_hash = bcrypt.hashpw(master_key.encode(), salt)
    
    encrypted_rows = []
    for row in rows:
        encrypted_row = {**row}
        encrypted_row['password'] = hash_password(row['password'])
        encrypted_rows.append(encrypted_row)
    
    with open(encrypted_path, 'w', newline='') as f:
        writer = csv.DictWriter(f, fieldnames=['website', 'url', 'username', 'password', 'notes', 'updated_at'])
        writer.writeheader()
        writer.writerows(encrypted_rows)
    
    print(f"加密完成！主密钥哈希已写入: {key_hash.decode()}")

# 使用示例
save_passwords('passwords_plain.csv', 'passwords_encrypted.csv', '你的主密钥')
```

#### 步骤2：了解密码哈希原理

如果你想深入理解这个过程，可以使用 198007.xyz 的 **[Bcrypt 哈希生成/验证工具](https://198007.xyz/tools/bcrypt-hash/)** 来直观感受密码是如何被转换为哈希值的。虽然这是模拟版本，但能帮你理解"为什么加密存储比明文存储安全得多"。

核心原理很简单：
- **加密** = 明文 → 密文（可以逆向解密）
- **哈希** = 明文 → 指纹（不可逆向，只能验证是否匹配）

密码存储应该用**哈希**而不是**加密**——即使文件泄露，黑客也无法还原你的原始密码。

### 方法2：用AI创建加密压缩包

如果你不想写代码，可以让AI帮你生成一个加密的ZIP方案：

> 请帮我写一段PowerShell脚本，把密码CSV文件用AES-256加密成ZIP压缩包，密码由用户输入，加密后的文件保存在本地。

AI会给你一个完整的脚本，你只需要运行它，输入主密钥，就能得到加密存储文件。

### 方法3：使用本地Markdown笔记加密存储

如果你已经有笔记习惯，可以用加密Markdown文件来存储密码：

1. 把密码清单整理成Markdown表格
2. 用AI生成加密脚本
3. 将加密后的内容保存为 `.enc` 文件
4. 存放在本地加密磁盘或加密云盘中

## 六、第五步：用DuckDB分析密码安全态势

当你的密码清单积累到一定规模（比如50+条），你可以用数据分析工具来发现安全趋势。

### 6.1 导出密码清单进行分析

把你的密码清单（脱敏后）导出为CSV，上传到 **[CSV/SQL 在线分析器](https://198007.xyz/tools/csv-sql-analyzer/)**，用SQL查询分析：

```sql
-- 统计各风险等级的密码数量
SELECT risk_level, COUNT(*) as count 
FROM passwords 
GROUP BY risk_level 
ORDER BY count DESC;

-- 找出密码长度不足的账户
SELECT website, password_length 
FROM passwords 
WHERE password_length < 12 
ORDER BY risk_level ASC;

-- 统计密码更新频率分布
SELECT 
  CASE 
    WHEN last_updated >= date('now', '-30 days') THEN '本月内'
    WHEN last_updated >= date('now', '-90 days') THEN '本季度内'
    ELSE '超过90天'
  END as update_range,
  COUNT(*) as count
FROM passwords
GROUP BY update_range;
```

通过这些分析，你能直观看到自己的密码安全状况——有多少高风险账户还没更新、密码长度分布如何、更换频率是否合理。

### 6.2 用DuckDB做长期趋势追踪

如果你有历史密码数据，可以把每次更换的记录存入 DuckDB，追踪密码安全指标的改善趋势。想了解更多 DuckDB 的使用技巧，欢迎访问 **[DuckDB Lab](https://duckdblab.org/zh/)** ，这里有丰富的查询优化和数据清洗教程。

## 八、常见误区与避坑指南

### 误区1：用一个密码管理器就万事大吉

密码管理器确实方便，但前提是**主密码足够强**。如果主密码被破解，所有密码都暴露。建议：密码管理器的 master password 也要用 AI 生成的高强度密码，并开启双重认证。

### 误区2：把密码存在微信收藏或备忘录里

备忘录里的密码是明文存储的，一旦手机丢失或被恶意软件扫描，所有密码瞬间泄露。**永远不要用备忘录存储密码**。

### 误区3：定期更换所有密码会导致疲劳

不必每次换新密码都用完全不同的规则。可以采用"基础密码 + 网站特定后缀"的策略，用 AI 帮你批量生成变体，既保持变化又不会太复杂。

### 误区4：认为"我的账户没什么价值，不值得被攻击"

这是最常见的思维陷阱。黑客攻击不是针对"有价值的账户"，而是批量扫描弱密码。你的邮箱、社交账号一旦被拿下，可能被用于诈骗你的联系人，损失远超你的想象。
