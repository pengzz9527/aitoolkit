## 一句话介绍

**TimesFM 2.5** 是 Google Research 开源的时间序列基础模型（Time Series Foundation Model），仅用 200M 参数就实现了强大的多变量时序预测能力，支持最长 16K 上下文长度、连续分位数预测和协变量回归，是工业级时间序列分析的首选 AI 工具。

## 它是什么？

TimesFM（Time Series Foundation Model）由 Google Research 开发，是一种基于解码器架构的基础模型，专门用于时间序列预测任务。不同于传统统计方法（如 ARIMA、Prophet）或专用深度学习模型，TimesFM 采用预训练-微调范式，在一个涵盖多个领域的大规模时间序列数据集上进行预训练，然后可以直接用于各种下游预测任务，无需针对每个场景重新训练。

该项目于 2024 年首次发布，论文《A Decoder-Only Foundation Model for Time-Series Forecasting》收录于 ICML 2024。截至 2026 年 6 月，GitHub 已获得 **24,000+ 星标**，2,200+ Fork，采用 Apache 2.0 开源协议。

**TimesFM 2.5** 于 2025 年 9 月发布，相比之前的 2.0 版本进行了重大升级：参数量从 500M 降至 200M，上下文长度从 2048 提升至 16K，新增连续分位数预测头（30M 参数），移除了频率指示器，并增加了协变量支持（XReg）。2026 年 4 月又新增了基于 HuggingFace Transformers + PEFT（LoRA）的微调示例。

## 核心功能

### 1. 强大的零样本预测能力

TimesFM 的核心优势在于其预训练基础模型架构。它在涵盖金融、能源、零售、物联网等多个领域的海量时间序列数据上进行了预训练，因此面对全新的时间序列数据时，无需任何微调就能给出合理的预测结果。这种零样本（zero-shot）能力使得它在数据稀缺或快速部署场景中极具价值。

### 2. 超长上下文支持（最高 16K）

TimesFM 2.5 支持高达 16,000 个历史数据点的上下文窗口，远超大多数传统时序模型的 2,048 限制。这意味着它可以捕捉更长期的季节性和趋势模式，对于具有复杂季节性（如年度周期、多年趋势）的数据集特别有效。

### 3. 连续分位数预测

通过可选的 30M 参数分位数头，TimesFM 2.5 支持从第 10 百分位到第 90 百分位的连续分位数预测。这为不确定性量化提供了重要工具——用户不仅得到点预测值，还能获得预测区间，在风险管理、库存优化等场景中极为关键。

### 4. 协变量回归（XReg）支持

2025 年 10 月更新后，TimesFM 2.5 增加了对协变量的支持。用户可以引入外部变量（如促销活动、天气数据、节假日等）来增强预测精度。这对于实际业务场景中利用额外信息进行精准预测非常有用。

### 5. 灵活的部署选项

TimesFM 同时支持 PyTorch 和 Flax（JAX）后端：
- **PyTorch 版本**：适合熟悉 PyTorch 生态的用户，可直接通过 `pip install timesfm[torch]` 安装
- **Flax 版本**：推理速度更快，适合对性能敏感的生产环境
- **Google 第一方产品集成**：已在 BigQuery ML、Google Sheets、Vertex AI Model Garden 等产品中落地

## 如何使用

### 安装

```bash
# 使用 PyTorch 后端
pip install timesfm[torch]

# 或使用 Flax 后端（推理更快）
pip install timesfm[flax]

# 如需协变量支持
pip install timesfm[xreg]
```

### 基本预测示例

```python
import torch
import numpy as np
import timesfm

torch.set_float32_matmul_precision("high")

# 加载 TimesFM 2.5 模型
model = timesfm.TimesFM_2p5_200M_torch.from_pretrained("google/timesfm-2.5-200m-pytorch")

# 配置预测参数
model.compile(
    timesfm.ForecastConfig(
        max_context=1024,
        horizon=12,
        normalize_inputs=True,
        use_continuous_quantile_head=True,
        force_flip_invariance=True,
        infer_is_positive=True,
        fix_quantile_crossing=True,
    )
)

# 执行预测
point_forecast, quantile_forecast = model.forecast(
    horizon=12,
    inputs=[
        np.linspace(0, 1, 100),       # 示例序列 1
        np.sin(np.linspace(0, 20, 67)), # 示例序列 2
    ],
)

print(point_forecast.shape)    # (2, 12) - 两条序列各预测 12 步
print(quantile_forecast.shape) # (2, 12, 10) - 均值 + 10th~90th 分位数
```

### 使用 Hugging Face 加载

```python
from huggingface_hub import hf_hub_download
import timesfm

# 直接从 Hugging Face 下载模型权重
checkpoint_path = hf_hub_download(
    repo_id="google/timesfm-2.5-200m-jax",
    filename="checkpoints/checkpoint_00000",
    repo_type="model"
)

# 加载 JAX 版本模型
tfm = timesfm.TimesFm(
    hparams=timesfm.TimesFmHParams(
        backend="jax",
        checkpoint_type=timesfm.CheckpointType.AWQ,
    ),
    wmgr=timesfm.WeightManager(checkpoint_path=checkpoint_path),
)

point_forecasts, quantile_forecasts = tfm.forecast(
    [your_time_series_data],
    forecast_horizon=12,
)
```

### 在 BigQuery ML 中使用（无需代码）

如果你的数据已经存储在 Google Cloud 上，可以直接在 SQL 中调用 TimesFM：

```sql
SELECT * FROM ML.FORECAST(
  MODEL `my_project.my_dataset.timesfm_model`,
  STRUCT(12 AS horizon, 0.95 AS confidence_level)
)
```

## 优缺点总结

### 优点

- **开箱即用**：预训练模型直接可用，零样本预测效果好
- **参数高效**：200M 参数实现卓越性能，推理成本远低于大型模型
- **灵活部署**：支持 PyTorch、Flax、BigQuery ML、Google Sheets 等多种方式
- **持续更新**：从 1.0 到 2.5 不断迭代，社区活跃
- **开源免费**：Apache 2.0 协议，商业使用无顾虑
- **不确定性量化**：内置分位数预测，适合风险敏感场景

### 缺点

- **学习曲线**：高级功能（协变量、微调）需要一定的 ML 基础
- **GPU 依赖**：虽然 200M 参数较小，但大规模数据仍需 GPU 加速
- **文档尚不完善**：部分高级功能的文档仍在补充中
- **中文资料少**：目前以英文文档和社区为主

## 推荐指数

⭐⭐⭐⭐⭐ **4.5 / 5**

TimesFM 2.5 是目前时间序列预测领域最先进的开源工具之一。Google Research 的工程实力体现在模型的高效性和实用性上——用更少的参数实现了更好的效果。无论是快速原型验证还是生产部署，TimesFM 都能胜任。

唯一扣分项在于文档和中文社区生态还不够完善，但对于有 ML 基础的用户来说，这并不构成实质性障碍。

**推荐场景**：需求预测、销售预测、异常检测、容量规划、金融时间序列分析。如果你正在寻找一个"装上去就能用"的时间序列预测方案，TimesFM 2.5 是目前最佳选择之一。
