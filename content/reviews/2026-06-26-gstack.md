## 一句话介绍

**gstack** 是 Y Combinator 总裁 Garry Tan 开源的 AI 编码工作流套件——把 Claude Code（或 Cursor、Codex 等其他 AI 编码助手）变成一个虚拟工程团队。23 个专业角色 Slash 命令，覆盖从产品构思、架构设计、代码审查、安全审计到发布部署的完整软件开发周期。MIT 开源许可，支持 10+ AI 编码代理。

---

## 核心功能

### 1. 完整的软件开发冲刺流程

gstack 不是零散的工具集合，而是一个端到端的开发方法论。它将软件冲刺分为七个阶段：**思考 → 计划 → 构建 → 审查 → 测试 → 发布 → 反思**。每个阶段都有对应的专业角色，上一个阶段的输出自动传递给下一个阶段，确保没有环节遗漏。

```
/office-hours → /plan-ceo-review → /plan-eng-review → 编码
→ /review → /qa → /ship → /land-and-deploy
```

### 2. 23 个专业 AI 角色

gstack 提供了 23 个 Slash 命令，每个都代表一个特定的专业角色：

| 角色 | 命令 | 职责 |
|------|------|------|
| YC 办公时间顾问 | `/office-hours` | 六个强制性问题重新定义你的产品方向，产出设计文档 |
| CEO/创始人评审 | `/plan-ceo-review` | 四种模式挑战产品范围，寻找被隐藏的创新机会 |
| 工程经理评审 | `/plan-eng-review` | 锁定架构、数据流、ASCII 图表、边界情况和测试计划 |
| 高级设计师评审 | `/plan-design-review` | 对每个设计维度 0-10 评分，检测 AI 生成的粗糙设计 |
| 开发者体验负责人 | `/plan-devex-review` | 20-45 个强制问题评估开发者体验，三种模式可选 |
| 设计合伙人 | `/design-consultation` | 从零构建完整的设计系统 |
| 高级工程师审查 | `/review` | 发现通过 CI 但在生产中会崩溃的 bug，自动修复明显问题 |
| 调试专家 | `/investigate` | 系统化根因调试，三条铁律：不调查就不修复 |
| 编码设计师 | `/design-review` | 审计设计问题并修复，原子提交，前后截图对比 |
| 设计探索器 | `/design-shotgun` | 生成 4-6 个 AI 设计变体，浏览器中对比，持续迭代直到满意 |
| 设计工程师 | `/design-html` | 将设计稿转为生产级 HTML，30KB 零依赖 |
| QA 主管 | `/qa` | 打开真实浏览器测试应用，发现并修复 bug，自动生成回归测试 |
| QA 报告员 | `/qa-only` | 纯 Bug 报告，不修改代码 |
| CISO（首席安全官） | `/cso` | OWASP Top 10 + STRIDE 威胁建模，零噪音过滤 |
| 发布工程师 | `/ship` | 同步主分支、运行测试、审计覆盖率、推送、创建 PR |
| 部署工程师 | `/land-and-deploy` | 合并 PR、等待 CI、部署、验证生产健康状态 |
| 性能监控 SRE | `/canary` | 部署后监控循环，检测控制台错误、性能回退 |
| 性能工程师 | `/benchmark` | 基线页面加载时间、Core Web Vitals、资源大小对比 |
| 多代理协调器 | `/pair-agent` | 与任何 AI 代理共享浏览器，自动 ngrok 隧道 |
| 自动化规划 | `/autoplan` | 自动制定开发计划 |
| 代码生成 | `/codex` | 跨代理代码生成支持 |
| 学习模块 | `/learn` | 帮助新手理解 gstack 工作流 |

### 3. 跨代理兼容——不止 Claude Code

gstack 最让人印象深刻的是它的广泛兼容性。它不仅仅服务于 Claude Code，还原生支持 10 种以上的 AI 编码代理：

- **Claude Code**（默认，最佳体验）
- **OpenAI Codex CLI**
- **Cursor**
- **OpenCode**
- **Factory Droid**
- **Slate**
- **Kiro**
- **Hermes**
- **GBrain**
- **OpenClaw**（通过 ACP 协议自动分发）

安装时只需指定 `--host` 参数，技能就会自动安装到对应代理的配置目录中。这种跨平台策略让 gstack 成为 AI 编码工具生态中的"通用技能包"。

### 4. 团队模式——自动更新与共享

gstack 提供了独特的团队模式。通过一行命令即可在仓库中启用团队协作：

```bash
./setup --team && gstack-team-init required && git add .claude/ CLAUDE.md && git commit -m "require gstack for AI-assisted work"
```

团队成员拉取代码后，每次 Claude Code 会话都会自动检查 gstack 更新（每小时限一次，网络故障安全，完全静默）。无需在仓库中维护 vendored 文件，避免了版本漂移问题。

### 5. 安全审计——企业级威胁建模

`/cso`（首席安全官）命令集成了 OWASP Top 10 和 STRIDE 威胁建模框架。它内置了 17 种误报排除规则和 8/10+ 置信度门控机制，确保每个安全发现都是独立验证的真实漏洞。每个发现都附带具体的攻击场景描述，而不仅仅是理论上的风险列表。

## 如何使用

### 快速安装（30 秒）

在 Claude Code 中粘贴以下指令：

```
Install gstack: run git clone --single-branch --depth 1 https://github.com/garrytan/gstack.git ~/.claude/skills/gstack && cd ~/.claude/skills/gstack && ./setup
```

安装完成后，在 `CLAUDE.md` 中添加 gstack 配置部分，告知 Claude Code 使用 gstack 的技能。

### 使用示例：从零构建一个应用

假设你想构建一个每日简报应用：

**Step 1: 产品构思**
```
你: 我想为我的日历构建一个每日简报应用
你: /office-hours
```
gstack 会提出六个强制性问题，帮你重新定义产品方向。比如它可能会指出"你说的每日简报应用，实际上是一个个人 AI 首席幕僚"。

**Step 2: CEO 评审**
```
你: /plan-ceo-review
```
阅读 Step 1 产出的设计文档，从 CEO 视角挑战产品范围和优先级。

**Step 3: 工程评审**
```
你: /plan-eng-review
```
生成 ASCII 数据流图、状态机、错误路径分析和测试矩阵。

**Step 4: 编码实现**
```
你: 批准计划。退出计划模式。
```
AI 会自动生成代码，约 2400 行，涉及 11 个文件，耗时约 8 分钟。

**Step 5: 代码审查**
```
你: /review
```
自动发现并修复 2 个问题，标记需要人工审批的竞态条件。

**Step 6: QA 测试**
```
你: /qa https://staging.myapp.com
```
打开真实浏览器，点击各个流程，发现并修复 bug。

**Step 7: 发布上线**
```
你: /ship
```
测试从 42 增加到 51 个，自动创建 PR。

### 安装到其他 AI 代理

gstack 支持多种代理，以 Codex 为例：

```bash
git clone --single-branch --depth 1 https://github.com/garrytan/gstack.git ~/gstack
cd ~/gstack && ./setup --host codex
```

技能将自动安装到 `~/.codex/skills/gstack-*/` 目录下。

## 总结推荐

gstack 代表了 AI 辅助软件开发的一个重要方向——**不是简单地让 AI 写代码，而是让 AI 扮演整个工程团队的角色**。Garry Tan 作为 YC 总裁，分享了他个人高效产出背后的秘密武器：23 个专业角色的结构化工作流。

**优点**：
- 完整的软件开发方法论，覆盖从构思到发布的每一个环节
- 23 个专业角色，每个都针对特定任务深度优化
- 跨 10+ AI 编码代理兼容，不绑定单一平台
- MIT 开源许可，可自由使用和修改
- 团队模式解决了多人协作的版本管理问题
- 内置安全审计和 QA 自动化，减少人为疏漏

**注意事项**：
- 需要理解软件工程基本流程才能充分利用
- 当前对 Claude Code 的体验最佳，其他代理的功能可能略有差异
- 部分命令（如 `/qa`）需要配置浏览器和外部服务
- 23 个命令的学习曲线相对较陡，建议从 `/office-hours` 和 `/review` 开始

**推荐指数：★★★★☆（4.5/5）**

对于任何使用 AI 编码助手进行软件开发的人来说，gstack 都是一个值得尝试的工具。它不仅仅是一组提示词模板，更是一套经过实战验证的工程方法论。无论你是独立开发者还是团队技术负责人，gstack 都能帮助你以更少的精力产出更高质量的产品。
