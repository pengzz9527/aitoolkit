# Video-Use: 用自然语言对话编辑视频，告别复杂剪辑软件

> 一句话简介：Video-Use 是一个基于 AI Agent 的开源视频编辑工具，让你通过聊天来剪辑视频——自动去除口误、智能调色、生成字幕和动画叠加层。

在视频创作领域，剪辑一直是门槛最高的环节之一。无论是专业的 DaVinci Resolve、Final Cut Pro，还是入门级的剪映，都需要用户学习复杂的界面和时间线操作。而 **Video-Use** 的出现正在改变这一现状——它让视频编辑变成了一场简单的对话。

Video-Use 由知名 AI 浏览器自动化项目 **Browser Use** 的团队开发，目前在 GitHub 上已获得 **12,700+ Star**，是近期 AI 工具赛道中最受关注的视频编辑项目之一。

## 核心功能

### 1. 智能转录与精准剪辑
Video-Use 使用 ElevenLabs Scribe API 对视频进行逐词级语音转录，获取精确到毫秒的时间戳、说话人分离以及音频事件标注（如笑声、掌声、叹息）。基于这些结构化数据，AI 代理可以精准定位填充词（如"嗯""啊"）、断句和沉默间隙，实现**按词边界剪辑**，避免生硬的切割。

### 2. 自动去除口误与填充词
对于口播类视频（演讲、教程、访谈），视频中的"嗯""那个""呃"等填充词会严重影响观感。Video-Use 会自动识别并标记这些片段，在获得用户确认后精准删除，同时应用 30ms 音频淡入淡出确保过渡平滑无爆音。

### 3. 智能调色与风格化
内置 ffmpeg 滤镜链支持多种预设调色方案（暖色调电影感、中性高对比度等），也支持自定义滤镜参数。每个剪辑段都会独立应用调色，保证画面一致性。

### 4. 自动字幕生成
支持自定义风格的字幕烧录——默认采用两词大写的高亮风格，也可完全自定义字体、颜色、位置和样式。字幕会在渲染管线最后一步应用，确保不会被其他叠加层遮挡。

### 5. 并行动画叠加层生成
通过独立的子代理并行生成动画叠加层，支持 HyperFrames、Remotion、Manim 等多种动画引擎。多个动画可以同时生成，总耗时仅等于最慢的一个。

### 6. 自我评估闭环
这是 Video-Use 最令人印象深刻的设计：每次渲染后，系统会自动在每一个剪辑边界运行 `timeline_view`，检查视觉跳变、音频爆音、字幕被遮挡等问题。只有自检通过的成品才会展示给用户，最多循环 3 次。

## 工作原理

Video-Use 的核心设计理念是 **"文本优先，视觉按需"**：

1. **转录层（始终加载）**：将视频转化为约 12KB 的结构化文本（`takes_packed.md`），包含每句话的时间戳、说话人和音频事件。这类似于 Browser Use 给 LLM 提供结构化的 DOM 而非截图。
2. **视觉层（按需调用）**：仅在决策点生成时间线视图（胶片 + 波形图 + 文字标签的 PNG），避免了暴力逐帧分析带来的 Token 浪费。

整个编辑流程为：**转录 → 打包 → LLM 推理 → 编辑决策列表（EDL）→ 渲染 → 自我评估**。如果自检发现问题，则修复并重渲染。

## 如何使用

### 环境准备

1. 克隆项目并安装依赖：
```bash
git clone https://github.com/browser-use/video-use
cd video-use
uv sync  # 或 pip install -e .
```

2. 安装 FFmpeg（必需）：
```bash
# macOS
brew install ffmpeg
# Ubuntu/Debian
apt-get install ffmpeg
```

3. 可选：安装 yt-dlp（用于下载在线视频）：
```bash
brew install yt-dlp  # macOS
apt-get install yt-dlp  # Ubuntu
```

### 配置 API Key

Video-Use 使用 ElevenLabs Scribe API 进行语音转录：

```bash
cp .env.example .env
# 编辑 .env 文件，填入你的 ElevenLabs API Key
# ELEVENLABS_API_KEY=your_key_here
```

你可以在 [ElevenLabs 官网](https://elevenlabs.io/app/settings/api-keys) 注册并获取 API Key。

### 使用 AI 代理运行

Video-Use 设计为与 AI 编码代理配合使用。以下是支持的代理：

- **Claude Code**（官方首选）
- **Codex**
- **Hermes**
- **OpenClaw**

设置方式：将项目软链接到代理的技能目录：
```bash
ln -sfn ~/video-use ~/.claude/skills/video-use
```

### 开始编辑

1. 将原始视频放入一个文件夹
2. 启动 AI 代理并进入该文件夹：
```bash
cd /path/to/your/videos
claude
```
3. 用自然语言下达指令：
```
把这些素材剪辑成一个发布视频
```
4. AI 代理会自动：
   - 清点所有素材
   - 转录并打包
   - 向你提议剪辑策略
   - 等待你确认
   - 执行剪辑、调色、加字幕
   - 自我评估后输出 `final.mp4`

所有输出文件保存在 `<视频目录>/edit/` 文件夹中，原始素材不会被修改。

## 设计亮点

Video-Use 的设计哲学值得每一位开发者借鉴：

1. **硬规则与自由度的平衡**：定义了 12 条不可违反的生产级规则（如字幕最后应用、按词边界剪辑等），其余全部交给 AI 的艺术判断。
2. **记忆持久化**：通过 `project.md` 记录每次会话的决策，下次打开时能无缝衔接。
3. **零假设原则**：不预设视频类型（演讲、访谈、旅行 Vlog），先观察素材再决定策略。
4. **并行化思维**：多个动画子代理同时运行，最大化利用计算资源。

## 潜在局限

- **依赖 ElevenLabs API**：虽然转录质量很高，但需要付费 API Key，且对网络有一定要求
- **需要 AI 代理环境**：目前主要与 Claude Code 等代理配合使用，纯命令行使用体验有限
- **学习 ffmpeg 知识**：高级用户可能需要了解 ffmpeg 滤镜语法来自定义调色效果
- **中文支持待验证**：ElevenLabs Scribe 对中文的转录精度需要实际测试

## 总结

Video-Use 代表了视频编辑工具的一个新方向：**用对话代替界面，用推理代替拖拽**。它不是要取代专业剪辑软件，而是为那些不需要逐帧精细控制、但追求效率的日常创作者提供了一个全新的工作流。

对于经常制作口播、教程、访谈类视频的内容创作者来说，Video-Use 可以大幅减少在剪辑软件 UI 上的时间消耗，让你专注于内容本身而非技术参数。
