# Crawl4AI 评测：开源 LLM 友好的网页爬虫与数据采集神器

在 AI 大模型时代，高质量的数据是训练和微调模型的核心资源。传统的网页爬虫（如 Scrapy）虽然功能强大，但输出格式往往不适合直接喂给 LLM。**Crawl4AI** 正是为解决这一痛点而生——它是一个专为 AI 场景设计的开源爬虫框架，将网页抓取与 LLM 友好格式完美结合。

**一句话简介：** 一个开源、异步、LLM 友好的高性能网页爬虫和 scraper，支持浏览器渲染、智能内容提取和结构化数据输出，71000+ Star。

## 核心功能

### 1. LLM 友好型输出格式

Crawl4AI 最大的特色就是为 LLM 优化输出格式。它不仅能提取纯文本内容，还能保留 HTML 结构、元数据、链接关系等丰富信息，使大模型能够理解网页的完整语义结构。输出可直接用于 RAG 系统、知识库构建或模型微调。

### 2. 异步并发架构

基于 Python asyncio 构建，Crawl4AI 支持高并发异步爬取。相比传统同步爬虫，其性能可提升数十倍，特别适合大规模数据采集场景。内置请求队列管理和速率限制，避免对目标网站造成过大压力。

### 3. 浏览器渲染支持

对于 JavaScript 动态渲染的单页应用（SPA），Crawl4AI 内置了浏览器自动化引擎，可以等待页面完全加载后再提取内容。这意味着你可以抓取 React、Vue、Angular 等前端框架构建的现代网站。

### 4. 智能内容提取

提供多种提取策略：
- **CSS 选择器**：精确提取特定元素
- **XPath**：处理复杂嵌套结构
- **AI 辅助提取**：利用 LLM 自动识别和提取关键信息
- **Markdown 转换**：直接将网页转换为干净的 Markdown 格式

### 5. 数据清洗与后处理

内置强大的数据清洗管道，自动去除广告、导航栏、侧边栏等无关内容，只保留核心正文。支持自定义清洗规则，可根据不同网站类型调整提取策略。

## 如何使用

### 安装方法

```bash
pip install crawl4ai
```

或者使用 Docker 部署：

```bash
docker pull unclecode/crawl4ai
```

### 基本使用示例

**简单爬取：**

```python
from crawl4ai import AsyncWebCrawler

async def main():
    async with AsyncWebCrawler(verbose=True) as crawler:
        result = await crawler.arun(url="https://example.com")
        print(result.markdown)

import asyncio
asyncio.run(main())
```

**带浏览器渲染的爬取：**

```python
result = await crawler.arun(
    url="https://react-app.example.com",
    browser_config={"js_enabled": True}
)
```

**AI 辅助内容提取：**

```python
result = await crawler.arun(
    url="https://news.example.com",
    extraction_strategy="llm_extration",
    extraction_params={
        "provider": "openai/gpt-4",
        "instruction": "提取新闻标题、摘要和发布时间"
    }
)
```

**批量爬取：**

```python
urls = ["https://site1.com", "https://site2.com", "https://site3.com"]
results = await crawler.arun_many(urls, warmup=True)
```

### API 服务部署

Crawl4AI 还提供 RESTful API 模式，方便集成到现有系统中：

```bash
crawl4ai serve --port 8000
```

然后通过 HTTP 请求进行爬取：

```bash
curl -X POST http://localhost:8000/crawl \
  -H "Content-Type: application/json" \
  -d '{"url": "https://example.com"}'
```
