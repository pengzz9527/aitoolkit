## 一句话介绍

**Omnigent** 是一个开源的 AI 代理编排框架和元控制面板（Meta-Harness），让你在一个统一的界面中同时调度 Claude Code、Codex、Cursor、Pi 等多个 AI 编程代理，支持跨设备协作、策略治理和实时团队协作。GitHub 4,489+ 星标，Apache 2.0 开源协议。

---

## 核心功能

### 1. 统一代理编排，告别工具切换

Omnigent 最大的亮点是它的"元控制面板"理念——它不取代任何单一 AI 代理，而是在它们之上提供一个统一的编排层。你可以在同一个会话中使用 Claude Code 写代码、用 Codex 做审查、用 Pi 做头脑风暴，无需在多个工具之间来回切换。代理之间可以互相委托任务，比如让一个代理review另一个代理的代码。

### 2. 跨设备无缝协作

Omnigent 的会话可以跨设备同步：你可以在终端启动一个代理会话，然后在浏览器中继续，甚至用手机随时查看进度。消息、子代理、终端输出和文件变更都保持实时同步。对于经常出差或喜欢多设备工作的开发者来说，这个功能非常实用。

### 3. 策略治理与安全沙箱

企业级用户最关心的安全问题，Omnigent 提供了完善的策略系统。你可以为代理设置各种策略：在执行危险操作前需要人工审批、限制 token 消耗预算、控制代理可以使用的工具范围等。策略分为三层（服务器级、代理级、会话级），且越具体的策略优先级越高。Linux 上还内置了 bubblewrap 沙箱隔离。

### 4. 灵活的模型支持

Omnigent 支持四种凭证类型：官方 API 密钥（Anthropic、OpenAI 等）、订阅模式（Claude Pro/Max、ChatGPT 计划）、兼容网关（OpenRouter、LiteLLM、Ollama、vLLM、Azure），以及 Databricks 工作区。每个代理可以有独立的默认模型，会话中还可以随时切换。

### 5. 团队协作与云部署

Omnigent 支持多用户协作，团队成员可以共享会话、实时观察代理工作、甚至共同操控（co-drive）。部署方式灵活：可以本地运行（Docker Compose 一键启动），也可以部署到 Render、Fly.io、Railway、Hugging Face Spaces 或 Modal 等云平台。还支持将代理部署在云沙箱中运行，不需要你的笔记本一直在线。

## 适用人群

- **多代理开发者**：如果你同时使用多个 AI 编程工具（Claude Code、Codex、Cursor 等），Omnigent 能让你统一管理，避免工具碎片化。
- **团队协作者**：需要团队成员共同使用 AI 代理进行代码审查、头脑风暴或结对编程的场景。
- **企业安全管理员**：需要对 AI 代理的使用进行策略管控、预算限制和操作审计的企业用户。
- **远程工作者**：需要在手机、平板、笔记本之间无缝切换 AI 会话的开发者。
- **AI 研究者**：想快速搭建多代理实验环境，比较不同模型和代理框架的效果。

| 特性 | Omnigent | CrewAI | LangGraph | AutoGen |
|------|----------|--------|-----------|---------|
| 支持的代理类型 | Claude Code、Codex、Cursor、Pi 及自定义 | 自定义为主 | 自定义为主 | 自定义为主 |
| 跨设备同步 | ✅ 原生支持 | ❌ | ❌ | ❌ |
| 策略治理 | ✅ 三层策略系统 | ❌ | ⚠️ 需自行实现 | ⚠️ 有限 |
| 团队协作 | ✅ 实时共享/共驾 | ⚠️ 基础 | ❌ | ❌ |

**关键差异**：Omnigent 的独特之处在于它是"代理的代理"——不自己写代理逻辑，而是为你已有的代理提供统一的编排、治理和协作层。而 CrewAI、LangGraph、AutoGen 更偏向于从零构建自己的代理工作流。

## 如何使用

### 安装

```bash
# 一键安装（推荐）
curl -fsSL https://raw.githubusercontent.com/omnigent-ai/omnigent/main/scripts/install_oss.sh | sh

# 或使用 uv 安装
uv tool install omnigent

# 或使用 Homebrew
brew install omnigent-ai/tap/omnigent
```

安装后有两个等效命令：`omnigent` 和简写的 `omni`。

### 启动第一个会话

```bash
# 交互式选择模型并启动会话
omnigent

# 或直接启动特定代理
omnigent claude    # 使用 Claude Code
omnigent codex     # 使用 Codex
```

启动后，终端会自动打开一个本地 Web UI（http://localhost:6767），你可以在浏览器中与代理交互。

### 配置模型凭证

```bash
omnigent setup
```

按提示添加 API 密钥、订阅凭证或网关配置。Omnigent 会自动检测环境变量中的现有凭证（如 `ANTHROPIC_API_KEY`、`OPENAI_API_KEY`）。

### 使用示例代理

Omnigent 自带两个有趣的示例代理：

```bash
# 🐙 Polly - 多代理编码协调员
# 她本人不写代码，而是作为技术主管规划、委派任务给编码子代理
omnigent run examples/polly/

# 🟠🔵 Debby - 双头头脑风暴伙伴
# 同时向 Claude 和 GPT 提问，并排展示两个答案
omnigent run examples/debby/
```

### 部署团队协作服务器

```bash
# 启动本地服务器
omnigent server start

# 注册本机为托管节点
omnigent host

# 团队成员通过浏览器访问 http://你的IP:6767 加入协作
```

### 编写自定义代理

只需一个简单的 YAML 文件：

```yaml
name: my_agent
prompt: 你是一个有帮助的数据分析师。

executor:
  harness: claude-sdk

tools:
  word_count:
    type: function
    callable: mypackage.mymodule.word_count
```

然后用 `omnigent run path/to/my_agent.yaml` 即可运行。

## 总结

Omnigent 代表了 AI 代理工具的一个新方向——不再局限于单个代理的能力，而是通过编排层把多个代理整合成一个协作系统。它的核心优势在于：

- **统一入口**：一个工具管理所有代理，告别多工具切换
- **跨设备体验**：从手机到笔记本无缝衔接
- **企业级治理**：策略系统让 AI 代理使用可控、可审计
- **灵活部署**：从本地到云端，从个人到团队全覆盖
- **开箱即用**：自带示例代理，五分钟就能体验多代理协作

**推荐指数**：⭐⭐⭐⭐☆（4.5/5）

对于已经在使用多个 AI 编程代理的开发者来说，Omnigent 几乎是必装的效率工具。唯一的不足是目前仍处于 Alpha 阶段，部分高级功能可能还有改进空间。但考虑到它才上线两周就已经获得 4,500+ 星标，发展速度非常快，值得持续关注。
