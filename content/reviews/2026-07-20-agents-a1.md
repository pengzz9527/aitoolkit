## 工具简介

**Agents-A1**（仓库名 `InternScience/Agents-A1`）是由 InternScience 团队开发的 35B Mixture-of-Experts（MoE）智能体模型，于 2026 年 6 月 26 日在 Hugging Face 开源。该模型专注于构建通用型 AI Agent，在长程搜索、工程任务、科学研究、指令遵循和工具调用等五大领域展现出卓越能力。项目采用 Apache-2.0 许可证，模型权重完全开放。

截至 2026 年 7 月，该模型在 Hugging Face 已获得 **584+ Likes** 和 **35,800+ Downloads**，位列 Hugging Face Trending 榜单前列。7 月 14 日还发布了更轻量的 4B 版本，进一步降低了本地部署门槛。

一句话总结：**Agents-A1 是一个"会思考、会规划、会调用工具"的开源智能体基座模型——它不只是一个聊天机器人，而是一个能够分解复杂任务、执行多步操作并自主调整策略的 AI Agent。**

## 核心功能

### 1. 长程任务规划与执行

Agents-A1 最核心的能力是其 **Agentic Reasoning（智能体推理）**。面对复杂任务时，它能够将问题拆解为可执行的子步骤，制定执行计划，并根据中间结果动态调整策略。例如，当你要求它"帮我调研某公司的技术栈并写一份对比分析报告"时，它会自动规划搜索、阅读、整理、写作等多个阶段，而不是简单地给出一个笼统回答。

这种能力来自于其独特的训练范式：团队构建了"领域锚定的知识-动作基础设施"，联合构造动作、观测和验证器输出，将 Agent 的执行过程转化为可训练目标。

### 2. 原生工具调用支持

Agents-A1 原生支持 **Function Calling** 和工具集成，能够无缝对接 API、代码解释器、搜索引擎等外部工具。在聊天模板中，它使用标准的 `<function_calls>` 格式进行工具调用，与 OpenAI 风格的 tool use 协议兼容。这意味着你可以直接将 Agents-A1 接入 LangChain、LlamaIndex、AutoGen 等主流 Agent 框架，无需额外的适配层。

### 3. 多模态理解能力

作为基于 Qwen3.5 MoE 架构的多模态模型（Image-Text-to-Text），Agents-A1 支持图像输入。结合其视觉理解能力和智能体规划能力，它可以处理需要"看图+思考+行动"的复杂场景，比如分析图表数据后自动编写代码进行数据处理。

### 4. 高精度指令遵循

在指令遵循方面，Agents-A1 在 **IFBench（80.6）** 和 **IFEval（94.8）** 两个权威基准测试中均取得优异成绩。这意味着当用户给出包含多个约束条件的复杂指令时，它能更准确地理解和执行，减少"偏题"或遗漏要求的情况。对于企业级应用来说，可靠的指令遵循是构建生产级 Agent 的基础。

## 适用人群

- **Agent 开发者**：需要构建自主任务执行系统的工程师，可以将 Agents-A1 作为 Agent 基座模型，配合工具调用实现自动化工作流。
- **AI 研究者**：对 MoE 架构、智能体训练范式、长程规划能力感兴趣的研究人员，Apache-2.0 协议允许自由使用和修改。
- **中小企业技术团队**：希望部署私有化 AI Agent 的团队，35B 参数（仅激活 3B）的 MoE 设计使得推理成本远低于同等性能的稠密大模型。
- **个人开发者**：7 月发布的 4B 版本让普通消费级显卡也能运行，适合构建本地 AI 助手原型。

## 与同类工具对比

### vs GPT-5.5 / DeepSeek-V4-Pro

Agents-A1 在多个基准上与 GPT-5.5（xhigh）和 DeepSeek-V4-Pro 等万亿参数级别的前沿模型竞争。特别是在 Seal-0（56.4 vs 42.34）、BrowseComp（75.5 vs 84.4）、MLE-Lite（43.94 vs 72.73）等任务上，表现已经非常接近甚至部分超越闭源旗舰模型。当然，在绝对性能上，GPT-5.5 仍在部分任务上领先。

### vs Qwen3.5-35B-A3B

Qwen3.5-35B-A3B 是 Agents-A1 的基础模型之一。Agents-A1 通过三阶段训练范式（全领域 SFT → 领域教师模型 → 多教师多域蒸馏）在 Agent 能力上实现了显著提升。在 Seal-0 上，Qwen3.5-35B-A3B 得分 41.4，而 Agents-A1 达到 56.4，提升超过 36%。

### vs Kimi-K2.6

Kimi-K2.6 在某些长程搜索任务上仍保持领先（如 XBench-DS-2510 得分 90.0 vs 86.0），但 Agents-A1 在 Seal-0、SciCode、MLE-Lite 等任务上反超。两者代表了不同的技术路线：Kimi 侧重规模缩放，Agents-A1 侧重异构智能体能力训练。

### vs 4B 小模型

InternScience 同时发布了 4B 版本的 Agents-A1，适合快速原型验证和本地部署。虽然性能无法与 35B 版相比，但在简单任务上已经具备基本的工具调用和指令遵循能力，是入门的好选择。

## 如何使用

### 方式一：Hugging Face Transformers 直接加载

```python
from transformers import AutoModelForCausalLM, AutoProcessor

model = AutoModelForCausalLM.from_pretrained(
    "InternScience/Agents-A1",
    torch_dtype="auto",
    device_map="auto"
)
processor = AutoProcessor.from_pretrained("InternScience/Agents-A1")
```

### 方式二：vLLM 部署（推荐用于生产环境）

```bash
pip install vllm
python -m vllm.entrypoints.openai.api_server \
    --model InternScience/Agents-A1 \
    --served-model-name agents-a1 \
    --tensor-parallel-size 4
```

部署后可通过 OpenAI 兼容 API 访问：

```python
from openai import OpenAI

client = OpenAI(base_url="http://localhost:8000/v1", api_key="not-needed")

response = client.chat.completions.create(
    model="agents-a1",
    messages=[
        {"role": "system", "content": "You are a helpful agent."},
        {"role": "user", "content": "搜索一下今天 AI 领域的最新新闻"}
    ],
    tools=[{"type": "function", "function": {...}}]
)
```

### 方式三：Mac 本地运行（MLX 量化版）

MLX Community 提供了多种量化版本，可以在 Mac 上直接运行：

```bash
# 安装 mlx 相关依赖后
python -c "from mlx_lm import load, generate; model, tokenizer = load('mlx-community/Agents-A1-4bit'); print(generate(model, tokenizer, prompt='你好', max_tokens=500))"
```

### 方式四：使用 4B 轻量版

如果硬件有限，可以尝试 4B 版本：

```python
model = AutoModelForCausalLM.from_pretrained(
    "InternScience/Agents-A1-4B",
    torch_dtype="auto",
    device_map="auto"
)
```

## 总结

**Agents-A1 是目前开源社区中最值得关注的智能体专用模型之一。** 它用 35B MoE 的参数量，在多个 Agent 基准上达到了与万亿参数闭源模型竞争的水平。其三大优势在于：

1. **真正的智能体能力**：不是简单地在对话中"假装"使用工具，而是经过专门的三阶段训练，具备真实的任务规划和执行能力。
2. **高效的 MoE 架构**：35B 总参数中仅激活约 3B，推理效率远高于同等性能的稠密模型。
3. **开放的生态**：Apache-2.0 协议 + 兼容 Transformers/vLLM/SGLang/MLX，从研究到生产都能快速落地。

如果你正在寻找一个开源的 Agent 基座模型，Agents-A1 绝对值得加入你的评估清单。特别是对于需要私有化部署、成本控制和对 Agent 能力有较高要求的场景，它是一个性价比极高的选择。

**推荐指数：⭐⭐⭐⭐½（4.5/5）**

唯一的小遗憾是，部分基准测试中仍与 GPT-5.5 等顶级模型存在一定差距，且在中文长程任务上的表现还需要更多社区验证。但随着 4B 版本的发布和量化优化的推进，Agents-A1 的可用性和普及度正在快速提升。
