## 一句话总结

**DeerFlow** 是由字节跳动开源的 SuperAgent 编排框架，通过子 Agent 并行协作、长期记忆、沙箱执行和环境技能系统，实现从深度研究到代码生成的全链路自动化。GitHub 72,774 颗星，MIT 开源协议。

## 它是什么？

DeerFlow（Deep Exploration and Efficient Research Flow）是字节跳动推出的开源 AI Agent 编排框架，2026 年 2 月发布的 2.0 版本为完全重写，与 1.x 版本共享零代码。它在 GitHub Trending 上曾连续多日登顶，并于 2026 年 2 月 28 日首次登上 GitHub Trending 第一名。

DeerFlow 的核心设计理念是"一个框架，多种能力"——它不再局限于单一任务，而是作为一个超 Agent 枢纽（SuperAgent Harness），协调多个子 Agent、管理记忆、调用工具和沙箱环境，完成从几分钟到几小时不等的复杂任务。

截至评测时，DeerFlow 在 GitHub 上已获得 **72,774 颗星**、**9,851 个 Fork**，支持 Python 3.12+ 和 Node.js 22+，采用 MIT 开源协议。

## 核心功能

### 1. 子 Agent 并行编排

DeerFlow 最核心的能力在于其多 Agent 协作机制。主 Agent（Lead Agent）可以将复杂任务自动分解，动态生成多个子 Agent，每个子 Agent 拥有独立的上下文、工具集和终止条件。子 Agent 在可能的情况下并行执行，完成后向主 Agent 汇报结构化结果，主 Agent 再综合所有子 Agent 的输出生成最终报告。

这意味着你可以让 DeerFlow 做一个深度研究报告——它会派出十几个子 Agent 分别从不同角度收集资料、分析数据，最后汇总成一份完整的报告、网站或演示文稿。

### 2. 长期记忆系统

大多数 AI Agent 在会话结束后就会忘记一切，但 DeerFlow 不会。它内置了跨会话的持久化记忆系统，能够记录你的个人画像、偏好设置和积累的知识。你使用得越多，DeerFlow 就越了解你——包括你的写作风格、技术栈和常用工作流。记忆数据存储在本地，完全由用户控制。

记忆更新还会自动去重，避免重复偏好和上下文在多次会话中不断累积。

### 3. 沙箱执行环境

DeerFlow 不只是"说话"的工具——它拥有自己的"电脑"。每个任务都会获得一个独立的执行环境，包含完整的文件系统视图。Agent 可以读写文件、查看图片，在配置安全的情况下还能执行 Shell 命令。

支持三种沙箱模式：
- **本地执行**：直接在宿主机上运行
- **Docker 容器隔离**：在独立容器中执行
- **Kubernetes 集群**：大规模生产部署

这是聊天机器人式工具与真正可执行 Agent 之间的关键区别。

### 4. Skills（技能系统）

Skills 是 DeerFlow 能够实现"几乎任何事情"的关键。每个 Skill 是一个结构化的能力模块，包含 Markdown 定义的工作流、最佳实践和资源引用。DeerFlow 内置了研究、报告生成、幻灯片制作、网页创建、图像和视频生成等多种技能。

Skills 采用渐进加载策略——只在任务需要时才加载，不会一次性占用上下文窗口。用户还可以通过 `/skill-name` 命令显式激活某个技能。此外，DeerFlow 还支持通过 `.skill` 归档文件安装自定义技能。

### 5. 多渠道 IM 接入

DeerFlow 支持通过多种即时通讯渠道接收任务，无需公网 IP。已集成的渠道包括：

| 渠道 | 连接方式 | 难度 |
|------|----------|------|
| Telegram | Bot API（长轮询） | 简单 |
| Slack | Socket Mode | 中等 |
| 飞书 / Lark | WebSocket | 中等 |
| 企业微信 | WebSocket | 中等 |
| 钉钉 | Stream Push（WebSocket） | 中等 |
| 微信 | Tencent iLink（长轮询） | 中等 |

接入后可以直接在聊天中发送任务，DeerFlow 会自动创建线程并回复。

### 6. 模型无关设计

DeerFlow 支持任何实现 OpenAI 兼容 API 的大语言模型。官方推荐使用支持长上下文窗口（100K+ tokens）、推理能力、多模态输入和强大工具调用的模型。推荐的模型包括 Doubao-Seed-2.0-Code、DeepSeek v3.2 和 Kimi 2.5，同时也支持 GPT-4o、GPT-5、Gemini 2.5 Flash 等主流模型，以及通过 OpenRouter 等平台接入的各种模型。

## 如何使用

### 方式一：Docker 一键部署（推荐）

```bash
# 1. 克隆仓库
git clone https://github.com/bytedance/deer-flow.git
cd deer-flow

# 2. 运行设置向导（选择 LLM 提供商、Web 搜索等）
make setup

# 3. 验证配置
make doctor

# 4. 启动 Docker
make up
```

启动后访问 `http://localhost:2026` 即可使用 Web 界面。

### 方式二：本地开发

```bash
# 1. 检查前置依赖
make check  # 需要 Node.js 22+, pnpm, uv, nginx

# 2. 安装依赖
make install

# 3. （可选）预拉取沙箱镜像
make setup-sandbox

# 4. 启动开发服务
make dev
```

### 方式三：Python 嵌入式客户端

```python
from deerflow.client import DeerFlowClient

client = DeerFlowClient()

# 直接对话
response = client.chat("帮我分析这份财报", thread_id="my-thread")

# 流式响应
for event in client.stream("hello"):
    if event.type == "messages-tuple" and event.data.get("type") == "ai":
        print(event.data["content"])

# 查看可用模型和技能
models = client.list_models()
skills = client.list_skills()
```

### 快速上手示例

1. 通过 `make setup` 向导配置 LLM 提供商（如 OpenAI、Anthropic 或 OpenRouter）
2. 设置 API Key（写入 `.env` 文件）
3. 在 Web 界面或 IM 渠道中发送任务，例如："帮我调研 2026 年 AI Agent 框架的发展趋势"
4. DeerFlow 会自动分解任务、调度子 Agent、收集信息并生成报告

## 总结

DeerFlow 2.0 是目前开源社区中最成熟的 SuperAgent 编排框架之一。它的子 Agent 并行协作机制、长期记忆系统、沙箱执行环境和 Skills 插件架构，使其能够胜任从简单问答到复杂深度研究的各类任务。

**推荐指数：★★★★☆**

- **优点**：功能全面、社区活跃、模型无关、支持多种部署方式、有完善的 Web UI 和 Python 客户端
- **不足**：部署配置相对复杂（需要 Node.js、Docker 等依赖），对低配服务器不太友好
- **适合**：需要端到端自动化研究和分析能力的团队和个人开发者

对于已经使用过 AutoGen 或 CrewAI 的用户来说，DeerFlow 提供的记忆系统和沙箱执行能力会带来明显的体验提升。如果你正在寻找一个能够真正"干活"的 AI Agent 框架，DeerFlow 值得尝试。
