# Herdr: 终端多智能体管理器，让所有 AI 编程助手在同一窗口协同作战

> 一句话简介：Herdr 是一个用 Rust 编写的终端多智能体管理器，能在同一个终端窗口中同时运行、监控和管理多个 AI 编程助手（如 Claude Code、OpenAI Codex、Cursor 等），实时显示各智能体的工作状态，GitHub 星标已超 12,000。

随着 AI 编程助手的爆发式增长，开发者手中可能同时运行着 Claude Code、OpenAI Codex、Cursor Agent、Kiro 等多个工具。每个工具各自占据一个终端窗口，切换繁琐，状态不明。**Herdr** 应运而生——它自称是"为智能体重新构建的 tmux"，让所有 AI 编程助手在你的终端中协同工作。

Herdr 由 Ogul Cancelik 开发，2026 年 6 月底首次登上 GitHub Trending 榜首，目前已有 **12,258+ Star**，支持 Linux、macOS 和 Windows（预览版），采用 AGPL-3.0 许可证。

## 核心功能

### 1. 一个终端，管理所有智能体

Herdr 的核心设计理念是让所有 AI 编程助手共享同一个终端界面。你可以同时启动多个 Agent，每个 Agent 拥有自己的真实终端会话。这意味着即使是全屏 TUI（终端用户界面）应用也能正常渲染——不像某些 GUI 管理器那样只是"模拟"终端。

```bash
# 启动 Herdr
herdr

# 在 Herdr 中启动不同的 AI 编程助手
claude code
codex
cursor agent
```

### 2. 智能体状态实时可视化

Herdr 侧边栏会实时显示每个智能体的状态，用颜色编码一目了然：

- **🔴 红色 (Blocked)**：智能体等待用户输入或遇到阻塞
- **🟡 黄色 (Working)**：智能体正在积极工作
- **🔵 蓝色 (Done)**：智能体已完成当前任务
- **🟢 绿色 (Idle)**：智能体空闲中

无需任何配置或钩子脚本，Herdr 通过进程名称匹配和终端输出启发式分析自动检测状态。目前已原生支持 **pi、Claude Code、Codex、Droid、AMP、OpenCode、Grok CLI、Hermes Agent、Kilo Code、Devin CLI、Cursor Agent、Antigravity CLI、Kimi Code、GitHub Copilot CLI、QoderCli** 等 15+ 主流 AI 编程助手。

### 3. 工作区、标签页、分屏管理

Herdr 提供了完整的终端多路复用功能：

- **工作区（Workspaces）**：按项目或文件夹组织不同的工作空间
- **标签页（Tabs）**：在同一工作区内创建多个标签页
- **分屏（Panies）**：垂直或水平分割面板，同时查看多个智能体的输出
- **鼠标原生操作**：点击、拖拽面板和标签页，无需记忆快捷键

```bash
# 快捷键示例（前缀键 ctrl+b）
# ctrl+b + shift+n  → 新建工作区
# ctrl+b + v 或 -  → 垂直分屏
# ctrl+b + c  → 新建标签页
# ctrl+b + w  → 切换工作区
# ctrl+b + q  → 分离（智能体继续运行）
# ctrl+b + ?  → 查看所有快捷键
```

### 4. 持久化与远程连接

关闭笔记本不会杀死智能体——Herdr 在后台运行服务器，保持所有面板和智能体存活。你可以随时从另一个终端重新连接，甚至通过 SSH 从手机重新接入。还支持远程模式：

```bash
# 将本地终端作为远程服务器的客户端
herdr --remote workbox
herdr --remote ssh://you@yourserver:2222
```

这对于在云服务器上运行智能体、本地终端作为客户端的场景非常有用。

### 5. 可脚本化的 Socket API

Herdr 提供本地 Unix Socket API 和 CLI，允许智能体本身操控 Herdr——创建工作区、分割面板、派生辅助智能体、订阅状态变更等。甚至可以编写自定义插件：

```bash
# 为智能体安装 Herdr 技能
npx skills add ogulcancelik/herdr --skill herdr -g
```

这意味着你的 AI 编程助手可以主动利用 Herdr 的多智能体编排能力，实现真正的 Agent-to-Agent 协作。

## 适用人群

- **多智能体开发者**：同时使用多个 AI 编程助手（如 Claude Code + Codex + Cursor），需要一个统一的终端界面管理它们
- **远程工作者**：需要在服务器上运行智能体，本地终端通过 SSH 连接的开发者
- **终端爱好者**：习惯使用 tmux/screen 等终端复用器，但需要更好的 AI 智能体感知能力
- **团队协作场景**：多人共享一台服务器，各自运行不同智能体进行开发

**tmux** 是终端复用的经典选择，但它诞生于 AI 智能体时代之前，对智能体的状态一无所知。虽然可以通过铃声字符和自定义钩子来"近似"实现状态感知，但需要自己编写大量配置。

**GUI 管理器**（如 Conductor、Emdash）提供了智能体状态展示，但它们通常是独立应用（很多仅限 macOS），在终端内部重绘界面，无法真正显示服务器上的全屏 TUI 应用。

**Herdr 的独特之处**在于它是一个单一的二进制文件（约 10MB），运行在你已经使用的终端中，支持 SSH 远程连接，显示每个智能体的真实屏幕，并且智能体本身可以通过 Socket API 主动编排 Herdr。

## 如何使用

### 安装

```bash
# Linux / macOS
curl -fsSL https://herdr.dev/install.sh | sh

# 或通过 Homebrew
brew install herdr

# 或通过 Nix
nix run github:ogulcancelik/herdr

# Windows（预览版）
powershell -ExecutionPolicy Bypass -c "irm https://herdr.dev/install.ps1 | iex"
```

### 快速上手

```bash
# 1. 启动 Herdr
herdr

# 2. 在面板中运行任意 AI 编程助手
# 例如在一个面板中运行 Claude Code：
claude code

# 3. 分割面板，在另一个面板中运行 Codex
# ctrl+b + v （垂直分割）
codex

# 4. 再分割一个面板，运行 Kilo Code
# ctrl+b + c （新建标签页）
kilo code

# 5. 观察侧边栏的状态变化
# 🔴 阻塞 / 🟡 工作中 / 🔵 完成 / 🟢 空闲
```

### 安装官方集成

Herdr 提供官方集成，支持会话恢复和语义状态报告：

```bash
# 为特定智能体安装集成
herdr integration install claude
herdr integration install codex
herdr integration install copilot
herdr integration install devin
herdr integration install cursor
herdr integration install opencode
herdr integration install pi
herdr integration install amp
herdr integration install droid
herdr integration install kimi
herdr integration install hermes
herdr integration install kilo
herdr integration install qodercli
```

### 远程模式

```bash
# 在服务器上运行 Herdr 服务端
herdr --remote myserver

# 从本地终端连接到远程服务器
herdr --remote ssh://user@server:22
```

## 总结

Herdr 填补了 AI 编程助手时代的终端管理空白。它不是一个简单的终端复用器，而是一个专门为多智能体场景设计的协调工具。其核心优势在于：

1. **真正的智能体感知**——无需配置即可自动检测 15+ 主流 AI 编程助手的状态
2. **轻量高效**——单一 Rust 二进制，无 Electron、无 GUI 封装、无遥测、无需账户
3. **远程友好**——SSH 无缝连接，服务器上的智能体状态随时可查看
4. **智能体可编程**——Socket API 允许智能体主动编排工作流，实现 Agent-to-Agent 协作

如果你同时使用多个 AI 编程助手，或者需要在远程服务器上管理智能体工作流，Herdr 是目前最好的终端多智能体管理解决方案。

**推荐指数：★★★★☆**（4/5）

扣掉的一星是因为 Windows 版本仍处于预览阶段，部分非主流智能体的状态检测仍需手动配置。但随着官方集成的持续扩展和社区贡献，这些问题有望很快解决。
