## 一句话介绍

**MinerU** 是 OpenDataLab（上海人工智能实验室旗下开源组织）开发的开源文档解析工具，能将 PDF、Word、PPT 等复杂文档一键转换为结构化的 Markdown 或 JSON 格式，完美保留表格、数学公式、图片和排版信息。GitHub 7 万+星，是 RAG 数据管道和 Agentic 工作流的明星组件。

---

## 核心功能

### 1. 高精度文档解析

MinerU 内置了先进的版面分析模型（LaTeX-OCR + Layout Parser），能够精准识别文档中的文本块、标题层级、段落、列表、表格和图片区域。对于扫描版 PDF，内置 OCR 引擎可将图像文字转为可编辑文本，识别精度在常见语言上可达 95% 以上。

### 2. 表格智能还原

传统 PDF 解析最大的痛点就是表格——很多工具会把表格拆成散乱的文本。MinerU 采用专门的表格检测与重建算法，能够将复杂表格（含合并单元格、多级表头）完整还原为 Markdown 表格格式，甚至可导出为 CSV/Excel。

### 3. 数学公式与特殊符号支持

MinerU 内置 LaTeX-OCR 能力，可自动检测文档中的数学公式并将其转换为 LaTeX 格式。这对学术论文、技术文档的处理至关重要——LLM 需要结构化的公式输入才能正确理解和推理。

### 4. 多格式输入

除了最常见的 PDF，MinerU 还支持：
- Microsoft Word（.docx）
- PowerPoint（.pptx）
- 图片（.png, .jpg, .bmp）
- 纯文本（.txt）
- HTML 页面

### 5. LLM 友好的输出格式

MinerU 的输出经过专门优化，可直接用于 RAG（检索增强生成）管道或作为 Agentic 工作流的输入。支持 Markdown 和 JSON 两种格式，Markdown 适合人类阅读，JSON 则便于程序化处理。

## 如何使用

### 方法一：pip 安装（推荐）

```bash
# 安装 MinerU
pip install mineru

# 基本用法：将 PDF 转为 Markdown
magic-pdf /path/to/input.pdf /path/to/output_dir
```

### 方法二：Docker 部署

```bash
# 拉取镜像
docker pull opendatalab/mineru:latest

# 运行解析
docker run -v /local/path:/data opendatalab/mineru:latest \
  magic-pdf /data/input.pdf /data/output
```

### 方法三：在线 Demo（免安装）

访问 HuggingFace Space：https://huggingface.co/spaces/opendatalab/MinerU

直接上传 PDF 文件，即可在线预览解析结果，无需任何配置。

### 方法四：Python API 集成

```python
from magic_pdf.pipe.uci_pipe import UCIPipe

# 初始化解析管道
pipe = UCIPipe()

# 解析 PDF 文件
result = pipe.pipe_single_pdf(
    "input.pdf",
    "output_dir"
)

# 获取 Markdown 内容
md_content = result.get_md()
print(md_content)
```

### 进阶配置

```bash
# 指定输出格式为 JSON
magic-pdf --format json /path/to/input.pdf /path/to/output_dir

# 使用特定模型（如仅 OCR 模式）
magic-pdf --model ocr_only /path/to/input.pdf /path/to/output_dir

# 并行处理多个文件
magic-pdf --parallel 4 /path/to/input_dir/ /path/to/output_dir/
```
