## 工具简介

**Kronos** 是由 NeoQuasar（shiyu-coder）开发的**全球首个面向金融 K 线（蜡烛图）的开源基础模型**。该项目目前在 GitHub Trending 榜单上持续走红，已获得 **32,700+ Stars**、5,600+ Forks，采用 MIT 开源许可证。其论文已被 AAAI 2026 接收，模型托管在 Hugging Face Hub 上。

简单来说，Kronos 把金融市场的 K 线数据当作一种"语言"来学习——就像大语言模型学习文本一样，Kronos 学习的是价格走势的"语法"和"语义"，从而能够进行价格预测、趋势分类、波动率估计等多种量化任务。

## 核心功能

### 1. K 线序列预测
Kronos 的核心能力是基于历史 K 线数据预测未来价格走势。它使用一个专门设计的 tokenizer 将连续的 OHLCV（开盘价、最高价、最低价、收盘价、成交量）数据量化为分层离散 token，然后用自回归 Transformer 模型进行预测。支持分钟级、小时级、日级等多种时间粒度。

### 2. 多任务量化分析
除了价格预测，Kronos 还能处理多种量化任务：
- **趋势分类**：判断未来一段时间内价格是上涨还是下跌
- **波动率估计**：预测未来价格波动的幅度
- **支撑/阻力位识别**：自动识别关键的价格水平

### 3. 多模型家族
Kronos 提供不同规模的模型选择，适配不同的计算需求：

| 模型 | 参数量 | 上下文长度 | 开源 |
|------|--------|-----------|------|
| Kronos-mini | 410万 | 2048 | ✅ |
| Kronos-small | 2470万 | 512 | ✅ |
| Kronos-base | 1.02亿 | 512 | ✅ |
| Kronos-large | 4.99亿 | 512 | ❌ |

对于个人开发者和研究者，Kronos-mini 和 Kronos-small 已经足够好用，可以在消费级 GPU 甚至 CPU 上运行。

### 4. 覆盖 45+ 全球交易所
Kronos 在超过 45 个全球交易所的历史数据上进行预训练，涵盖加密货币、股票、期货等多种资产类别。这种大规模跨市场训练使得模型具有很强的泛化能力，即使在未见过的交易对上也能表现良好。

### 5. 微调支持
2025年8月，团队发布了微调脚本，用户可以使用自己的数据对 Kronos 进行微调，适配特定的交易策略或市场场景。

## 如何使用

### 第一步：安装依赖

```bash
git clone https://github.com/shiyu-coder/Kronos.git
cd Kronos
pip install -r requirements.txt
```

### 第二步：加载模型

```python
from model import Kronos, KronosTokenizer, KronosPredictor

# 从 Hugging Face Hub 加载 tokenizer 和模型
tokenizer = KronosTokenizer.from_pretrained("NeoQuasar/Kronos-Tokenizer-base")
model = Kronos.from_pretrained("NeoQuasar/Kronos-small")

# 初始化预测器
predictor = KronosPredictor(model, tokenizer, max_context=512)
```

### 第三步：准备数据并预测

```python
import pandas as pd

# 加载历史 K 线数据（必须包含 open, high, low, close 列）
df = pd.read_csv('btc_usdt.csv')

# 进行未来 24 小时的预测

    df=df,
    x_timestamp=df['timestamp'],

    pred_len=24

```

### 第四步：可视化结果

Kronos 还提供了在线 Demo（https://shiyu-coder.github.io/Kronos-demo/），可以直观地查看 BTC/USDT 未来 24 小时的预测走势。你也可以使用 matplotlib 自行绘制预测曲线与实际价格的对比图。

### 进阶：微调自己的模型

如果你有自己的特定市场数据，可以使用团队发布的微调脚本来适配：


## 总结

Kronos 是金融 AI 领域的一个突破性项目。它将大语言模型的思想成功迁移到了金融市场分析中，开创了"用 AI 解读市场语言"的新范式。

**优点：**
- 首个开源的 K 线基础模型，填补了市场空白
- 多模型家族适配不同需求，Mini 版本可在笔记本上运行
- 45+ 交易所数据预训练，泛化能力强
- 已被 AAAI 2026 接收，学术认可度高
- MIT 许可证，可自由商用
- 文档完善，API 简洁易用

**需要注意：**
- 金融预测存在固有风险，AI 模型不能保证盈利
- 大模型（Large）需要较多 GPU 资源
- 目前主要支持 Python，其他语言需要封装

**推荐指数：★★★★★（5/5）**

如果你关注量化投资或 AI 金融应用，Kronos 绝对值得尝试。它的开源性质和低门槛设计让任何人都能快速上手，无论是学术研究还是实盘辅助，都是目前最好的选择之一。
