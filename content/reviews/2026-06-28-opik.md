## 一句话介绍

**Comet Opik** 是由 Comet 公司开源的 LLM 应用可观测性平台，为生成式 AI 应用提供从原型到生产的全生命周期管理——包括深度追踪（Tracing）、自动化评估（Evaluation）、提示词优化（Prompt Optimization）和生产监控（Production Monitoring）。GitHub 近 2 万星，Apache 2.0 许可，是目前最全面的开源 LLM-Ops 工具之一。

---

## 核心功能

### 1. 全链路追踪与调试

Opik 的核心能力是对 LLM 调用进行细粒度追踪。无论是简单的 ChatGPT API 调用，还是复杂的 Agent 多步推理链，Opik 都能自动记录每一次模型交互的输入、输出、Token 消耗、延迟时间和元数据。它支持 Span 级别的嵌套追踪——这意味着你可以清晰地看到每个 Agent 子任务的执行路径，快速定位性能瓶颈和错误根源。

Opik 原生集成了 LangChain、LlamaIndex、OpenAI、Google ADK、AutoGen 和 Flowise AI 等主流框架，接入成本极低。只需安装 Python SDK 并设置环境变量，即可自动捕获所有 LLM 调用。

### 2. 自动化评估与实验管理

Opik 提供了强大的评估体系。开发者可以创建数据集（Datasets），定义评估指标，然后通过实验（Experiments）对不同版本的 Prompt、模型或 RAG 配置进行 A/B 测试。内置的评估指标包括：

- **幻觉检测（Hallucination Detection）**——判断模型输出是否与参考上下文一致
- **回答相关性（Answer Relevance）**——评估生成内容与查询意图的匹配度
- **上下文精度（Context Precision）**——衡量检索内容对最终回答的贡献
- **审核指标（Moderation）**——检测不安全或不当内容

更高级的是其 **LLM-as-a-Judge** 能力——让另一个 LLM 作为裁判来评估生成质量，适用于那些无法用简单规则衡量的主观指标。

### 3. 提示词游乐场（Prompt Playground）

Opik 内置了一个交互式提示词游乐场，开发者可以在 UI 中直接测试不同的 Prompt 模板和模型组合，实时对比输出效果。这个功能类似于一个可视化的 Prompt 沙盒，支持保存和版本管理你的最佳 Prompt 配置。

### 4. 生产监控与在线评估规则

对于已上线的 AI 应用，Opik 的设计目标是支撑大规模生产环境——官方宣称可处理每日 4000 万+条 Trace。它提供实时监控仪表盘，展示反馈评分、Trace 数量、Token 用量等关键指标。

更实用的是 **在线评估规则（Online Evaluation Rules）**——你可以在生产环境中配置自动触发的评估规则，例如当某个请求的幻觉分数超过阈值时自动告警。结合 LLM-as-a-Judge 指标，这构成了一个闭环的生产质量保障体系。

### 5. Agent 优化器与安全护栏

Opik 还提供了两个特色功能：**Agent Optimizer** 可以自动优化 Agent 的 Prompt 和工具选择策略，而 **Guardrails** 则帮助你在 AI 应用中实施安全合规措施，防止不当输出。这些功能使 Opik 不仅仅是一个监控工具，更是一个完整的 AI 应用优化平台。

|------|------|-----------|-------------------|---------------|
| **开源程度** | 完全开源（Apache 2.0） | 闭源 | 部分开源 | 部分开源 |
| **自托管** | ✅ Docker/K8s 一键部署 | ❌ 仅云端 | ⚠️ 有限支持 | ✅ 可自托管 |
| **价格** | 免费（自托管）/ 免费额度（云端） | 按用量计费 | 按存储和计算计费 | 免费 |
| **框架支持** | LangChain/LlamaIndex/OpenAI/ADK/AutoGen | LangChain/LlamaIndex | 广泛 | LangChain/LlamaIndex |
| **评估指标** | 丰富（含幻觉检测等） | 丰富 | 基础 | 中等 |

## 如何使用

### 方式一：使用 Comet 云端（最简单）

```bash
# 安装 SDK
pip install opik

# 设置 API 密钥（在 comet.com 注册后获取）
export COMET_API_KEY=your-api-key
export COMET_PROJECT_NAME=your-project

# 在代码中使用
import opik
client = opik.Opik()
trace = client.trace("my-first-trace")
```

访问 [comet.com](https://www.comet.com) 注册免费账号即可获得云端 Opik 实例，无需任何服务器部署。

### 方式二：Docker 自托管（推荐企业用户）

```bash
# 克隆仓库
git clone https://github.com/comet-ml/opik.git
cd opik

# 一键启动（包含基础设施 + 后端 + UI）
./opik.sh

# 或者只启动基础设施用于开发
./opik.sh --infra

# 启动后访问 localhost:5173
```

自托管版本支持 Docker Compose 和 Kubernetes 两种部署方式，适合对数据隐私有严格要求的团队。

### 方式三：Kubernetes 部署

对于大规模生产环境，Opik 提供 Helm Chart，可以直接部署到 Kubernetes 集群：

```bash
helm repo add opik https://comet-ml.github.io/opik-helm-chart
helm install opik opik/opik
```

### 接入已有项目

以 LangChain 为例，只需添加几行代码：

```python
from opik.integrations.langchain import LangChainTracer

tracer = LangChainTracer()
chain = your_chain.with_config({"callbacks": [tracer]})
result = chain.invoke("你的问题")
```

所有 LangChain 的运行轨迹会自动发送到 Opik，你可以在 Web UI 中查看完整的执行链路。
