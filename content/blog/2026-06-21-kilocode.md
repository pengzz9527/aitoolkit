## 一句话介绍

**Kilo Code** 是一款开源 AI 编程智能体平台，支持在 VS Code、JetBrains IDE 和命令行终端中运行，提供 500+ 大模型选择、多智能体协作和完全自主的 CI/CD 模式，在 GitHub 上已获得超过 23,000 个星标。

---

## 核心功能

### 1. 全平台覆盖，随处可用

Kilo Code 的最大亮点之一是它的跨平台能力。无论你使用 VS Code、JetBrains 系列 IDE（IntelliJ、PyCharm、WebStorm 等），还是纯命令行环境，都能无缝接入。此外还提供云端智能体（Cloud Agent）和 KiloClaw（常驻 AI 助手）服务，无需本地机器即可运行。

### 2. 500+ 模型自由选择

Kilo Code 不绑定任何单一模型供应商。用户可以从 500+ 模型中选择，包括 GPT-5.5、Claude Opus 4.7、Claude Sonnet 4.6、Gemini 3.1 Pro Preview 等主流模型。更独特的是，它支持**任务中途切换模型**——比如在编写代码时用小而快的模型，在架构设计时切换到推理能力更强的模型，实现性能与成本的平衡。

### 3. 多智能体协作

Kilo Code 内置了五种专用智能体，可根据不同任务类型切换：

- **Code 智能体**：默认模式，根据自然语言描述实现和编辑代码
- **Plan 智能体**：先设计架构和实施方案，再开始编码
- **Ask 智能体**：仅回答问题，不修改任何文件
- **Debug 智能体**：排查和追踪代码问题
- **Review 智能体**：审查代码变更，检测性能、安全、风格和测试覆盖等问题

用户还可以创建自定义智能体，满足特定工作流需求。

### 4. 自主模式（Autonomous Mode）

通过 `kilo run --auto` 命令，Kilo Code 可以在 CI/CD 流水线中完全自主运行，无需任何人工确认。它会自行执行测试、调试和修复，非常适合自动化开发流程。

### 5. MCP 市场扩展

Kilo Code 集成了 MCP（Model Context Protocol）市场，用户可以发现和连接各种 MCP 服务器来扩展智能体的能力，比如接入数据库、文档检索、外部 API 等。

## 如何使用

### 安装步骤

#### VS Code 安装

1. 打开 VS Code 扩展市场
2. 搜索「Kilo Code」或直接访问 [VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=kilocode.Kilo-Code)
3. 点击安装
4. 创建 Kilo 账号后即可使用 500+ 模型

#### CLI 安装（推荐开发者）

```bash
# 使用 npm 安装
npm install -g @kilocode/cli

# 或使用 Homebrew（macOS/Linux）
brew install Kilo-Org/tap/kilo

# 或使用一键安装脚本
curl -fsSL https://kilo.ai/cli/install | bash
```

安装完成后，进入任意项目目录运行 `kilo` 即可启动。

#### JetBrains 安装

1. 打开 IntelliJ IDEA / PyCharm / WebStorm 等 JetBrains IDE
2. 进入 Settings → Plugins
3. 搜索「Kilo Code」并安装
4. 或者从 [JetBrains Marketplace](https://plugins.jetbrains.com/plugin/28350-kilo-code) 直接安装

### 基本使用流程

1. **选择智能体**：在编辑器顶部栏切换 Code / Plan / Ask / Debug / Review 模式
2. **选择模型**：从下拉列表中选择所需的 AI 模型（支持中途切换）
3. **描述任务**：用自然语言描述你想让 AI 完成的工作
4. **审查输出**：查看生成的代码，确认后接受或要求修改

### 自主模式示例

在 CI/CD 流水线中使用：

```bash
kilo run --auto "运行测试套件并修复所有失败的测试"
```

这会完全自动地执行测试、定位问题并修复代码，无需人工干预。
