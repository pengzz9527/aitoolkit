## 工具简介

**Kimi CLI** 是由中国 AI 公司 Moonshot AI（月之暗面）开发的终端 AI 编程智能体，目前已在 GitHub 上斩获 **9,571+ ⭐**（约 1,168 Forks），稳居 GitHub Trending 榜单前列。它基于 Python 开发，采用 Apache-2.0 许可证，核心定位是：**在终端中通过自然语言完成软件开发任务，包括代码读写、Shell 命令执行、网页搜索与内容获取，并能自主规划和调整执行策略。**

一句话总结：**Kimi CLI 是一个运行在终端里的 AI 编程助手——你只需告诉它需求，它就能自主编写代码、执行命令、搜索信息并完成任务，全程无需离开命令行界面。**

值得注意的是，Kimi CLI 正在逐步演进为 **Kimi Code CLI**（https://github.com/MoonshotAI/kimi-code），由同一团队打造的下一代终端 AI 代理。安装 Kimi Code CLI 会自动迁移配置与会话数据，现有文档和已安装版本仍可正常使用。

## 核心功能

### 1. Shell 命令模式

Kimi CLI 不仅是一个编码智能体，还内置了 Shell 命令模式。通过按下 `Ctrl-X` 即可切换至 Shell 模式，直接在 Kimi CLI 内部执行 Shell 命令而无需退出程序。这种设计让用户可以在同一个界面中交替使用 AI 辅助编码和原生 Shell 操作，大幅提升工作效率。

```bash
# 启动 Kimi CLI
kimi

# 按 Ctrl-X 切换到 Shell 模式
# 执行完命令后再按 Ctrl-X 返回 AI 模式
```

### 2. VS Code 扩展集成

Kimi CLI 提供了官方的 VS Code 扩展（Kimi Code VS Code Extension），可以无缝嵌入到 VS Code 的开发环境中。用户可以在编辑器侧边栏直接与 Kimi 对话，让 AI 理解项目上下文、修改代码、调试问题，体验与 Cursor 或 Copilot 类似的 IDE 级集成。

### 3. ACP 协议兼容（Agent Client Protocol）

Kimi CLI 原生支持 Agent Client Protocol（ACP），这是一种开放的 AI 代理通信协议。通过运行 `kimi acp` 命令，可以将 Kimi CLI 作为 ACP 代理服务器启动，从而与任何支持 ACP 的编辑器或 IDE 集成，包括：

- **Zed**：在 `~/.config/zed/settings.json` 中配置 ACP 代理
- **JetBrains IDE**：通过 `~/.jetbrains/acp.json` 接入
- 其他任何 ACP 兼容客户端

这使得 Kimi CLI 不仅仅是一个独立的 CLI 工具，更可以作为通用 AI 后端嵌入到多种开发环境中。

### 4. MCP 工具链支持

Kimi CLI 内置了对 Model Context Protocol（MCP）的全面支持，允许连接各种外部 MCP 服务器来扩展其能力：

```bash
# 添加 HTTP 传输的 MCP 服务器
kimi mcp add --transport http context7 https://mcp.context7.com/mcp \
  --header "CONTEXT7_API_KEY: ctx7sk-your-key"

# 添加 OAuth 认证的 MCP 服务器
kimi mcp add --transport http --auth oauth linear https://mcp.linear.app/mcp

# 添加 stdio 模式的 MCP 服务器
kimi mcp add --transport stdio chrome-devtools -- npx chrome-devtools-mcp@latest

# 列出所有已添加的 MCP 服务器
kimi mcp list

# 移除某个 MCP 服务器
kimi mcp remove chrome-devtools
```

此外还支持通过 `--mcp-config-file` 选项一次性加载完整的 MCP 配置文件，方便企业级部署和管理。

### 5. Zsh 插件集成

对于使用 Oh My Zsh 的用户，Kimi CLI 提供了专门的 zsh-kimi-cli 插件。安装后在 `~/.zshrc` 中添加插件列表，重启 Zsh 即可通过 `Ctrl-X` 快捷键随时唤出 AI 代理模式，将 AI 能力深度融入日常 Shell 工作流。

```bash
# 安装 Zsh 插件
git clone https://github.com/MoonshotAI/zsh-kimi-cli.git \
  ${ZSH_CUSTOM:-~/.oh-my-zsh/custom}/plugins/kimi-cli

# 在 ~/.zshrc 中添加
plugins=(... kimi-cli)
```

## 如何使用

### 安装步骤

**通过 pip 安装：**

```bash
pip install kimi-cli
```

**或者从源码构建：**

```bash
git clone https://github.com/MoonshotAI/kimi-cli.git
cd kimi-cli
make prepare   # 准备开发环境
uv run kimi    # 运行 Kimi CLI
```

### 基本操作流程

1. **启动会话**：

   ```bash
   kimi
   ```

2. **输入编程需求**（支持中英文）：

   ```
   > 帮我写一个 Python Flask 应用，实现用户注册和登录功能
   ```

3. **AI 自动执行**：Kimi CLI 会分析问题、生成代码、在终端中执行并展示结果。如果结果不理想，可以继续对话调整：

   ```
   > 把密码加密改成 bcrypt，并且加上邮箱验证
   ```

4. **切换 Shell 模式**：按下 `Ctrl-X` 可以直接执行 Shell 命令，完成后再次按下 `Ctrl-X` 返回 AI 模式。

5. **管理 MCP 工具**：

   ```bash
   kimi mcp add --transport stdio search -- npx @anthropic/mcp-server-search
   ```

### 作为 ACP 客户端使用

如果你使用的是支持 ACP 的编辑器（如 Zed），可以这样配置：

```json
{
  "agent_servers": {
    "Kimi CLI": {
      "type": "custom",
      "command": "kimi",
      "args": ["acp"],
      "env": {}
    }
  }
}
```

然后在编辑器中创建 Kimi CLI 线程即可直接使用。

### 登录认证

首次使用时需要运行 `/login` 完成登录认证，之后才能正常使用 Kimi 模型的 API 服务。

## 局限性

了解 Kimi CLI 的局限性同样重要：

- **模型依赖**：底层使用 Kimi 系列模型，模型能力和可用性与 Moonshot AI 的服务状态直接相关
- **社区规模**：相比 Open Interpreter 和 Claude Code，Kimi CLI 的社区资源和第三方扩展较少
- **文档语言**：虽然支持中文，但部分技术文档仍以英文为主
- **大型项目支持**：对于超大型多文件项目，上下文管理和代码理解能力仍有提升空间
- **正在演进中**：项目正逐步向 Kimi Code CLI 过渡，部分功能可能会调整或迁移
