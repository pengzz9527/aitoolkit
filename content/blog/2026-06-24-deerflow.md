## 一句话介绍

**DeerFlow 2.0**（Deep Exploration and Efficient Research Flow）是字节跳动开源的超级 Agent 编排框架，基于 LangGraph 和 LangChain 构建，通过子 Agent 并行执行、长期记忆、沙箱环境和可扩展技能系统，让 AI Agent 能够完成从深度研究到代码生成的复杂长周期任务。GitHub 星标 739+，2026 年 2 月 28 日曾登顶 GitHub Trending 第一名。

---

## 核心功能

### 1. 子 Agent 并行编排

DeerFlow 最核心的能力在于它能将复杂任务自动分解为多个子任务，每个子任务由独立的子 Agent 处理。主 Agent（Lead Agent）可以动态创建子 Agent，每个子 Agent 拥有自己的上下文、工具和终止条件。子 Agent 之间可以并行执行，完成后将结构化结果汇报给主 Agent，由主 Agent 综合输出最终结果。

这意味着你不再需要一个 Agent 慢慢思考——你可以让它派出十几个"分身"同时调研不同方向，最后汇总成一份完整的报告、网站或幻灯片。

### 2. 沙箱执行环境

DeerFlow 不只是"聊天机器人+工具调用"，它拥有真正的执行环境。每个任务都会获得一个隔离的沙箱，具备完整的文件系统视图。Agent 可以读写文件、查看图片、执行 Shell 命令（需配置）。它支持两种沙箱模式：

- **AioSandboxProvider**：在隔离容器中执行 Shell 命令，安全性更高
- **LocalSandboxProvider**：将文件操作映射到主机目录，适合可信的本地工作流

这种设计让 DeerFlow 能在真实环境中完成任务——写代码、处理文件、生成报告，而不是仅仅输出文本。

### 3. 长期记忆系统

大多数 AI Agent 在会话结束后就忘记了一切。DeerFlow 打破了这一限制——它在会话之间构建持久化的用户画像、偏好和知识积累。随着使用时间的增加，DeerFlow 会越来越了解你的写作风格、技术栈和常用工作流。所有记忆数据存储在本地，完全由用户控制。

### 4. 渐进式技能系统

DeerFlow 的技能（Skills）是其"几乎什么都能做"的关键。每个技能是一个结构化的 Markdown 文件，定义了工作流、最佳实践和参考资源。内置技能涵盖研究、报告生成、幻灯片制作、网页开发、图像和视频生成等。

技能的加载采用渐进式策略——只在需要时才加载对应技能，保持上下文窗口精简。用户可以通过斜杠命令（如 `/research 调研某主题`）显式激活特定技能。用户还可以自定义技能、替换内置技能或将多个技能组合成复合工作流。

### 5. 上下文工程优化

面对长周期任务，DeerFlow 通过多种手段管理上下文：

- **子 Agent 上下文隔离**：每个子 Agent 只能看到自己的上下文，不会被主 Agent 或其他子 Agent 的信息干扰
- **自动摘要**：在会话过程中对已完成子任务进行摘要，将中间结果卸载到文件系统
- **严格工具调用恢复**：当 Provider 或中间件中断工具调用循环时，自动清理元数据并注入占位符结果，避免推理模型因格式错误而失败

## 与同类工具对比

| 维度 | DeerFlow 2.0 | AutoGen (Microsoft) | CrewAI | LangGraph |
|------|-------------|---------------------|--------|-----------|
| 定位 | 超级 Agent 编排框架 | 多 Agent 对话框架 | 多 Agent 角色扮演 | Agent 状态机库 |
| 沙箱执行 | 内置隔离沙箱 | 无 | 无 | 无（需自行集成） |
| 长期记忆 | 本地持久化记忆 | 无 | 无 | 无 |
| 技能系统 | 渐进式加载的 SKILL.md | 无 | 角色定义 | 无 |
| 子 Agent | 动态创建，并行执行 | 手动编排 | 手动编排 | 手动编排 |
| 模型支持 | 开放（OpenAI、Anthropic、本地 vLLM、OpenRouter 等） | 较灵活 | 较灵活 | 最灵活 |
| 学习曲线 | 中等（提供 setup wizard） | 较高 | 较低 | 较高 |
| 社区活跃度 | 快速增长（GitHub Trending #1） | 成熟稳定 | 活跃 | 非常活跃 |

DeerFlow 的独特优势在于它是唯一一个将**沙箱执行、长期记忆和技能系统**整合在一起的开源框架。AutoGen 和 CrewAI 更偏向于多 Agent 对话编排，需要额外集成才能实现文件操作和持久化存储。LangGraph 提供了最底层的灵活性，但需要大量自建工作。DeerFlow 则提供了"开箱即用"的完整体验，同时保留了充分的可扩展性。

## 如何使用

### 环境要求

- Python 3.12+
- Node.js 22+
- Docker（推荐）或本地开发环境

### 安装步骤

**第一步：克隆仓库**

```bash
git clone https://github.com/bytedance/deer-flow.git
cd deer-flow
```

**第二步：运行设置向导**

```bash
make setup
```

向导会引导你完成以下配置：
- 选择 LLM 提供商（OpenAI、Anthropic、OpenRouter、本地 vLLM 等）
- 配置可选的网络搜索工具（Tavily 等）
- 设置执行和安全偏好（沙箱模式、Bash 权限、文件写入工具等）
- 自动生成 `config.yaml` 并将密钥写入 `.env`

整个过程约 2 分钟。

**第三步：启动服务**

推荐使用 Docker：

```bash
make docker-up
```

或者本地开发模式：

```bash
make dev
```

默认服务地址为 `http://localhost:2026`。

**第四步：验证安装**

```bash
make doctor
```

该命令会检查所有配置项并给出可操作的修复建议。

### 快速体验

启动后，你可以通过 Web 界面或 API 发送任务。例如，让 DeerFlow 研究某个技术趋势并生成报告：

1. 在 Web UI 中输入你的任务描述
2. DeerFlow 会自动分解任务，创建子 Agent
3. 子 Agent 并行执行研究和数据收集
4. 主 Agent 综合结果，生成最终报告

你也可以通过 Claude Code 直接交互——安装 `claude-to-deerflow` 技能后，就能在 Claude Code 中向 DeerFlow 发送研究任务、检查状态和管理线程。

### 支持的模型

DeerFlow 支持广泛的模型接入：
- **云端 API**：GPT-4o、GPT-5、Claude Sonnet/Opus、Gemini 系列、OpenRouter 上的任意模型
- **本地部署**：vLLM 托管的 Qwen3、Llama 等开源模型
- **CLI 工具**：Codex CLI、Claude Code OAuth 集成

## 总结

DeerFlow 2.0 是字节跳动在 AI Agent 领域的一次重要开源贡献。它从一个深度研究框架起步，经过社区反馈后重构为功能全面的超级 Agent 编排平台。

**优点：**
- 开箱即用，setup wizard 极大降低了入门门槛
- 沙箱执行环境让 Agent 真正能在"真实世界"中工作
- 长期记忆系统让 Agent 越用越懂你
- 渐进式技能加载保持上下文窗口精简
- 活跃的社区和快速增长的生态

**需要注意的：**
- 基于 LangGraph/LangChain 构建，依赖链较长，首次部署可能需要排查依赖问题
- 沙箱 Shell 执行需要谨慎配置安全边界
- 相比 CrewAI 等轻量框架，DeerFlow 的资源消耗更高

**推荐指数：★★★★☆（4/5）**

DeerFlow 是目前开源 Agent 框架中最接近"超级 Agent"概念的实现之一。如果你需要构建能完成复杂长周期任务的 AI Agent 系统，DeerFlow 2.0 值得重点关注。对于只需要简单对话式 Agent 的场景，可能略显重量级，但其可扩展性和完整性使其成为长期投资的优秀选择。
