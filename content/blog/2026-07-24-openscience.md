## 工具简介

**OpenScience** 是由 Synthetic Sciences 团队开发的开源 AI 科研工作台（AI Workbench），目前已在 GitHub 上斩获 **2,710+ ⭐**（约 350 Forks），自 2026 年 7 月初上线以来迅速成为科研 AI 领域的热门项目。它以浏览器为交互界面，集成文献检索、假设构建、代码编写、实验运行和结果分析的全流程，支持 Anthropic、OpenAI、Google 等数十个模型提供商的 API 密钥，也可通过其 Atlas 平台使用托管模型。

一句话总结：**OpenScience 是一个让 AI 像科研合作者一样工作的平台——你给出一个研究目标，它自动阅读文献、提出假设、编写并运行代码、执行实验、最后写出完整的分析报告。**

与传统的 AI 编程助手不同，OpenScience 的核心定位不是写通用代码，而是专门为科学研究设计的工作流引擎。它内置了 290+ 个专业技能（Skills），涵盖深度学习训练（DeepSpeed、PEFT、TRL）、分子生物学、化学信息学、论文写作和 LaTeX 排版、图表生成以及云算力调度（Modal、Tinker 等）等多个领域。

## 核心功能

### 1. 全链路研究闭环

OpenScience 最大的亮点在于它能够自主完成从文献调研到最终报告撰写的完整科研循环：

- **文献综述**：自动查询 arXiv、PubMed、Semantic Scholar 等学术数据库，筛选相关论文并提取关键信息
- **假设构建**：基于文献分析提出可验证的研究假设
- **代码编写与执行**：自动生成实验代码并在本地或云端环境中运行
- **数据分析**：对实验结果进行统计分析并可视化
- **报告撰写**：将研究发现整理成结构化的分析报告

整个过程在一个连续的会话中完成，用户只需在浏览器中观察进度即可。

### 2. 多专业智能体系统

OpenScience 采用多智能体架构，默认包含一个通用 `research` 智能体，以及三个领域专家智能体：

| 智能体 | 专业方向 |
|-------|---------|
| **research** | 通用科学研究，协调全流程 |
| **biology** | 分子生物学、临床医学 |
| **physics** | 物理模拟与计算 |
| **ml** | 机器学习工程 |

此外还有 critique（评审）和 literature-review（文献综述）子智能体，以及一个只读的计划模式（plan mode），让用户先审视方案再执行。

### 3. 30+ 科学数据库直连

OpenScience 将主流科学数据库作为工具直接暴露给 AI 智能体，无需手动查询：

- **生物信息**：UniProt、PDB（蛋白质数据库）、Ensembl、ChEMBL
- **化学品**：PubChem
- **学术论文**：arXiv、OpenAlex、Semantic Scholar
- **其他**：约 30 余个科学数据源

智能体可以直接调用这些数据库进行查询，获取最新的研究数据和文献。

### 4. 丰富的专业技能库（290+ Skills）

OpenScience 的技能系统覆盖了科研的各个环节：

- **训练框架**：DeepSpeed、PEFT、TRL 等主流微调方案
- **数据集处理**：数据清洗、标注、增强
- **分子与临床生物学**：蛋白质结构分析、基因序列处理
- **化学信息学**：分子指纹、化合物筛选
- **论文与排版**：LaTeX 模板、图表生成
- **云算力**：Modal、Tinker 等云平台的自动调度

### 5. 模型无关与私有化部署

OpenScience 不绑定任何特定的 AI 模型提供商。用户可以通过以下方式接入模型：

- **自带密钥（BYOK）**：设置 `ANTHROPIC_API_KEY`、`OPENAI_API_KEY`、`GEMINI_API_KEY` 等环境变量，直接使用自己的 API 密钥
- **Atlas 托管平台**：通过 Synthetic Sciences 的 Atlas 平台使用预置的前沿模型，按充值钱包计费
- **免费演示模式**：首次启动时可选择跳过密钥配置，使用免费演示模型体验

所有 API 密钥仅存储在本地机器上，请求直接发送到对应的提供商，不经过第三方中转。

## 适用人群

- **科研人员**：需要快速完成文献综述、数据分析的实验型研究人员
- **研究生/博士生**：辅助开展课题研究、撰写论文初稿
- **AI/ML 工程师**：快速验证算法思路、生成实验对比报告
- **生物/化学研究者**：利用内置的领域技能和数据库加速分子分析和实验设计
- **跨学科研究者**：需要一个统一平台整合多种工具和数据库的复合背景学者

## 如何使用

### 安装

OpenScience 基于 TypeScript 开发，使用 Bun 运行时。安装非常简单：

```bash
# 方式一：全局安装
npm install -g @synsci/openscience
openscience

# 方式二：一次性运行（无需全局安装）
npx synsci
```

### 配置 API 密钥

安装完成后，启动 OpenScience 会在浏览器中打开工作区界面。首次运行会引导你选择模型接入方式：

```bash
# 设置 Anthropic API 密钥（示例）
export ANTHROPIC_API_KEY=sk-ant-xxxxx

# 启动 OpenScience
openscience
```

支持的密钥环境变量包括：`ANTHROPIC_API_KEY`、`OPENAI_API_KEY`、`GEMINI_API_KEY` 等。你也可以通过以下命令交互式地添加密钥：

```bash
openscience keys add
```

### 开始研究项目

启动后，在工作区的浏览器界面中输入你的研究目标，例如：

> "请帮我分析 Transformer 架构在蛋白质序列预测中的最新进展，并给出实验验证方案。"

OpenScience 会自动：
1. 查询相关文献（arXiv、PubMed 等）
2. 筛选出最重要的论文并总结
3. 提出可验证的假设
4. 编写实验代码
5. 在本地或云端运行实验
6. 生成分析结果和可视化图表
7. 输出完整的研究报告

你可以在浏览器中实时查看每个步骤的进度，也可以随时介入调整方向。

### 打开特定项目

如果你已有项目目录，可以直接指定路径打开：

```bash
openscience ~/research/my-project
```

这样 OpenScience 会将工作区与项目文件关联，方便读写项目中的数据和分析结果。

## 总结

OpenScience 代表了 AI 辅助科学研究的一个全新方向——不是简单的问答工具，而是真正能够像科研合作者一样工作的智能体平台。它的核心优势在于：

1. **全链路自动化**：从文献调研到报告撰写，一站式完成
2. **领域专业化**：内置生物、物理、ML 等专业智能体和 290+ 技能
3. **数据直连**：30+ 科学数据库开箱即用
4. **灵活接入**：支持任意模型提供商，不锁定生态
5. **完全开源**：Apache 2.0 许可证，可自行部署和扩展

对于需要频繁进行文献调研、实验设计和数据分析的科研人员来说，OpenScience 是一个值得尝试的强大工具。它特别适合那些希望借助 AI 加速研究进程、但又需要保持对实验过程完全控制力的用户。

**推荐指数：★★★★☆**（4/5）

扣掉的一星是因为目前版本仍处于早期阶段，部分高级技能的稳定性和准确性还有提升空间，且 Atlas 托管平台的功能相对有限。但随着项目的快速迭代和社区贡献的增加，OpenScience 有望成为科研 AI 领域的重要基础设施之一。
